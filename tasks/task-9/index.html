    №9. Электронная таблица: условия по строкам¶

    Python можно таблицей ~6 мин 1 балл файл .ods

    Коротко

    Данные из таблицы — Ctrl+A, Ctrl+C → Блокнот → 9.txt. Цикл по строкам: a = [int(x) for x in s.split()]; повторы — «отпечаток» raz = sorted(a.count(x) for x in set(a)) («одно число трижды, остальные четыре различны» — raz == [1, 1, 1, 1, 3]), повторяющиеся povt и неповторяющиеся nepovt — списками; условие → if почти дословно; k += 1. Номер строки — enumerate(…, 1).

    Как узнать задачу¶

    • «Откройте файл электронной таблицы, содержащей в каждой строке пять (шесть, семь…) натуральных чисел. Определите количество строк таблицы, для которых выполнены оба условия: — …; — …». Файл в 2027 — .ods.
    • Первое условие обычно про повторы («все числа различны», «одно число повторяется трижды, остальные различны»), второе — про суммы, средние, максимум и минимум.
    • Вместо «количества строк» могут спросить наибольший (наименьший) номер строки, сумму чисел в такой строке или сумму номеров.

    Шаблон¶

    Шаг 1 — данные. Откройте файл в LibreOffice Calc (или Excel), Ctrl+A (выделить всё), Ctrl+C, вставьте в Блокнот и сохраните как 9.txt в папке с программой. Числа в строке будут разделены табуляцией. (В редактор PyCharm десятки тысяч строк лучше не вставлять — он «задумывается».)

    Шаг 2 — программа:

    # №9, демоверсия ЕГЭ-2027 (данные таблицы скопированы в 9.txt): в каждой строке пять натуральных чисел. Сколько строк,
# в которых все числа различны, а удвоенная сумма максимального и минимального больше суммы оставшихся трёх?
# Ответ: 4874
k = 0                                          # сколько подходящих строк
for s in open('9.txt'):                        # s — строка файла: '6\t334\t334\t334\t525\n'
    a = [int(x) for x in s.split()]            # числа строки: [6, 334, 334, 334, 525]
    raz = sorted(a.count(x) for x in set(a))   # сколько раз встречается каждое число: [1, 1, 3]
    povt = [x for x in a if a.count(x) > 1]    # повторяющиеся — со всеми копиями: [334, 334, 334]
    nepovt = [x for x in a if a.count(x) == 1] # неповторяющиеся: [6, 525]
    if raz == [1, 1, 1, 1, 1] and 2 * (max(a) + min(a)) > sum(a) - max(a) - min(a):
        k += 1
print(k)
    В условии В шаблоне
    все числа в строке различны raz == [1, 1, 1, 1, 1] или len(set(a)) == len(a)
    одно число повторяется дважды, остальные (четыре) различны raz == [1, 1, 1, 1, 2]
    одно число трижды, остальные различны (из семи) raz == [1, 1, 1, 1, 3]
    два числа по два раза, остальные различны (из семи) raz == [1, 1, 1, 2, 2]
    одно число трижды, другое дважды, остальные различны (из семи) raz == [1, 1, 2, 3]
    в строке есть повторяющиеся; есть и те, и другие povt; povt and nepovt (пустой список — «ложь»)
    сумма (среднее) повторяющихся «с учётом повторений» sum(povt), sum(povt) / len(povt)
    сумма повторяющихся «без учёта повторений»; само повторяющееся число sum(set(povt)); povt[0]
    максимум, минимум, «оставшиеся три» max(a), min(a), sum(a) - max(a) - min(a)
    два наибольших, «по порядку» a.sort() — тогда a[0] наименьшее, a[-1] и a[-2] наибольшие
    максимальное число не повторяется a.count(max(a)) == 1
    «не больше», «не превышает»; «не меньше» <=; >=
    оба условия; хотя бы одно and; or
    номер строки, сумма номеров, сумма чисел строки вкладка «Номер строки»

    raz — это сколько раз встречается каждое число, по возрастанию. Его пишут прямо по условию: «из семи чисел одно трижды, остальные четыре различны» — четыре единицы и тройка. Считать копии не нужно — в этом главная ошибка (см. ниже).

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, пересказ). В каждой строке таблицы — пять натуральных чисел. Сколько строк, в которых все числа различны, а удвоенная сумма максимального и минимального чисел больше суммы трёх оставшихся?

    Решение.

    Условие Код
    в строке все числа различны raz == [1, 1, 1, 1, 1]
    удвоенная сумма максимального и минимального 2 * (max(a) + min(a)) — скобки!
    сумма трёх оставшихся sum(a) - max(a) - min(a)
    оба условия; «больше» and, >

    Программа — шаблон выше. Ответ: 4874.

    Проверка вторым способом

    Попарно сравнить все числа строки (all(a[i] != a[j] …)), отсортировать и проверить 2 * (a[0] + a[4]) > a[1] + a[2] + a[3] — тоже 4874. Или таблицей (ниже, «Подробнее»): в LibreOffice получается то же число. Для контроля полезно посмотреть первые строки файла глазами и решить их вручную.

    Разновидности¶

    Условие Как записать
    демо-2027 и ЕГЭ 2023–2026: повторы + сумма / среднее / max, min шаблон
    «одно число трижды, остальные различны; повторяющееся больше среднего неповторяющихся» raz == […, 3], povt[0] > sum(nepovt) / len(nepovt) (вкладка «Повторы»)
    «среди семи чисел совпадают ровно четыре» одно число 4 раза: raz == [1, 1, 1, 4]
    «минимальное число встречается два или три раза, остальные без повторений» a.count(min(a)) in (2, 3) and len(povt) == a.count(min(a))
    есть число, повторяющееся не меньше трёх раз max(raz) >= 3
    квадрат суммы / сумма квадратов; «более чем в 6 раз меньше» (…) ** 2, sum(x ** 2 for x in …); сумма трёх > 6 * min(a)
    тройка — стороны (остроугольного) треугольника; можно выбрать три числа, не образующие треугольник a.sort(): a[0] + a[1] > a[2] (a[0]**2 + a[1]**2 > a[2]**2); тройки — combinations(a, 3)
    четыре числа образуют арифметическую прогрессию; разбиваются на две пары с равными суммами a.sort(), a[1] - a[0] == a[2] - a[1] == a[3] - a[2]; три разбиения: a[0] + a[1] == a[2] + a[3] or …
    чётных больше, чем нечётных; сумма чётных меньше ch = [x for x in a if x % 2 == 0] и nech
    «заметное» число — больше среднего строки z = [x for x in a if x > sum(a) / len(a)]
    в строке есть целая часть среднего; есть квадрат / куб натурального числа sum(a) // len(a) in a; round(x ** 0.5) ** 2 == x, round(x ** (1/3)) ** 3 == x
    числа по возрастанию / неубыванию / невозрастанию a == sorted(a) (+ len(set(a)) == len(a) для строгого), a == sorted(a, reverse=True)
    две четвёрки: столбцы 1–4 и 5–8 a[:4], a[4:]
    наибольший / наименьший номер строки, сумма чисел этой строки, сумма (чётных) номеров вкладка «Номер строки»
    ячейка: число не повторяется в строке и встречается в своём столбце (в других строках) N раз; соседние ячейки вкладка «Вся таблица»
    числа целые, бывают отрицательные; «в ответе — абсолютное значение» шаблон работает; abs(…) в ответе
    старые прототипы: среднее строки больше 400, сколько чисел больше 20 одна формула в таблице или то же if 
    # №9 (своя, на данных демоверсии 9.txt): сколько строк, в которых одно число повторяется трижды, два других различны,
# а повторяющееся число больше среднего арифметического неповторяющихся?
# Ответ: 2048
k = 0
for s in open('9.txt'):
    a = [int(x) for x in s.split()]
    raz = sorted(a.count(x) for x in set(a))
    povt = [x for x in a if a.count(x) > 1]
    nepovt = [x for x in a if a.count(x) == 1]
    if raz == [1, 1, 3] and povt[0] > sum(nepovt) / len(nepovt):   # povt[0] — само число (в povt три копии)
        k += 1
print(k)

    povt для строки [7, 3, 7, 7, 12] — [7, 7, 7]: число лежит в списке столько раз, сколько встречается. Поэтому само число — povt[0], а «сумма повторяющихся с учётом повторений» — sum(povt).

    # №9 (своя, на данных демоверсии 9.txt): найдите строку с наибольшим номером, в которой одно число повторяется
# дважды, три других различны, а повторяющееся число меньше наименьшего из неповторяющихся. Выведите номер строки
# и сумму её чисел.
# Ответ: 27779 2702
v = []
for n, s in enumerate(open('9.txt'), 1):       # n — номер строки, как в таблице (с 1)
    a = [int(x) for x in s.split()]
    raz = sorted(a.count(x) for x in set(a))
    povt = [x for x in a if a.count(x) > 1]
    nepovt = [x for x in a if a.count(x) == 1]
    if raz == [1, 1, 1, 2] and povt[0] < min(nepovt):
        v.append((n, sum(a)))                  # запоминаем номер и сумму — того, что спрашивают
print(*max(v))                                 # наибольший номер (и сумма этой строки)

    enumerate(…, 1) нумерует строки с 1 — как в таблице. Запоминайте то, что спрашивают, вместе с номером: пары (номер, сумма); max(v) — пара с наибольшим номером, min(v) — с наименьшим, sum(n for n, _ in v) — сумма номеров.

    # №9 (своя, на данных демоверсии 9.txt): назовём ячейку интересной, если число в ней не повторяется в своей строке
# и встречается в своём столбце больше 35 раз. Сколько строк, в которых не меньше трёх интересных ячеек?
# Ответ: 75
t = [[int(x) for x in s.split()] for s in open('9.txt')]   # вся таблица: t[r][c] — строка r, столбец c
cols = [[row[c] for row in t] for c in range(5)]          # столбцы
k = 0
for row in t:
    n = 0                                      # интересных ячеек в строке
    for c in range(5):
        x = row[c]
        if row.count(x) == 1 and cols[c].count(x) > 35:
            n += 1
    if n >= 3:
        k += 1
print(k)

    Условие про столбец или другие строки — строкой не обойтись: читаем всю таблицу в список t. Работает ~12 с на 28 000 строк (count по столбцу для каждой ячейки); быстрее — from collections import Counter и Counter(cols[c])[x]. Соседи клетки — t[r + dr][c + dc] для dr, dc из −1, 0, 1 (кроме самой клетки, в пределах таблицы).

    Подробнее: решение таблицей (LibreOffice Calc / Excel)

    Данные никуда переносить не нужно — всё в той же таблице. Проверено в LibreOffice 26.8 на демоверсии (4874) и на задаче «одно число трижды» с Решу ЕГЭ (36).

    1. Счётчики повторов. Справа от данных, в F1: =СЧЁТЕСЛИ($A1:$E1;A1) — сколько раз встречается число из A1. Знак $ — чтобы при протягивании диапазон A:E не уезжал. Протянуть вправо до J1 (по клетке на число), затем вниз на все строки (двойной щелчок по маркеру в углу — если соседний столбец заполнен).
    2. Условие в K1: =ЕСЛИ(И(СУММ(F1:J1)=5;2*(МАКС(A1:E1)+МИН(A1:E1))>СУММ(A1:E1)-МАКС(A1:E1)-МИН(A1:E1));1;0) — «все различны» ⇔ все счётчики равны 1 ⇔ их сумма 5. Протянуть вниз.
    3. Ответ: =СУММ(K:K) (или посмотреть сумму в строке состояния, выделив столбец).

    Для «одно число трижды, остальные различны» (7 чисел, счётчики в H:N): СЧЁТЕСЛИ(H1:N1;3)=3 и СЧЁТЕСЛИ(H1:N1;1)=4; среднее неповторяющихся — СРЗНАЧЕСЛИ(H1:N1;1;A1:G1), повторяющееся — СУММЕСЛИ(H1:N1;3;A1:G1)/3. Не проверяйте «сумма счётчиков = 13»: так же суммируются «2 + 2 + 2 + 1» (см. «Типичные ошибки»).

    Таблицей удобно, когда условие простое; на сложных повторах столбцов-помощников становится много — программа короче.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Копии в списке повторов. Число, которое встречается трижды, лежит в povt три раза: «одно число трижды» — len(povt) == 3, а не 1 (у разборщиков из-за этого 0 строк вместо 941). А «две пары» через count(x) != 1 принимает и число, повторённое 4 раза: на файлах Решу ЕГЭ 59778 и 89192 — номер 15 вместо 372 и 3914 строк вместо 143. «Отпечаток» raz пишется прямо по условию и таких ошибок не даёт.
    • Сумма счётчиков СЧЁТЕСЛИ в таблице неоднозначна. Для семи чисел и «3 + 1 + 1 + 1 + 1», и «2 + 2 + 2 + 1» дают 13; для восьми «3 + 3 + 1 + 1» и «4 + 1 + 1 + 1 + 1» — 20. Считайте, сколько счётчиков равны 3 и сколько равны 1.
    • Пустая строка в конце 9.txt (лишний Enter) — max() падает: ValueError: max() arg is an empty sequence (Python 3.11 и 3.12). Удалите пустую строку.
    • Куб через int: int(64 ** (1/3)) = 3, int(1000 ** (1/3)) = 9 — дробная степень даёт 3.9999… Только round(…).
    • s.split(';') или s.split(' ') на данных, скопированных из таблицы, — ValueError (там табуляция). Только s.split() без аргумента.
    • Скобки: 2 * max(a) + min(a) вместо 2 * (max(a) + min(a)) — на демоверсии 4422 вместо 4874. Квадрат суммы (x + y) ** 2 ≠ сумма квадратов x ** 2 + y ** 2.
    • Знаки: «не больше» — <=, «больше» — > (с >= на демоверсии 4877 вместо 4874). Среднее — /, не //.
    • Повторяющееся число — povt[0], а не a[0] (первое число строки может быть любым).
    • Номер строки считают для каждой строки (enumerate), а не только для подходящих. «Сумма чисел строки с наибольшим номером» — у последней подходящей строки, а не наибольшая сумма; print(sum(a)) после цикла — сумма последней строки файла.
    • Таблица без $: =СЧЁТЕСЛИ(A1:E1;A1) при протягивании вправо превращается в СЧЁТЕСЛИ(B1:F1;B1) — счёт неверный.
    • СРЗНАЧЕСЛИ без подходящих клеток даёт #ДЕЛ/0!, и СУММ по столбцу тоже становится ошибкой — оберните в ЕСЛИОШИБКА(…;0) или считайте единицы СЧЁТЕСЛИ(K:K;1).
