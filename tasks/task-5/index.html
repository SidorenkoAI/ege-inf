    №5. Алгоритм: число → запись → число¶

    Python ~4 мин 1 балл без файла

    Коротко

    Перебрать N с 1: s = bin(n)[2:] → правки строки по условию (if … else) → r = int(s, 2) → подходящие — в список → min или max. Спрашивают R — в список кладём r, спрашивают N — n.

    Как узнать задачу¶

    • «На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.
    • Строится двоичная запись числа N. 2. …»
    • Дальше — правило: что дописать слева или справа, что заменить; часто зависит от чётности N или суммы цифр.
    • Вопрос: «наименьшее R, превышающее 95», «наибольшее N, при котором R меньше 30» и т. п.
    • Бывает троичная, четверичная, восьмеричная запись — и вариант совсем без систем счисления (цифры числа).

    Шаблон¶

    # №5, демоверсия ЕГЭ-2027: чётное N — к двоичной записи слева и справа по две единицы (11…11),
# нечётное — слева 1, справа 00. Наименьшее R, превышающее 95.
# Ответ: 100
otvet = []                          # сюда — все подходящие ответы
for n in range(1, 10000):           # N натуральное — с 1
    s = bin(n)[2:]                  # двоичная запись без '0b'
    if n % 2 == 0:
        s = '11' + s + '11'
    else:
        s = '1' + s + '00'
    r = int(s, 2)                   # обратно в десятичную
    if r > 95:                      # условие из вопроса
        otvet.append(r)             # спрашивают R → r, спрашивают N → n
print(min(otvet))                   # наименьшее → min, наибольшее → max

    Что менять под задачу:

    В условии В шаблоне
    двоичная запись N s = bin(n)[2:] — [2:] убирает 0b
    N чётное / делится на k n % 2 == 0 / n % k == 0
    дописать справа / слева s = s + '01' / s = '1' + s
    последние k цифр записи s[-k:]
    два левых разряда заменить на 10 s = '10' + s[2:] — срезом, не replace
    сумма цифр двоичной записи; «число единиц» s.count('1')
    сумма цифр любой записи sum(map(int, s))
    остаток (или другое число) — в двоичную и дописать s = s + bin(n % 3 * 3)[2:]
    каждую 1 заменить на 11 s.replace('1', '11')
    запись в обратном порядке s[::-1]
    середина записи (длина чётная) s[:len(s) // 2] + '1' + s[len(s) // 2:]
    троичная, четверичная запись своя функция to_base(n, 3) (вкладка ниже), обратно — int(s, 3)
    восьмеричная oct(n)[2:], обратно — int(s, 8)
    превышает / не превышает / меньше / не меньше > / <= / < / >=
    спрашивают R / N otvet.append(r) / otvet.append(n)
    наименьшее / наибольшее min(otvet) / max(otvet)
    «N > 20», «N нечётное» range(21, …); n % 2 == 1 — в условие if

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, пересказ). Строится двоичная запись N. Если N чётное — к ней слева и справа дописывается по две единицы, если нечётное — справа два нуля, слева единица. Получилась двоичная запись R. Укажите наименьшее R, превышающее 95.

    Условие Код
    двоичная запись N s = bin(n)[2:]
    N чётное → по две единицы слева и справа if n % 2 == 0: s = '11' + s + '11'
    иначе → слева 1, справа 00 else: s = '1' + s + '00'
    перевод в десятичную r = int(s, 2)
    R превышает 95, спрашивают R if r > 95: otvet.append(r)
    наименьшее print(min(otvet))

    Ответ: 100 (при N = 9).

    Проверка вручную
    N запись N запись R R
    4 100 11 100 11 115
    5 101 1 101 00 52
    6 110 11 110 11 123
    7 111 1 111 00 60
    8 1000 11 1000 11 227
    9 1001 1 1001 00 100

    Нечётные N из трёх цифр дают R из шести цифр — не больше 63; чётные из трёх — 115 и 123; любые N из четырёх цифр дают R от 100 и выше. Наименьшее R > 95 — 100. Обратите внимание: первое подходящее R — 115 (N = 4), а наименьшее — 100.

    Разновидности¶

    Условие Как записать
    дописать цифры слева/справа по чётности N (демо-2027, ЕГЭ 2024–2026) шаблон
    спрашивают N: «наибольшее N, при котором R < …» otvet.append(n) и max (вкладка)
    «при каком N R наименьшее среди больших …» в список — пары (r, n): min(otvet)[1]
    «N не больше 12 — наибольшее R» range(1, 13), условия на R нет
    дважды дописать остаток суммы цифр на 2 s = s + str(s.count('1') % 2) — две такие строки подряд
    сумма цифр чётна → дописать и заменить два левых разряда (демо-2023) if … else, срез '10' + s[2:] (вкладка)
    N делится на 3 — дописать три последние цифры, иначе остаток × 3 в двоичной (демо-2024) s + s[-3:], s + bin(n % 3 * 3)[2:]
    троичная / четверичная запись (ЕГЭ-2023, ЕГЭ-2025) своя to_base (вкладка)
    восьмеричная, «приписать слева» oct(n % 7 * 7)[2:] + s
    «R, ближайшее к числу»; среди равных — наибольшее N min(otvet, key=lambda r: abs(r - 150)) (вкладка)
    заменить каждую цифру; дописать запись в обратном порядке; вставить в середину replace, s[::-1], срезы (таблица выше)
    ответ — чётное R, нечётное N добавить в if: r % 2 == 0, n % 2 == 1
    без систем счисления: цифры трёх-, четырёхзначного числа; «в порядке неубывания» a, b, c = map(int, str(n)), меньшее — первым (вкладка) 
    # №5 (своя): если N делится на 3 — к двоичной записи слева дописывается 1, справа 0; иначе справа дописывается
# двоичная запись остатка от деления N на 3. Наибольшее N, после обработки которого R меньше 200.
# Ответ: 97
otvet = []
for n in range(1, 10000):
    s = bin(n)[2:]
    if n % 3 == 0:
        s = '1' + s + '0'
    else:
        s = s + bin(n % 3)[2:]      # остаток — тоже в двоичную, без '0b'
    r = int(s, 2)
    if r < 200:
        otvet.append(n)             # спрашивают N — в список кладём n
print(max(otvet))

    # №5 (своя): если число единиц в двоичной записи чётно — справа дописывается 1, затем два левых разряда
# заменяются на 11; иначе справа 0, затем два левых разряда — на 10. Наименьшее N, при котором R больше 63.
# Ответ: 32
otvet = []
for n in range(1, 10000):
    s = bin(n)[2:]
    if s.count('1') % 2 == 0:       # count('1') — единица в кавычках
        s = s + '1'
        s = '11' + s[2:]            # «заменить два левых разряда» — срез, а не replace
    else:                           # else, а не второй if: s уже изменилась
        s = s + '0'
        s = '10' + s[2:]
    r = int(s, 2)
    if r > 63:
        otvet.append(n)
print(min(otvet))

    # №5 (своя): троичная запись N; если N делится на 3 — справа дописывается 12, иначе остаток от деления N на 3
# умножается на 4, переводится в троичную и дописывается справа. Наименьшее R, большее 300.
# Ответ: 302
def to_base(x, b):                  # запись числа x в системе с основанием b (2…10)
    if x == 0:
        return '0'                  # без этой строки 0 превратится в пустую строку
    s = ''
    while x > 0:
        s = str(x % b) + s          # остаток — очередная цифра справа налево
        x //= b
    return s


otvet = []
for n in range(1, 10000):
    s = to_base(n, 3)
    if n % 3 == 0:
        s = s + '12'
    else:
        s = s + to_base(n % 3 * 4, 3)
    r = int(s, 3)                   # из троичной — int(s, 3)
    if r > 300:
        otvet.append(r)
print(min(otvet))

    # №5 (своя): если N делится на 4 — к двоичной записи справа дописываются две её последние цифры, иначе —
# двоичная запись остатка от деления N на 4. Укажите R, ближайшее к 150.
# Ответ: 147
otvet = []
for n in range(1, 10000):
    s = bin(n)[2:]
    if n % 4 == 0:
        s = s + s[-2:]              # две последние цифры — срез с конца
    else:
        s = s + bin(n % 4)[2:]
    r = int(s, 2)
    otvet.append(r)                 # условия нет — берём все R
print(min(otvet, key=lambda r: abs(r - 150)))    # ближайшее: наименьшее расстояние |R − 150|

    # №5 (своя), без систем счисления: на вход — трёхзначное N. Сумма первой и второй цифр и произведение второй
# и третьей записываются друг за другом в порядке неубывания. Наибольшее N, для которого получится 1218.
# Ответ: 936
otvet = []
for n in range(100, 1000):          # трёхзначные
    a, b, c = map(int, str(n))      # цифры числа
    s1, s2 = a + b, b * c
    r = str(min(s1, s2)) + str(max(s1, s2))     # «неубывание»: сначала меньшее
    if r == '1218':
        otvet.append(n)
print(max(otvet))
    Подробнее: решение функцией — ответ одной строкой

    Алгоритм — в функцию f(n), она возвращает R. Тогда «наименьшее R > 95» — min(f(n) for n in … if f(n) > 95), «наименьшее N, при котором R > 95» — min(n for n in … if f(n) > 95). Короче, но надо понимать генераторы.

    # №5, демоверсия ЕГЭ-2027 — то же решение функцией: f(n) — это R, ответ — одной строкой.
# Ответ: 100
def f(n):
    s = bin(n)[2:]
    if n % 2 == 0:
        s = '11' + s + '11'
    else:
        s = '1' + s + '00'
    return int(s, 2)


print(min(f(n) for n in range(1, 10000) if f(n) > 95))    # спрашивают N — min(n for n in … if f(n) > 95)
    Подробнее: задачи с огромным диапазоном N (за рамками шаблона)

    В тренировочных работах СтатГрада 2024–2025 бывает «N принадлежит отрезку [234 567 890; 567 891 234]» или «сколько чисел R лежит на отрезке». Перебор сотен миллионов N на Python идёт минуты, поэтому там рассуждают: чем больше N, тем длиннее запись, значит, наибольшее R — у одного из последних N отрезка; перебирают только их, range(567891230, 567891235), — чётные и нечётные дают R разной длины. (Так решается задача СтатГрада 24.10.2024, ответ сверен с Решу ЕГЭ.) Среди задач ЕГЭ 2015–2026 в каталоге Решу ЕГЭ таких нет.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Два if вместо if … else. Если условие проверяется по строке, которую первая ветка уже изменила («число единиц чётно → дописать 1 …»), второй if срабатывает после первого. На задачах в формате демо-2023 так получилось 12, 17 и 15 вместо верных 16, 24 и 19; в примере «Два левых разряда» — 24 вместо 32. Одно правило «если … иначе …» — это всегда if … else.
    • Первое найденное R — не наименьшее. R при росте N «скачет»: в демо первое R > 95 — 115 (N = 4), а наименьшее —
    • Для R — только список и min/max; break годится, только когда спрашивают N.
    • Своя функция перевода без нуля. while x > 0 для 0 вернёт пустую строку, и цифра 0 молча пропадёт. В задаче «дописать троичную запись остатка от деления N на 3» R(12) выходит 12 вместо 36, а «наибольшее N, при котором R < 20» — 18 вместо 6. Первая строка функции — if x == 0: return '0'.
    • Перебор с нуля. Натуральные — с 1: в демо N = 0 дало бы R = 27, и «наименьшее R > 20» стало бы 27 вместо 28. Если в условии «N > 20» — перебор с 21.
    • Не переприсвоили строку. s.replace('1', '11') сам s не меняет — нужно s = s.replace('1', '11').
    • s.count(1) и s + n % 2 — TypeError: в строке ищем и дописываем строки: s.count('1'), s + str(n % 2).
    • Забыли [2:] у bin — в запись попадёт 0b, и int(s, 2) выдаст ошибку или чужое число.
    • «Два левых разряда» через replace — заменятся все такие пары в записи, а не первые две цифры.
    • Перепутали лево и право, «не превышает» (<=) и «меньше» (<), N и R в вопросе.
    • Мало перебрали. Если ответ — у самого края range, увеличьте границу и проверьте снова. В задачах ЕГЭ, которые мы проверяли, 10 000 хватало с запасом.
