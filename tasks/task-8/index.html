    №8. Комбинаторика: слова из букв¶

    Python можно вручную ~4 мин 1 балл без файла

    Коротко

    Перебрать все слова через product(sorted(буквы), repeat=длина), номер — enumerate(…, 1), условие из задачи — в if.

    Как узнать задачу¶

    • «Все N-буквенные слова, составленные из букв …, записаны в алфавитном порядке и пронумерованы».
    • Спрашивают номер слова, слово по номеру или сколько слов подходит под условие.
    • Иногда вместо букв — цифры: «сколько существует пятизначных чисел в восьмеричной системе, у которых…».

    Шаблон¶

    # №8, демоверсия ФИПИ-2027: слова из 5 букв А, К, Ц, Е, Н, Т в алфавитном порядке.
# Первое слово с чётным номером, которое не начинается с А, Е, К и содержит хотя бы одну Т.
# Ответ: 3914 НААТЕ
from itertools import product

alphabet = sorted('АКЦЕНТ')                               # буквы по алфавиту — обязательно!
for i, w in enumerate(product(alphabet, repeat=5), 1):    # i — номер слова, с 1
    w = ''.join(w)                                        # кортеж букв -> строка
    if i % 2 == 0 and w[0] not in 'АЕК' and 'Т' in w:     # условие из задачи
        print(i, w)
        break                                             # «первое» — дальше не ищем

    Что менять под задачу:

    В условии В шаблоне
    буквы sorted('…') — порядок букв не важен, sorted расставит по алфавиту
    длина слова repeat=5
    условие строка if … (как переписывать — в таблице «Разновидности» ниже)
    «первое» слово break после print
    «последнее» слово убрать break — останется напечатанным последнее подошедшее
    «сколько слов» вместо print и break — счётчик (пример ниже)

    Пример с разбором¶

    Задача (демоверсия ФИПИ-2027, пересказ). Из букв А, К, Ц, Е, Н, Т составляют пятибуквенные слова (буквы могут повторяться), все слова записаны в алфавитном порядке и пронумерованы с 1. Найдите первое слово с чётным номером, которое не начинается с букв А, Е, К и содержит хотя бы одну Т. В ответ запишите номер слова.

    Решение — шаблон выше, условие переводим дословно:

    В условии В коде
    чётный номер i % 2 == 0
    не начинается с А, Е, К w[0] not in 'АЕК'
    хотя бы одна Т 'Т' in w
    все три условия сразу and между ними

    Программа печатает 3914 НААТЕ. Ответ: 3914.

    Проверка вручную: слово — это число

    Пронумеруйте буквы по алфавиту цифрами с нуля: А = 0, Е = 1, К = 2, Н = 3, Т = 4, Ц = 5. Тогда каждое слово — это пятизначное число в шестеричной системе, а номер слова = значение числа + 1 (первое слово ААААА = 0, его номер 1).

    НААТЕ → 3 0 0 4 1₆ = 3·6⁴ + 4·6 + 1 = 3888 + 24 + 1 = 3913, номер 3913 + 1 = 3914. Сходится.

    Так же быстро ищется «слово по номеру»: номер − 1 → перевести в систему с основанием «число букв» → цифры заменить буквами.

    Разновидности¶

    На экзамене встречаются две группы: список слов (номер, слово по номеру, количество по номерам) и все комбинации — чаще всего числа в k-ичной системе. Шаблон один, меняются строка product(…) и if.

    Что спрашивают

    Вопрос Как записать
    номер первого слова с условием print(i) и break — как в шаблоне
    номер последнего слова без break: последним напечатается нужное (или last = i и print(last) после цикла)
    слово по номеру («что стоит на 350-м месте») if i == 350: print(w)
    сколько слов / чисел счётчик count — вкладка «Количество» ниже
    сколько слов с чётными (нечётными) номерами и условием if i % 2 == 0 and …: count += 1 — номер i от enumerate, а счётчик отдельно
    номер в списке, куда попали не все слова («коды, где буква В ровно одна, записаны по алфавиту») номер считаем сами: i += 1 внутри if отбора, а не enumerate — номер есть только у кодов из списка

    Что за слова

    Условие Как записать
    буквы могут повторяться product(буквы, repeat=длина)
    каждая буква — не больше одного раза permutations(буквы, длина); если спрашивают номер — permutations(sorted(буквы), длина)
    слова из перестановок букв слова (КАПКАН, КАРЕТА) set(permutations('КАПКАН')) — set убирает одинаковые слова
    k-ичные числа цифры системы как буквы: product('01234567', repeat=5) и обязательно w[0] != '0'
    система больше 10 цифры '0123456789AB…'; «цифр больше 9» — буквы A… (вкладка ниже)
    все цифры разные permutations('0123456789', 4) или len(set(w)) == len(w)
    длина числа не задана («сколько чисел с разными цифрами делятся на 5») цикл по длинам: for n in range(1, 11): и внутри permutations('0123456789', n)
    цифры идут по возрастанию (не по убыванию) w[0] < w[1] < w[2] (>= — «невозрастание»); строго по возрастанию любой длины — combinations(цифры, n)
    коды всех длин подряд (A…Z, потом AA…ZZ, потом AAA…) номер = все более короткие коды + код как число + 1 — вкладка «Коды всех длин»
    очень много вариантов (8–12 цифр в системе 9–16) перебор не дождаться — вкладка «Без полного перебора»

    Условия на буквы

    Условие Как записать
    ровно две буквы А / не меньше двух / от одной до двух w.count('А') == 2 / >= 2 / 1 <= w.count('А') <= 2
    ровно одна гласная (из Э, А) w.count('Э') + w.count('А') == 1
    начинается / заканчивается на … w[0] == '…', w[-1] == '…'; «не на А, Е, К» — w[0] not in 'АЕК'
    нет сочетания КК 'КК' not in w
    нет двух одинаковых букв подряд all(w[k] != w[k + 1] for k in range(len(w) - 1))
    рядом с 3 нет чётной цифры all('3' + d not in w and d + '3' not in w for d in '024') — вкладка «Числа»
    чётные и нечётные цифры чередуются all(int(w[k]) % 2 != int(w[k + 1]) % 2 for k in range(len(w) - 1))
    гласные и согласные чередуются all((w[k] in 'ЕАИ') != (w[k + 1] in 'ЕАИ') for k in range(len(w) - 1)) — в строке гласные этой задачи
    две гласные не стоят рядом all(not (w[k] in 'УА' and w[k + 1] in 'УА') for k in range(len(w) - 1)); Й — согласная, Ь — ни гласная, ни согласная
    ровно две цифры больше 12, причём рядом sum(1 for c in w if c in 'DEF') == 2 and any(w[k] in 'DEF' and w[k + 1] in 'DEF' for k in range(len(w) - 1))
    гласных больше, чем согласных (6 букв) sum(1 for c in w if c in 'ЕОИА') > 3 
    # №8, количество: сколько слов из 6 букв можно составить из букв В, Е, С, Н, А,
# если буква А встречается ровно 2 раза и слово не начинается с Н?
# Ответ: 3200
from itertools import product

count = 0
for w in product('ВЕСНА', repeat=6):      # для количества порядок букв не важен
    w = ''.join(w)
    if w.count('А') == 2 and w[0] != 'Н':
        count += 1
print(count)

    # №8, перестановки: сколько различных слов можно получить перестановкой букв слова КАПКАН,
# если две буквы К не стоят рядом?
# Ответ: 120
from itertools import permutations

count = 0
for w in set(permutations('КАПКАН')):     # set — убрать одинаковые слова (две К, две А)
    w = ''.join(w)
    if 'КК' not in w:
        count += 1
print(count)

    # №8, числа: сколько существует шестеричных пятизначных чисел, в которых ровно одна цифра 3
# и рядом с цифрой 3 не стоит чётная цифра?
# Ответ: 710
from itertools import product

count = 0
for w in product('012345', repeat=5):         # цифры шестеричной системы — с нулём!
    w = ''.join(w)
    if w[0] != '0' and w.count('3') == 1:     # w[0] != '0' — иначе число не пятизначное
        if all('3' + d not in w and d + '3' not in w for d in '024'):
            count += 1
print(count)

    # №8, система больше 10: сколько существует шестнадцатеричных четырёхзначных чисел,
# в которых ровно одна цифра F и не больше двух цифр, больших 9?
# Ответ: 9400
from itertools import product

count = 0
for w in product('0123456789ABCDEF', repeat=4):
    w = ''.join(w)
    big = 0                                   # сколько цифр больше 9 (это буквы A…F)
    for c in w:
        if c in 'ABCDEF':
            big += 1
    if w[0] != '0' and w.count('F') == 1 and big <= 2:
        count += 1
print(count)

    # №8, буква Ё: слова из 4 букв Л, Ё, Ж, Е записаны в алфавитном порядке и пронумерованы с 1.
# Какое слово стоит под номером 100?
# Ответ: ЁЖЕЛ
from itertools import product

order = 'АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ'
alphabet = sorted('ЛЁЖЕ', key=order.index)    # просто sorted() поставит Ё первой — неверно!
for i, w in enumerate(product(alphabet, repeat=4), 1):
    if i == 100:
        print(''.join(w))
        break

    Перебирать все коды долго и не нужно: сначала идут все более короткие коды, а среди кодов той же длины номер — это код как число в системе «число букв» плюс 1 (как в «Проверке вручную» выше).

    # №8, коды всех длин: выписаны все коды из латинских букв A…Z — сначала однобуквенные по алфавиту,
# потом двухбуквенные (AA, AB, …, ZZ), потом трёхбуквенные и так далее. Под каким номером код HELLO?
# Ответ: 3752127
s = 'HELLO'
n = sum(26 ** k for k in range(1, len(s)))    # все более короткие коды: 26 + 26² + 26³ + 26⁴
v = 0
for c in s:                                   # код — число в 26-ричной системе: A = 0, B = 1, …, Z = 25
    v = v * 26 + (ord(c) - ord('A'))
print(n + v + 1)                              # + 1 — нумерация с единицы

    product перебирает примерно 3 млн слов в секунду: 60 млн — около 20 секунд, это нормально. Но 15⁸ ≈ 2,5 млрд — уже больше 8 минут. Тогда перебираем не сами числа, а виды цифр на каждом месте (ноль / буква / остальные) и умножаем, сколько цифр каждого вида.

    # №8, без полного перебора: сколько существует 16-ричных девятизначных чисел, в записи которых
# ровно три нуля и не больше двух цифр-букв (A…F)?
# Ответ: 347208120
from itertools import product

# 16⁹ ≈ 69 млрд чисел — перебор не дождаться. Цифры трёх видов: 0, буквы A…F (6 штук), 1…9 (9 штук).
# Перебираем вид цифры на каждом месте (3⁹ = 19 683 варианта) и умножаем, сколько цифр каждого вида.
count = 0
for w in product('0LD', repeat=9):            # 0 — ноль, L — буква, D — цифра 1…9
    w = ''.join(w)
    if w[0] != '0' and w.count('0') == 3 and w.count('L') <= 2:
        count += 6 ** w.count('L') * 9 ** w.count('D')
print(count)

    Тот же приём — «чётная / нечётная» на месте (11-значные числа, где нечётные цифры не стоят рядом). Совсем редкие задачи (подсчёт «подходящих» чисел по соседним парам, числа не больше N с разными цифрами) решаются динамикой или счётом по цифрам N — за рамками шаблона.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Ведущий ноль. «Пятизначное число» не может начинаться с 0, хотя в условии этого не пишут. Без w[0] != '0' в задаче «8-ричные пятизначные, не начинаются с нечётной…» получается 12180 вместо 9135.
    • Буква Ё. sorted ставит Ё перед А: sorted('ЁЛКА') → Ё, А, К, Л — номера слов уедут. Если в словах есть Ё — порядок задаётся алфавитом (вкладка «Буква Ё»). В примере без этого вместо ЁЖЕЛ выходит ЕЖЁЛ.
    • Латинские буквы вместо русских. О и O, А и A, Е и E выглядят одинаково, но 'О' == 'O' — это False: программа ничего не найдёт или даст неверный ответ. Буквы условия набирайте в русской раскладке, а не копируйте: на Решу ЕГЭ так набраны условия минимум четырёх задач №8 (латинские M, A, C, T в списке букв, латинская T в «ровно одну букву T»).
    • «Не может начинаться с А и заканчиваться Г» — это два отдельных запрета: w[0] != 'А' and w[-1] != 'Г'. Запись not (w[0] == 'А' and w[-1] == 'Г') запрещает только оба сразу: в 4-буквенных словах из А, Б, В, Г получится 240 вместо 144. Так понимают эту формулировку во всех задачах Решу ЕГЭ, где она встречается.
    • Номер только у кодов из списка. «Коды, где В ровно одна, записаны по алфавиту и пронумерованы» — номер есть только у таких кодов; enumerate по всем словам даст номер больше нужного.
    • count не считает пересекающиеся вхождения: 'АААА'.count('АА') = 2, хотя пар «АА» там три. Для «нет АА» ('АА' not in w) это неважно, а для «ровно одно сочетание АА» — ошибка.
    • Буквы не отсортированы. product('АКЦЕНТ', …) перебирает слова не в алфавитном порядке — номера будут неверными. Всегда sorted(…), когда спрашивают номер. Если в условии обратный алфавитный порядок — sorted(…, reverse=True).
    • Номер с нуля. enumerate(…) без 1 начинает с 0 — ответ на 1 меньше.
    • Номер растёт только у подходящих слов. Номер — у каждого слова списка; поэтому enumerate, а не count += 1 внутри if. Номер (i) и количество (count) — разные переменные.
    • Сравнение кортежа со строкой. product выдаёт кортеж ('Н', 'А', …); без ''.join(w) проверка 'КК' in w всегда ложна.
    • Повторы при перестановке слова с одинаковыми буквами — без set слова посчитаются по несколько раз (КАРЕТА, 4 буквы без АА: 288 вместо 156).
    • Чередование через replace (чётные → 0, нечётные → 1) делайте после проверки w[0] != '0', иначе после замены уже не понять, был ли ноль первым.
    • Печать всех слов в IDLE. Перебор 10 млн слов идёт около 2 секунд, но print каждого слова повесит среду. Печатайте только ответ.
    • «Ровно две» и «не менее двух» — разные условия (== и >=).
