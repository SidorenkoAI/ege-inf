    №19–21. Теория игр¶

    Python можно вручную можно в таблице ~5 + 7 + 10 мин 3 балла (по 1) без файла

    Коротко

    Одна функция f(s, m) — «за m ходов игра кончится победой нужного игрока». Конец игры → m % 2 == 0; ходы кончились → False; ходит победитель — any, соперник — all. Вызовы: №19 f(s, 2), №20 f(s, 3) and not f(s, 1), №21 f(s, 4) and not f(s, 2).

    Как узнать задачу¶

    • «Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежит куча камней (лежат две кучи)… Игроки ходят по очереди, первый ход делает Петя».
    • «Игра завершается в тот момент, когда количество камней в куче становится не менее …».
    • Три вопроса к одной игре: №19 — «Ваня выигрывает первым ходом», №20 — «Петя не может выиграть за один ход, но может вторым», №21 — «Ваня выигрывает первым или вторым ходом, но не может гарантированно первым».

    Шаблон¶

    # №19–21 (шаблон): в куче S камней, ход — добавить 1 или 3 камня или удвоить кучу; игра кончается,
# когда в куче не менее 45 камней; 1 <= S <= 44. №19: при любом ходе Пети Ваня выигрывает первым ходом;
# №20: Петя не может выиграть первым ходом, но выигрывает вторым при любой игре Вани;
# №21: Ваня выигрывает первым или вторым ходом при любой игре Пети, но не может гарантированно первым.
# Ответ: [22]
# Ответ: [11, 19, 21]
# Ответ: [18, 20]
from functools import lru_cache


@lru_cache(None)
def f(s, m):                     # s — камней в куче, m — сколько ходов ещё осталось в игре
    if s >= 45:                  # игра окончена:
        return m % 2 == 0        # последний ход сделал тот, кто должен выиграть, — если m чётное
    if m == 0:                   # ходы кончились, а игра — нет
        return False
    h = [f(s + 1, m - 1), f(s + 3, m - 1), f(s * 2, m - 1)]      # все ходы из условия
    return any(h) if m % 2 == 1 else all(h)    # ходит победитель — хватит одного хода; соперник — все


print([s for s in range(1, 45) if f(s, 2)])                      # №19: игра из 2 ходов
print([s for s in range(1, 45) if f(s, 3) and not f(s, 1)])      # №20: за 3 хода, но не за 1
print([s for s in range(1, 45) if f(s, 4) and not f(s, 2)])      # №21: за 4 хода, но не гарантированно за 2

    Как это работает. m — сколько ходов осталось сделать. Игрок, который должен выиграть по вопросу, ходит, когда m нечётное (в №19 при m = 1 ходит Ваня), соперник — когда чётное. Если игра кончилась при чётном m — последний ход сделал нужный игрок. Победителю хватает одного хорошего хода (any), а соперник может сходить как угодно — выигрыш должен получаться при всех его ходах (all).

    Вопрос Ходов в игре Вызов
    №19: Ваня выигрывает первым ходом (при любом ходе Пети) Петя, Ваня — 2 f(s, 2)
    №20: Петя не может выиграть первым ходом, но выигрывает вторым при любой игре Вани 3, но не 1 f(s, 3) and not f(s, 1)
    №21: Ваня выигрывает первым или вторым ходом, но не может гарантированно первым 4, но не 2 f(s, 4) and not f(s, 2)

    Что менять под задачу:

    В условии В шаблоне
    «игра завершается, когда камней не менее 45» if s >= 45: — знак как в условии: «более 45» — s > 45, «не более 20» — s <= 20
    ходы список h — по одному f(…, m - 1) на ход: f(s + 4, m - 1), f(s * 3, m - 1), f(s // 2, m - 1)
    «1 ≤ S ≤ 44» range(1, 45) — правая граница на 1 больше
    «наименьшее», «два наименьших», «наибольшее», «сколько», «сумма» min(…), […][:2], max(…), len(…), sum(…) — или прочитать по списку
    две кучи f(x, y, m), ходы для каждой кучи, конец — по сумме (пример ниже)
    «неудачный ход Пети» (только №19) в последней строке all → any (см. «Разновидности»)

    Что не трогать: return m % 2 == 0, if m == 0: return False, any(h) if m % 2 == 1 else all(h) и m в трёх вызовах — они одинаковы во всех задачах. @lru_cache(None) ускоряет перебор (как в №16).

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, пересказ). Две кучи камней: в первой 17, во второй S (1 ≤ S ≤ 115). За ход можно добавить в одну из куч 4 камня или увеличить одну из куч вдвое. Игра кончается, когда в двух кучах вместе не менее 133 камней. №19: известно, что Ваня выиграл своим первым ходом; наименьшее S. №20: два наименьших S, при которых Петя не может выиграть первым ходом, но выигрывает вторым при любой игре Вани. №21: наименьшее S, при котором Ваня выигрывает первым или вторым ходом при любой игре Пети, но не может гарантированно первым.

    Решение.

    Условие Код
    две кучи: 17 и S позиция — два числа: f(x, y, m), вызов f(17, s, …)
    в двух кучах вместе не менее 133 if x + y >= 133:
    +4 или ×2 в одну из куч четыре хода: f(x + 4, y, m - 1), f(x * 2, y, m - 1), f(x, y + 4, m - 1), f(x, y * 2, m - 1)
    №19: «Ваня выиграл» — не сказано «при любом ходе Пети» Петя мог сходить неудачно: копия g, где всегда any
    1 ≤ S ≤ 115 range(1, 116) 
    # №19–21, демоверсия ЕГЭ-2027: две кучи — 17 и S камней; ход — добавить 4 камня в одну из куч или удвоить
# одну из куч; игра кончается, когда в двух кучах вместе не менее 133 камней; 1 <= S <= 115.
# №19: Ваня выиграл своим первым ходом (Петя мог сходить неудачно) — наименьшее S;
# №20: два наименьших S — Петя не может выиграть первым ходом, но выигрывает вторым при любой игре Вани;
# №21: наименьшее S — Ваня выигрывает первым или вторым ходом при любой игре Пети, но не гарантированно первым.
# Ответ: 29
# Ответ: [28, 48]
# Ответ: 44
from functools import lru_cache


@lru_cache(None)
def f(x, y, m):                  # две кучи — два числа в позиции
    if x + y >= 133:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(x + 4, y, m - 1), f(x * 2, y, m - 1), f(x, y + 4, m - 1), f(x, y * 2, m - 1)]
    return any(h) if m % 2 == 1 else all(h)


@lru_cache(None)
def g(x, y, m):                  # для №19: копия f, где и соперник ходит any — «неудачный ход»
    if x + y >= 133:
        return m % 2 == 0
    if m == 0:
        return False
    h = [g(x + 4, y, m - 1), g(x * 2, y, m - 1), g(x, y + 4, m - 1), g(x, y * 2, m - 1)]
    return any(h)


print(min(s for s in range(1, 116) if g(17, s, 2)))
print([s for s in range(1, 116) if f(17, s, 3) and not f(17, s, 1)][:2])
print(min(s for s in range(1, 116) if f(17, s, 4) and not f(17, s, 2)))

    Ответ: 29; 28 48; 44.

    Проверка вручную: №19 при S = 29

    Позиция (17, 29). Петя может получить (21, 29), (34, 29), (17, 33) или (17, 58). Из (17, 58) Ваня удваивает вторую кучу: 17 + 116 = 133 — выигрыш. При S = 28 самый сильный ход Пети — (17, 56), и Ваня получит не больше 17 + 112 = 129 < 133, а после других ходов Пети — ещё меньше. Значит, 29 — наименьшее.

    Разновидности¶

    Условие Как записать
    «Ваня выиграл первым ходом после неудачного хода Пети» / «Ваня выиграл своим первым ходом» (демо-2027) только для №19: в последней строке all → any (у Пети тоже «хотя бы один ход»); для №20 и №21 — вернуть all (пример выше — функция g)
    «при любом ходе Пети Ваня может выиграть первым ходом» шаблон, f(s, 2); «Петя не может выиграть за один ход» проверять не нужно — all уже это учитывает
    куча уменьшается («убрать 3 камня», «уменьшить в 3 раза») конец s <= …, ходы s - 3, s // 3; перебор S — с запасом (вкладка «Куча уменьшается»)
    «уменьшить вдвое, если нечётно — остаётся на 1 больше» (s + 1) // 2 — округление вверх
    две кучи, конец по сумме f(x, y, m), x + y >= … (пример выше)
    конец по произведению куч / «в одной из куч не менее 48» x * y >= … / max(x, y) >= 48
    «окно»: игра кончается при x · y ≥ 70, но если вышло больше 110 — выиграл соперник if x * y >= 70: return (m % 2 == 0) == (x * y <= 110)
    две кучи уменьшаются («убрать 3 из одной из куч», «в 3 раза»), конец — сумма ≤ 53 перебор S — с нижней границы условия, не с 54 (см. «Типичные ошибки»)
    «добавить столько камней, сколько в другой куче» ходы f(x + y, y, m - 1) и f(x, y + x, m - 1)
    ×2 только в первую кучу, ×3 — только во вторую ходы выписать как в условии: f(x * 2, y, m - 1), f(x, y * 3, m - 1)
    «добавить в меньшую кучу», «в большую +1…3 или удвоить меньшую» ходы собрать с if x <= y: / else: (при равных кучах — в любую)
    ход с условием: «×2, если нечётно», «добавить n/k, если n делится на k», «нельзя получить число, кратное 3» h собирать с if или списком [… for k in … if s % k == 0] (вкладка «Ход с условием»)
    «нельзя повторять ход, который только что сделал соперник» / «свой предыдущий ход» в позицию добавить последний ход: f(s, last, m) (вкладка)
    «Петя выигрывает третьим ходом, но не первым и не вторым» f(s, 5) and not f(s, 3)
    «Ваня выигрывает вторым или третьим ходом, но не гарантированно вторым» f(s, 6) and not f(s, 4)
    «у Вани есть стратегия при любой игре Пети» — без номера хода f(s, 60) — ходов заведомо хватит (кэш обязателен: без него 2⁶⁰ вызовов)
    «Петя мог выиграть первым ходом, но Ваня выиграл после его неудачного хода» f(s, 1) и g(s, 2) (g — с any)
    конец «ровно 1 камень» / «ровно 42 камня», ходы «в сторону 42» if s == 42:; ходы [s + 1, s + 3, s + 7] if s < 42 else [s - 1, s - 3, s - 7]
    «наименьшее суммарное число камней в двух кучах, если Петя выиграл первым ходом» (S нет) перебор пар: min(a + b for a in … for b in … if not конец and any(конец после хода)) — «не меньше одного камня в каждой» — с 1
    три кучи; три игрока позиция из трёх чисел; кто ходит — ход % 3 (на ЕГЭ пока не было)
    вопрос «сумма / количество значений», «пять значений», «наименьшее и наибольшее» всё по списку S из того же вызова 
    # №19–21: в куче S камней, ход — убрать 3 или 7 камней или уменьшить кучу в 3 раза (с округлением вниз);
# игра кончается, когда в куче не более 120 камней; S > 120.
# №19: Ваня выиграл первым ходом после неудачного хода Пети — наибольшее S;
# №20: два наименьших S (Петя не может первым, но выигрывает вторым ходом); №21: наибольшее S.
# Ответ: 1088
# Ответ: [366, 367]
# Ответ: 1100
from functools import lru_cache

TOP = 121 * 3 ** 4               # за 4 хода куча уменьшится не больше чем в 3**4 = 81 раз: дальше ответов нет


@lru_cache(None)
def f(s, m):
    if s <= 120:                 # куча убывает — конец игры «не более»
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s - 3, m - 1), f(s - 7, m - 1), f(s // 3, m - 1)]
    return any(h) if m % 2 == 1 else all(h)


@lru_cache(None)
def g(s, m):                     # для №19 («неудачный ход»): всегда any
    if s <= 120:
        return m % 2 == 0
    if m == 0:
        return False
    return any([g(s - 3, m - 1), g(s - 7, m - 1), g(s // 3, m - 1)])


print(max(s for s in range(121, TOP) if g(s, 2)))
print([s for s in range(121, TOP) if f(s, 3) and not f(s, 1)][:2])
print(max(s for s in range(121, TOP) if f(s, 4) and not f(s, 2)))

    Верхней границы S в условии нет. За 4 хода куча уменьшается не больше чем в 3⁴ = 81 раз (самый сильный ход — «в 3 раза»), поэтому с S ≥ 121 · 81 до 120 не дойти — дальше ответов нет. «Перебор до 1000» здесь даёт неверные ответы на №19 и №21: настоящие — 1088 и 1100. Для «неудачного хода» в убывающей игре обычно спрашивают наибольшее S.

    # №19: в куче n камней; если n делится на k (k > 1), можно добавить в кучу n / k камней (из 12 — добавить 6, 4,
# 3, 2 или 1 камень). Игра кончается, когда в куче больше 60 камней; S <= 60. Сколько существует S, при которых
# Петя не может выиграть первым ходом, но при любом ходе Пети Ваня выигрывает первым ходом?
# Ответ: 7
from functools import lru_cache


@lru_cache(None)
def f(s, m):
    if s > 60:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s + s // k, m - 1) for k in range(2, s + 1) if s % k == 0]     # ходы — только разрешённые
    return any(h) if m % 2 == 1 else all(h)


print(len([s for s in range(2, 61) if f(s, 2)]))     # с 2: при S = 1 ходов нет, а all([]) == True

    При S = 1 у Пети нет ни одного хода, список h пуст, а all([]) в Python — True: шаблон засчитает S = 1, и вместо 7 выйдет 8. Проверьте, есть ли позиции без ходов, и уберите их из перебора.

    # №19–21: в куче S камней, ход — добавить 1 или 2 камня или удвоить кучу, но нельзя повторять ход, который
# только что сделал соперник. Игра кончается, когда в куче не менее 40 камней; 1 <= S <= 39.
# №19: при любом ходе Пети Ваня выигрывает первым ходом; №20: наименьшее и наибольшее S;
# №21: Ваня выигрывает первым или вторым ходом, но не гарантированно первым.
# Ответ: [19]
# Ответ: [10, 18]
# Ответ: [9]
from functools import lru_cache


@lru_cache(None)
def f(s, last, m):               # last — каким ходом (1, 2, 3) только что ходил соперник; 0 — ходов не было
    if s >= 40:
        return m % 2 == 0
    if m == 0:
        return False
    h = []
    if last != 1:
        h.append(f(s + 1, 1, m - 1))
    if last != 2:
        h.append(f(s + 2, 2, m - 1))
    if last != 3:
        h.append(f(s * 2, 3, m - 1))
    return any(h) if m % 2 == 1 else all(h)


print([s for s in range(1, 40) if f(s, 0, 2)])
v = [s for s in range(1, 40) if f(s, 0, 3) and not f(s, 0, 1)]
print([v[0], v[-1]])
print([s for s in range(1, 40) if f(s, 0, 4) and not f(s, 0, 2)])
    Подробнее: без программы — выигрышные и проигрышные позиции

    Так решают вручную (и так же устроены все программы). Для одной кучи «+1 или ×2, не менее 129» идём от порога вниз:

    Позиция Что значит Пример
    В1 — выигрыш за 1 ход есть ход, после которого игра окончена 65…128 (65 · 2 = 130)
    П1 — проигрыш за 1 ход все ходы ведут в В1 — ответ №19 64 → 65 или 128
    В2 — выигрыш за 2 хода не В1 и есть ход в П1 («подложить» сопернику П1) — ответ №20 32 и 63 (→ 64)
    П12 — проигрыш за 1–2 хода не П1, и все ходы ведут в В1 или В2 — ответ №21 62 → 63 (В2) или 124 (В1)
    «неудачный ход» (№19) есть ход в В1 33…128

    В таблице то же самое считается формулами: строка — позиция (в столбце A числа 1, 2, 3, …, тогда ИНДЕКС(B$2:B$89; A2*2) — значение для позиции после хода ×2). Столбец «Конец» =A2>=45, «В1» =ЕСЛИ(B2;ЛОЖЬ();ИЛИ(ИНДЕКС(B$2:B$89;A2+1);ИНДЕКС(B$2:B$89;A2+3);ИНДЕКС(B$2:B$89;A2*2))), «П1» — то же с И по столбцу В1, и так далее; формулы протянуть вниз, ответы — строки со значением ИСТИНА. Готовый лист для игры из шаблона: 19-21-pozicii.ods (проверен в LibreOffice: совпал с программой на 20 играх). Для двух куч позиций слишком много — там программа. Некоторые решают в Excel «деревом» (старт → ходы Пети → самый сильный ход Вани, условное форматирование «больше 128») и подбирают S руками — это дольше и легче ошибиться.

    Типичные ошибки¶

    Скрытые ловушки — проверены на 241 задаче Решу ЕГЭ

    • «Неудачный ход» без any. «Ваня выиграл первым ходом после неудачного хода Пети» — у Пети тоже any. С all неверны все 47 таких задач сайта. И наоборот: «при любом ходе Пети» с any — неверны все 28.
    • Не вернули all после №19. Если any осталось, №20 и №21 неверны в 159 задачах из 161. Удобнее держать для №19 отдельную копию функции (как g в примере).
    • Забыли not f(s, 1) в №20 или not f(s, 2) в №21. В список попадают S, где выигрывают раньше: неверно 28 ответов №20 из 80 и 24 ответа №21 из 81. В шаблоне выше без not в список №21 попадает 22 — ответ №19: на вопрос «наибольшее» вышло бы 22 вместо 20.
    • Убывающая куча, «перебор до 1000». Ответ бывает больше: в 20 задачах сайта из 51 «до 1000» даёт неверный ответ (до 60 025 и 78 019 в задачах с порогом 20 007 и 26 005). Граница — порог × (самое сильное деление)⁴.
    • Две убывающие кучи: перебор S с «порог + 1». В первой куче уже есть камни — сумма больше порога и при меньших S. Резерв ЕГЭ 22.06.2026 (19 камней и S, конец — сумма ≤ 53, S ≥ 35): перебор с 54 даёт в №19 ответ 54 вместо 38; пересдача 08.07.2026 — 48 вместо 34. Начинать с нижней границы S из условия: range(35, 54 * 3 ** 4).
    • Позиция без ходов («добавить n/k» при n = 1): all([]) — True, лишнее S в ответе (Решу 68252: 7 вместо 6).
    • «Не меньше одного камня в каждой куче» в задаче без S: перебор с нуля даёт 45 вместо 46 (Решу 58486).
    • Конец игры проверяют после if m == 0. Тогда победа последним ходом не засчитывается — пустые списки.
    • Знак конца игры. «Не менее 45» — >= 45, «превышает 45», «более 45» — > 45; «не более 20» — <= 20.
    • Граница range. «1 ≤ S ≤ 44» — range(1, 45); S, при которых игра уже окончена, в перебор не включать.
    • Две кучи: ход только в одну. «Добавить в одну из куч» — четыре хода, а не «в обе сразу».
    • Деление. «Уменьшить в 3 раза с округлением вниз» — s // 3; / даёт дробные кучи.
    • Ответ «два значения». Записывать в порядке возрастания; если в списке больше двух, читать вопрос: два наименьших, наименьшее и наибольшее…
