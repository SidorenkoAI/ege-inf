    №14. Системы счисления¶

    Python ~3 мин 1 балл без файла

    Коротко

    Две функции на все случаи: cifry(n, b) — число → список цифр-чисел в системе b (цифра 24 — это одно число 24, а не «2» и «4»); chislo([2, 7, x, 9], b) — список цифр → число. Считаем цифры — c.count(0), sum([d for d in c if d > 9]). Неизвестное (x, y, основание p) — перебор: наименьшее — первое и break, наибольшее — последнее. Работает при любом основании, даже больше 36.

    Как узнать задачу¶

    • «Значение арифметического выражения 3·3125⁸ + 2·625⁷ − … записали в системе счисления с основанием 25. Сколько значащих нулей…» — посчитать цифры записи.
    • «Операнды записаны в системе с основанием 22: 27x98876₂₂ + 26x51₂₂ + …; x — неизвестная цифра. Наименьшее x, при котором значение кратно 21; в ответ — частное».
    • «7¹⁷⁰ + 7¹⁰⁰ − x, где x — целое положительное, не больше 2030… наибольшее x, при котором в записи ровно 71 нуль».
    • В демоверсии 2027 — все три примера; на экзамене будет один из них. Бывают и неизвестное основание p («в системе с основанием p верно равенство…»), и две системы в одном выражении.

    Шаблон¶

    # №14 (демоверсия ЕГЭ-2027, пример 2): значение выражения 3·3125⁸ + 2·625⁷ − 4·625⁶ + 3·125⁵ − 2·25⁴ − 2025

def cifry(n, b):                        # число n → список его цифр в системе с основанием b

        n //= b
    return c[::-1]                      # старшая цифра — первой


def chislo(c, b):                       # список цифр в системе b → число
    n = 0
    for d in c:
        n = n * b + d                   # приписать цифру справа
    return n

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, пример 1, пересказ). Операнды записаны в системе с основанием 22: 27x98876₂₂ + 26x51₂₂ + 711x5₂₂, x — неизвестная цифра. Найдите наименьшее x, при котором значение выражения кратно 21, и для него — частное от деления значения на 21 (в десятичной системе).

    Решение.

    Условие Код
    x — цифра 22-ричной системы for x in range(22):
    три числа с цифрой x chislo([2, 7, x, 9, 8, 8, 7, 6], 22) + …
    кратно 21 if n % 21 == 0:
    частное; наименьшее x — первое print(x, n // 21), break 
    # №14 (демоверсия ЕГЭ-2027, пример 1): 27x98876₂₂ + 26x51₂₂ + 711x5₂₂, x — неизвестная цифра 22-ричной системы.

# Ответ: 3 276296118
def cifry(n, b):                        # число n → список его цифр в системе с основанием b
    c = []
    while n > 0:
        c.append(n % b)                 # остаток — младшая цифра (числом: 10, 24…)
        n //= b
    return c[::-1]                      # старшая цифра — первой


def chislo(c, b):                       # список цифр в системе b → число
    n = 0
    for d in c:
        n = n * b + d                   # приписать цифру справа

for x in range(22):                     # x — цифра: 0…21
    n = chislo([2, 7, x, 9, 8, 8, 7, 6], 22) + chislo([2, 6, x, 5, 1], 22) + chislo([7, 1, 1, x, 5], 22)

    Программа печатает 3 276296118: x = 3, в ответ — частное. Ответ: 276296118.

    Проверка: другим способом

    Для оснований до 36 работает и встроенный int(строка, b) — но цифру x нужно подставлять символом алфавита: D = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ', int(f'27{D[x]}98876', 22). Получается то же: подходят x = 3, A (10) и H (17), наименьшее — 3, частное 276296118.

    Подробнее: вручную — запись степеней

    Так решают задачи, где перебор невозможен (огромный x), и так проверяют ответ программы.

    1. bⁿ в системе b — единица и n нулей: 7¹⁷⁰ = 1 0…0 (170 нулей).
    2. Сумма степеней — единицы на своих местах: 7¹⁷⁰ + 7¹⁰⁰ — единица, 69 нулей, единица, 100 нулей.
    3. Разность bⁿ − bᵐ — (n − m) цифр «b − 1», потом m нулей: 5³⁶ − 5²⁴ = 12 четвёрок и 24 нуля.
    4. Коэффициент — сначала перевести в систему b: 16 · 5⁵⁰ — это «31» и 50 нулей (16 = 31₅).
    5. Вычитание маленького числа (−2025) меняет только младшие цифры: перевести 2025 и вычесть «столбиком» с заёмом.
    6. Основание — степень другого: 4²⁰ = 16¹⁰, 2 · 4²³ = 8 · 16¹¹ — сразу видно цифры 16-ричной записи.

    Для оснований до 36 есть и встроенный способ: int(строка, b) и алфавит D[x] (см. «Проверка» в примере).

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • x в f-строке числом. int(f'98{x}79641', 19) при x = 10 вставляет две цифры «1» и «0» — число молча другое. На задачах Решу ЕГЭ с цифрой x так ошибаются 6 из 14 (все «наибольшее x»: 59692, 70078, 84708, 81816, 84676, 92191). Цифра — символом D[x] или списком chislo.
    • Цифры строкой str(n % b) при b > 10. Цифра 10 становится «10» — лишний «0»; на случайных 20-значных 25-ричных числах count('0') ошибается в 822 случаях из 1000. На задачах Решу (25 и 16) случайно угадывает — тем опаснее.
    • int(s, b) — только до 36. На Решу есть основания 37, 39, 40, 47 — ValueError.
    • bin(n).count('0') — на 1 больше: ноль из префикса 0b (Решу 92256: 72 вместо 71). То же hex, oct.
    • print(n) и str(n) огромного числа — ошибка в Python 3.11+: больше 4300 десятичных цифр (5 · 7776²⁰¹³ — около 7800) — ValueError: Exceeds the limit (4300 digits). В версиях до осени 2022 года ограничения не было. Функция cifry строк не строит — ей ограничение не мешает.
    • Первая цифра — не ноль. В уравнениях с основанием p (Решу 76682, 76711) с нулём в старшем разряде находятся десятки «решений»; число yx в 63030 с y = 0 — «квадрат» 0.
    • / вместо // при частном: на больших числах — потеря цифр или OverflowError.
    • Не тот диапазон x: «положительное» — с 1; «не превышает 2030» — range(1, 2031); цифра системы b — range(b), а не range(b + 1); в двух системах — до меньшего основания.
    • Наименьшее — break на первом; наибольшее — последнее (или перебор сверху вниз и break).
    • В ответ — частное (или значение), а не x. Программа печатает x для себя.
    • Опечатка при переписывании выражения (6**10 вместо 6**100) — ошибки нет, ответ неверный. Перепишите выражение второй раз и сравните.
    • Буквы-цифры: E = 14, а не I; G = 16, H = 17.
    • Счётчик внутри перебора — заново для каждого x (cifry(…).count(…) делает это сам).
