    №17. Последовательность чисел из файла¶

    Python ~13 мин 1 балл файл .txt

    Коротко

    Числа — в список a; вспомогательное число (минимум, «максимальный, оканчивающийся на 25») — до цикла; for i in range(len(a) - 1) по парам a[i], a[i + 1]; суммы подходящих — в список s; ответ len(s), max(s).

    Как узнать задачу¶

    • «В файле содержится последовательность целых чисел… Определите количество пар (троек) последовательности, в которых…».
    • «Под парой подразумевается два идущих подряд элемента последовательности».
    • В ответе два числа: количество и максимальная (минимальная) сумма.

    Шаблон¶

    # №17, демоверсия ЕГЭ-2027 (файл 17.txt): пары соседних чисел, в которых остаток от деления
# на 33 хотя бы одного из элементов равен минимальному элементу последовательности.
# В ответе — количество таких пар и максимальная из их сумм.
# Ответ: 622 174933
a = [int(x) for x in open('17.txt')]       # все числа файла — в список

m = min(a)                                 # вспомогательное число — ДО цикла, один раз
s = []                                     # суммы подходящих пар
for i in range(len(a) - 1):                # пара: a[i] и a[i + 1]; до len(a) - 1!
    if a[i] % 33 == m or a[i + 1] % 33 == m:     # «хотя бы один» — это or
        s.append(a[i] + a[i + 1])
print(len(s), max(s))                      # количество пар = количество сумм

    Что менять под задачу:

    В условии В шаблоне
    имя файла open('17.txt') — файл лежит в одной папке с программой
    «минимальный элемент», «минимальный положительный, кратный 35» строка перед циклом: min(x for x in a if x > 0 and x % 35 == 0)
    пары range(len(a) - 1), элементы a[i], a[i + 1]
    тройки range(len(a) - 2), тройка a[i:i + 3]
    «хотя бы один» or
    «оба», «все» and
    «ровно один», «ровно два из трёх», «не более двух» сумма условий: (усл1) + (усл2) + (усл3) == 2 (True = 1)
    что спрашивают вторым числом max(s) / min(s); в s кладём то, что просят (сумму, произведение)

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, файл 17.txt из архива ФИПИ). Натуральные числа до 100 000. Найдите количество пар соседних чисел, в которых остаток от деления на 33 хотя бы одного из элементов равен минимальному элементу последовательности, и максимальную из сумм таких пар.

    Решение — шаблон выше:

    Условие Код
    минимальный элемент последовательности m = min(a) — один раз, до цикла
    пара соседних a[i], a[i + 1], i до len(a) - 1
    остаток от деления на 33 хотя бы одного равен m a[i] % 33 == m or a[i + 1] % 33 == m
    количество и максимальная сумма суммы в список s; len(s), max(s)

    Программа печатает 622 174933. Ответ: 622 174933 (два числа — в две ячейки бланка).

    Разновидности¶

    Условие Как записать
    минимальный / максимальный элемент m = min(a) до цикла
    «минимальный положительный, кратный 35» min(x for x in a if x > 0 and x % 35 == 0)
    «максимальный, оканчивающийся на 25» (есть отрицательные) max(x for x in a if abs(x) % 100 == 25)
    «трёхзначный» (есть отрицательные) 100 <= abs(x) <= 999
    «сумма всех отрицательных», «количество кратных 32» sum(x for x in a if x < 0), len([x for x in a if x % 32 == 0])
    «элементы не равны, модуль разности кратен …» a[i] != a[i + 1] and abs(a[i] - a[i + 1]) % k == 0
    «хотя бы одно отрицательное» a[i] < 0 or a[i + 1] < 0
    тройки, «ровно два из трёх трёхзначные» сумма условий (вкладка)
    «среднее арифметическое тройки меньше …» sum(t) / 3 — обычное деление, не //
    «произведение максимального и минимального в тройке» max(t) * min(t); в список — его, ответ min(s) или max(s)
    «все числа тройки одного знака» all(x > 0 for x in t) or all(x < 0 for x in t)
    «квадрат суммы не больше квадрата …» так и писать: (a[i] + a[i + 1]) ** 2 <= m ** 2 — не «упрощать»
    «абсолютное значение максимальной суммы» abs(max(s)) — сначала максимум, потом модуль
    ответ — минимальная сумма min(s)
    четвёрки подряд range(len(a) - 3), t = a[i:i + 4]
    «среднее арифметическое всех чётных элементов» до цикла: ev = [x for x in a if x % 2 == 0], sr = sum(ev) / len(ev)
    «один делится на 3, а другой меньше среднего» оба случая: (x % 3 == 0 and y < sr) or (y % 3 == 0 and x < sr)
    «остаток от деления на 7 равен остатку максимального элемента» x % 7 == max(a) % 7 (max(a) — до цикла)
    «последняя цифра совпадает с последней цифрой минимального»; «нет таких чисел» x % 10 == mn % 10; «нет» — not any(…)
    «больше чисел, кратных 3, чем кратных 5» сравнить две суммы условий: sum(x % 3 == 0 for x in t) > sum(x % 5 == 0 for x in t)
    «сумма больше M, но меньше удвоенного M» m < sum(t) < 2 * m
    «запись меньшего элемента пары оканчивается на 5» abs(min(x, y)) % 10 == 5 — не «хотя бы одного»
    «последняя цифра одного равна предпоследней другого»; «две последние цифры одинаковы» abs(x) % 10 == abs(y) // 10 % 10 (и наоборот); abs(x) // 10 % 10 == abs(x) % 10
    «сумма двух наибольших чисел тройки» sum(sorted(t)[1:])
    «старшие разряды чисел совпадают» len(set(str(abs(x))[0] for x in t)) == 1
    тройка — стороны остроугольного / прямоугольного треугольника p, q, r = sorted(t), p + q > r, p*p + q*q > r*r (==); нет таких — печатать 0 0
    пара — любые два различных элемента, порядок не важен (старый формат) два цикла for i …: for j in range(i + 1, n) — 50 млн пар, ≈ 15 с 
    # №17 (свой файл chisla.txt, есть отрицательные): тройки подряд идущих чисел, в которых
# ровно два элемента трёхзначные, а сумма тройки не больше максимального элемента
# последовательности, оканчивающегося на 25. Ответ — количество троек и максимальная сумма.
# Ответ: 487 98737
a = [int(x) for x in open('chisla.txt')]

m25 = max(x for x in a if abs(x) % 100 == 25)       # abs: у −125 % 100 будет 75, а не 25
s = []
for i in range(len(a) - 2):                         # тройка: a[i], a[i + 1], a[i + 2]
    t = a[i:i + 3]
    tri = [100 <= abs(x) <= 999 for x in t]         # трёхзначное — по модулю: −512 тоже
    if sum(tri) == 2 and sum(t) <= m25:             # True считается как 1: «ровно два»
        s.append(sum(t))
print(len(s), max(s))

    Файл — свой: скачать chisla.txt (5000 чисел от −99 999 до 99 999), сохранить рядом с программой под именем chisla.txt.

    Подробнее: можно ли в таблице?

    Для пар и троек подряд — можно: числа в столбец A, вспомогательное число — в отдельную ячейку (=МИН(A:A)), в столбце B формула для строки (=ЕСЛИ(ИЛИ(ОСТАТ(A1;33)=$D$1;ОСТАТ(A2;33)=$D$1);A1+A2;"")), потом =СЧЁТ(B:B) и =МАКС(B:B). Но формулы получаются длинными, а у последней строки нет пары — её приходится убирать вручную. Программа короче и надёжнее; таблица — запасной вариант.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Отрицательные числа и %. В Python -17 % 10 = 3, -125 % 100 = 75: «оканчивается на 25» без abs пропустит −125 и захватит −75, −375. Пишите abs(x) % 100 == 25.
    • len(str(x)) считает минус. len(str(-512)) = 4. На нашем файле «ровно два трёхзначных» через len(str(x)) == 3 даёт 460 троек вместо 487; через 100 <= x <= 999 без abs — 197.
    • Минимум внутри цикла. if a[i] % 33 == min(a) пересчитывает минимум на каждом шаге: на демо-файле (10 000 чисел) — 1 с, а на 100 000 чисел — в сто раз дольше. Считайте m = min(a) до цикла.
    • Максимум «на всякий случай» вне if. Если maxi = max(maxi, a[i] + a[i + 1]) стоит не внутри условия, максимум берётся по всем парам: на демо-файле 177 727 вместо 174 933.
    • Счётчик с maxi = 0 при отрицательных суммах. Если все подходящие суммы отрицательные (например, оба числа пары меньше нуля), maxi так и останется 0. Список s и max(s) этой ошибки не дают.
    • «Упростили» квадраты. (a + b)² ≤ M² и a + b ≤ M — разные условия, когда сумма отрицательная: на нашем файле 4927 пар против 4943.
    • abs нужен и в задачах сайта. Мы прогнали 85 задач Решу ЕГЭ. «k-значное» без abs в файлах с отрицательными числами меняет ответ в 6 задачах из 9 (например, 204 тройки вместо 2627), «оканчивается на …» без abs — в 3 из 12. Трёхзначное «начинается с цифры 5» — тоже по модулю: −555 подходит.
    • «Абсолютное значение максимальной суммы» — abs(max(s)). max(abs(…)) на задаче сайта даёт 195 618 вместо 962.
    • Первая строка файла — количество чисел. Так устроены 10 файлов Решу ЕГЭ; ответы сайта получены чтением файла целиком, как в шаблоне (в 9 задачах эта строка ни на что не влияет, в одной меняет ответ на 1). На экзамене внимательно прочитайте условие: если сказано, что первое число — количество, пропустите его (a = a[1:]).
    • range(len(a)) для пар — IndexError: list index out of range: у последнего числа нет пары. Пары — len(a) - 1, тройки — len(a) - 2.
    • ValueError: max() arg is an empty sequence — ни одна пара (или ни одно число для вспомогательного) не подошла: проверьте условие и что открыт нужный файл.
    • ValueError: invalid literal for int() — в конце файла пустая строка. Удалите её в файле или читайте [int(x) for x in open('17.txt') if x.strip()].
    • «Положительный» — строго > 0: ноль не положительный и не «квадрат натурального числа».
    • «Если таких троек нет — выведите 0 0». max([]) падает с ValueError — проверьте if s: перед max.
    • Файл в Блокноте — одной строкой. Некоторые файлы разделяют строки одним символом \r: Блокнот склеивает числа, но Python читает такой файл как обычно.
    • Перепутали порядок в ответе: сначала количество, потом сумма — как в условии.
