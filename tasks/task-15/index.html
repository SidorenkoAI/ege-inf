    №15. Логика: найти параметр A¶

    Python можно вручную ~3 мин 1 балл без файла

    Коротко

    Формулу — в функцию F(x, A) (→ — это <=, ¬ДЕЛ(x, m) — это x % m != 0), затем for A in range(…): if all(F(x, A) for x in range(…)) — подходящие A. Наименьшее — первое, наибольшее — последнее.

    Как узнать задачу¶

    • «Для какого наименьшего / наибольшего натурального (целого неотрицательного) числа A выражение … тождественно истинно (принимает значение 1 при любом …)?»
    • В формуле есть ДЕЛ(x, A), поразрядная конъюнкция x & A, неравенства с x и y или отрезки на числовой прямой.

    Шаблон¶

    # №15, демоверсия ЕГЭ-2027: ДЕЛ(x, A) ∨ ((x ∈ B) → ¬ДЕЛ(x, 22)), B = [70; 90].
# Наибольшее натуральное A, при котором выражение истинно при любом целом x > 0.
# Ответ: 88
def F(x, A):
    B = 70 <= x <= 90                          # x ∈ [70; 90]
    return (x % A == 0) or (B <= (x % 22 != 0))     # ДЕЛ(x, A) — это x % A == 0; «→» — это <=


for A in range(1, 1000):                       # перебираем A
    if all(F(x, A) for x in range(1, 10000)):  # истинно при ВСЕХ x из большого диапазона
        otvet = A                              # наибольшее — последнее подходящее
print(otvet)

    Что менять под задачу:

    В условии В Python
    ДЕЛ(x, m) — «делится» x % m == 0
    ¬ДЕЛ(x, m) — «не делится» x % m != 0 — без not (см. «Типичные ошибки»)
    → (следование) <= — обе части в скобках
    ∨, ∧, ¬, ≡ or, and, not ( … ), ==
    x ∈ [70; 90] 70 <= x <= 90
    x & m (поразрядная конъюнкция) (x & m) — всегда в скобках
    «наибольшее A» запоминаем последнее подходящее (otvet = A)
    «наименьшее A» print(A) и break — первое подходящее
    «натуральное», «положительное» range(1, …); «неотрицательное» — range(0, …)

    Диапазон x берите с большим запасом: если в формуле числа до 100 — x до 10 000. Проверка: увеличьте диапазон в 10 раз — ответ не должен измениться. Для поразрядной конъюнкции & — x и A до степени двойки больше всех чисел условия: при 20777 — до 2 ** 15 (= 32 768).

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027). ДЕЛ(n, m) — «n делится без остатка на m»; B = [70; 90]. Для какого наибольшего натурального A выражение ДЕЛ(x, A) ∨ ((x ∈ B) → ¬ДЕЛ(x, 22)) истинно при любом целом положительном x?

    Решение — шаблон выше:

    Условие Код
    ДЕЛ(x, A) x % A == 0
    x ∈ B B = 70 <= x <= 90
    (x ∈ B) → ¬ДЕЛ(x, 22) B <= (x % 22 != 0)
    ∨ or
    наибольшее A otvet = A в цикле, print(otvet) после

    Программа печатает 88. Ответ: 88.

    Проверка вручную

    Правая часть ложна, только когда x ∈ [70; 90] и x делится на 22 — это единственное x = 88. Значит, при x = 88 обязана быть истинна левая часть: 88 делится на A. Наибольшее такое A — само 88.

    Разновидности¶

    Условие Как записать
    ДЕЛ(x, A), ДЕЛ(x, m) шаблон
    ДЕЛ и отрезок (x ∈ B) — демо-2027 шаблон: B = 70 <= x <= 90
    ДЕЛ и неравенство «x + A ≥ 80» прямо в формулу: (x + A >= 80)
    поразрядная конъюнкция x & A шаблон, каждое (x & m) в скобках, x от 0 (вкладка)
    две переменные x, y (неравенства, «x · y > A») all(F(x, y, A) for x in range(…) for y in range(…)) (вкладка)
    «тождественно ложно» all(not F(x, A) for x in …)
    «при каком A найдутся x и y, что выражение ложно» any(not F(x, y, A) for …) вместо all
    «сколько существует целых A» счётчик count += 1 вместо print; A — и отрицательные: range(-1000, 1000)
    x, y — «любые целые» (не только неотрицательные) range(-200, 200)
    A под знаком ДЕЛ: ДЕЛ(90, A), ДЕЛ(A, 45), ДЕЛ(750, x) делимое — первым: 90 % A == 0, A % 45 == 0, 750 % x == 0
    условие на само A: «(A < 50) ∧ …» просто часть формулы: (A < 50) and (…)
    числа в условии большие (сотни, тысячи) и x, и A перебирать дальше этих чисел (см. «Типичные ошибки»)
    числа — десятки тысяч и две переменные («89 241 < 5y + x») перебор пар не дождаться — для каждого y берём только самое опасное x = 89241 − 5y
    гибрид: «(x + 40 < A) ∨ (x + A < 40) → ДЕЛ(x, A)» шаблон — A по-прежнему число
    ТРЕУГ(n, m, k) — «есть треугольник со сторонами», МАКС своя функция: n < m + k and m < n + k and k < n + m; max(x, 5)
    отрезки: найти наименьшую / наибольшую длину отрезка A перебор концов A по «граничным точкам» (вкладка)
    отрезки: «формулы тождественно равны», «обе формулы истинны» в F — (формула1) == (формула2), (…) and (…)
    отрезки: «наименьшее количество целых точек в A» вместо длины — math.floor(a2) - math.ceil(a1) + 1 (длина + 1)
    отрезок A и x² ≤ 100 (x вещественное) x² ≤ 100 — это [−10; 10]: границы ±10 — в точки перебора
    множество A: наименьшее количество элементов список x, при которых формула без A ложна (как способ «список»), — len(A)
    множества A, P, Q (произведение элементов и т. п.) вручную: какие x делают формулу ложной без A 
    # №15: x & y — поразрядная конъюнкция. Наименьшее натуральное A, при котором
# ((x & 28 ≠ 0) ∨ (x & 45 ≠ 0)) → ((x & 17 = 0) → (x & A ≠ 0)) истинно при любом целом x ≥ 0.
# Ответ: 44
def F(x, A):
    return (((x & 28) != 0) or ((x & 45) != 0)) <= (((x & 17) == 0) <= ((x & A) != 0))


for A in range(1, 1000):
    if all(F(x, A) for x in range(0, 10000)):  # x ≥ 0 — перебор с нуля
        print(A)                               # наименьшее — первое подходящее
        break

    # №15: наименьшее натуральное A, при котором (x · y < A) ∨ (x > 9) ∨ (y > 40)
# истинно при любых целых положительных x и y.
# Ответ: 361
def F(x, y, A):
    return (x * y < A) or (x > 9) or (y > 40)


for A in range(1, 1000):
    if all(F(x, y, A) for x in range(1, 100) for y in range(1, 100)):   # все пары x, y
        print(A)
        break

    # №15, отрезки: P = [30; 35], Q = [10; 25], R = [20; 41]. Наименьшая длина отрезка A,
# при котором (x ∈ A) ∨ (x ∈ P) ∨ ((x ∈ Q) → (x ∈ R)) истинно при любом x.
# Ответ: 10
def F(x, a1, a2):
    A = a1 <= x <= a2                          # отрезок A = [a1; a2] — его ищем
    P = 30 <= x <= 35
    Q = 10 <= x <= 25
    R = 20 <= x <= 41
    return A or P or (Q <= R)


tochki = []
for t in [30, 35, 10, 25, 20, 41]:             # все границы отрезков из условия
    tochki += [t - 0.1, t, t + 0.1]            # сама граница и точки рядом с ней

dliny = []
for a1 in tochki:                              # начало A
    for a2 in tochki:                          # конец A
        if a1 <= a2 and all(F(x, a1, a2) for x in tochki):
            dliny.append(a2 - a1)
print(round(min(dliny)))                       # наибольшая длина — max(dliny)

    Как это работает. Ответ — всегда отрезок между точками из условия, а на каждом куске прямой между границами формула ведёт себя одинаково. Поэтому достаточно проверить сами границы и точки рядом с ними (±0,1), а концы A перебирать из тех же точек. round убирает «хвост» 0,1, если конец A не входит в отрезок. Не надо думать, включены ли концы и сколько у A кусков, — проверили на 300 случайных задачах против полного перебора. Наибольшая длина — max(dliny).

    Подробнее: отрезки способом «список» (как в материалах Умскула)

    Отрезки — списки целых чисел, в A собираем x, без которых формула ложна (для наименьшей длины A пустой и дополняется append; для наибольшей A сначала большой и из него вычёркивают remove):

    # №15, отрезки, способ «список» (как в материалах Умскула) для той же задачи:
# собираем в A целые x, при которых без A выражение ложно, и смотрим края списка.
# Ответ: 10 19
P = list(range(30, 36))
Q = list(range(10, 26))
R = list(range(20, 42))
A = []                                         # наименьшая длина: начинаем с пустого A
for x in range(0, 100):
    if not ((x in A) or (x in P) or ((x in Q) <= (x in R))):
        A.append(x)                            # без x формула ложна — x обязан быть в A
print(min(A), max(A))      # 19 нет среди границ: на самом деле A идёт до 20, длина 20 - 10 = 10

    Дальше — вручную: длина — это «правый край − левый край», а не len(A), и края надо сверить с числами из условия. Здесь программа даёт 10…19, но 19 в условии нет: x между 19 и 20 тоже не покрыты, A идёт до 20, длина 20 − 10 = 10 (а не 9). Если в списке «дырка» (два куска), A должен накрыть оба — от левого края первого до правого края второго. Из-за этих ручных шагов основной способ — граничные точки. На Решу ЕГЭ «список» без правки краёв (max(A) - min(A)) ошибается в 9 из 25 задач на наименьшую длину, в двух — сразу на 2 (оба края A не входят в отрезки условия); граничные точки решили все 34 задачи раздела верно.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • not без своих скобок. В Python not слабее сравнений: not (x % A == 0) <= (…) значит not ((x % A == 0) <= (…)). В задаче Умскула (ответ 126) такая запись не находит ни одного A. Пишите x % A != 0 вместо not ДЕЛ, а если not нужен — (not ( … )) целиком в скобках.
    • Диапазон y короче чисел из условия. В примере «Две переменные» есть y > 40: при y до 30 получится 271 вместо 361 — перебор не дошёл до опасных пар.
    • Ответ у границы перебора A. Наибольшее A для ДЕЛ(x, A) ∨ ¬ДЕЛ(x, 1100) при range(1, 1000) — 550, а на самом деле 1100. Ответ близко к концу range — расширьте range и проверьте снова.
    • Слишком маленький диапазон x. Для ДЕЛ(x, A) → (¬ДЕЛ(x, 120) ∨ ДЕЛ(x, 7)) при x до 100 «ответ» 1, при x до 1000 и дальше — 7: до первого x, делящегося на 120, перебор просто не дошёл.
    • & с большими числами и x до 10 000. В задаче Решу ЕГЭ с масками 20777 и 12332 получается 257 вместо 16641: в 20777 есть бит 2¹⁴ = 16 384, а x до него не дошёл. x и A — до 2 ** 15 (≈ 7 с, нормально).
    • & и сравнения без своих скобок. (x & 17 == 0 <= x & A != 0) — для Python это цепочка сравнений «… == 0 и 0 <= … и … != 0», а не импликация: программа не находит ни одного A. Каждое ((x & m) == 0) — в скобках целиком.
    • ДЕЛ(90, A) наоборот. «90 делится на A» — 90 % A == 0. Записали A % 90 — подходящих A нет, и print(otvet) падает с NameError.
    • «Найдутся x, y» через all. Ответ — край перебора (999 вместо 64): нужен any(not F(…)).
    • «Положительное» и «неотрицательное». Положительные — с 1, неотрицательные — с 0: range(0, …).
    • Наибольшее вместо наименьшего. С break печатается первое подходящее A; для наибольшего — последнее.
    • Формула без общих скобок, & и % перепутаны (x & 5 и x % 5 — разные вещи).
    • Отрезки: длина как len(A). В отрезке [6; 12] семь целых точек, а длина 6. И наоборот: спросили число целых точек — длина даст на 1 меньше.
    • «Целое A» — не только положительное. Для «наименьшего целого A» или «сколько целых A» перебирайте A с отрицательных.
