    №26. Обработка файла: сортировка, жадный выбор, журнал¶

    Python ~35 мин 2 балла файл .txt

    Коротко

    Сюжеты у №26 разные (журнал сервера, коробки, места в зале, камера хранения, рейтинг), а порядок решения один:

    1. первая строка — отдельно (f.readline()): в ней количества и ограничения;
    2. остальные строки — в список;
    3. отсортировать в нужном порядке (sort, key=); журнал (демо-2027) уже идёт по времени — не сортируем;
    4. один проход по списку, в переменных — «состояние»: сколько взяли, что занято, последний взятый;
    5. второй вопрос чаще всего — переделать последний шаг (заменить последний взятый, выбрать последнее мероприятие).

    Как узнать задачу¶

    • К заданию приложен файл .txt: в первой строке — количества (N, иногда ещё K, S, M), дальше строки с числами, иногда с буквами или временем ЧЧ:ММ:СС.
    • Длинный сюжет и ответ из двух чисел; второе почти всегда спрашивают «при условии, что первое наибольшее» или «для найденного…».
    • По сюжету сразу видно, что сортировать (и какая вкладка «Разновидностей» нужна):
    Сюжет Что сортировать Где в карточке
    журнал сервера, резервные копии (ЕГЭ-2026, демо-2027) ничего: строки уже по времени «Пример с разбором»
    архив, контейнеры на судне, посылки, закупка по возрастанию: берём самые маленькие «Шаблон»
    коробки-матрёшки, коржи, кольца, цилиндры по убыванию: от самой большой «Матрёшка»
    места в рядах, сосны, частицы на экране, пиксели пары (ряд, место) «Ряды и места»
    концертный зал «перед местом всё свободно», морской бой для каждого места — первый занятый ряд «Перед местом свободно»
    камера хранения, МФЦ, парковка, окна банка по времени прихода «Очередь к ячейкам»
    конференц-зал, мероприятия, уборка снега по времени окончания «Расписание»
    студенты, викторина, абитуриенты, лидер продаж по ключу-кортежу «Рейтинг»
    офис, магазин, процессы: сколько людей в каждый момент не сортируем: массив изменений +1/−1 «Отрезки времени»
    «каждый третий товар бесплатно», «четвёртый за полцены» цены по убыванию «Акции»
    шлифовка и покраска деталей, рейтинг продуктов все 2N чисел вместе «Конвейер»

    Шаблон¶

    # №26, «Как можно больше» (свои данные): на диск объёмом S сохранить файлы как можно большего числа пользователей,
# затем — самый большой файл, который может быть сохранён при таком количестве
# Ответ: 266 67
f = open('arhiv.txt')
s, n = map(int, f.readline().split())      # 1. первая строка — отдельно
a = sorted(int(x) for x in f)              # 2. остальные — в список и отсортировать
summa = k = 0
for x in a:                                # 3. один проход: маленькие, пока влезают
    if summa + x > s:
        break
    summa += x
    k += 1
zapas = s - (summa - a[k - 1])             # 4. второй вопрос: место, если убрать последний взятый
print(k, max(x for x in a if x <= zapas))

    Как это работает. Задача «на диск объёмом S сохранить файлы как можно большего числа пользователей». Чтобы файлов было больше всего, берём самые маленькие: сортируем по возрастанию и складываем, пока помещается. Второй вопрос — «самый большой файл при таком количестве»: количество уже не увеличить, но последний взятый файл можно заменить на больший. Убираем последний (освобождается zapas места) и берём самый большой файл, который влезет на его место.

    Эти четыре шага — общий порядок для любого №26: меняются сюжет, ключ сортировки и то, что делаем в проходе.

    В условии В программе
    первая строка «S N» s, n = map(int, f.readline().split()) — до того, как читать остальное
    K и N в двух разных строках k = int(f.readline()), n = int(f.readline())
    в строке «время клиент объём», «цена буква» t, c, v = s.split(), числа — через int
    по возрастанию / по убыванию sorted(a) / sorted(a, reverse=True); у списка — a.sort()
    сортировать по второму числу пары sorted(z, key=lambda p: p[1])
    «по убыванию суммы, при равенстве — по возрастанию ID» key=lambda p: (-p[0], p[1]) — минус переворачивает порядок
    одна точка (место) записана в файле дважды set(...) до сортировки
    в файле есть пустые строки for s in f if s.strip()
    «номер ячейки», «номер окна» в списке номера с 0, в ответе — i + 1
    «если вариантов несколько — с наибольшим…» сравнивать кортежи: max(otvet, (k, last))

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027; такая же задача была на ЕГЭ-2026). Сервер выполняет запросы; в журнале — время регистрации, идентификатор клиента и объём данных. Данные копятся в разделе памяти вместимостью K. Каждый раз, когда свободной памяти недостаточно для очередного запроса, сервер делает резервную копию всего накопленного, освобождает раздел и продолжает работу. Найдите клиента, передавшего наибольший общий объём, и сумму двух наибольших резервных копий, созданных не позднее 11:59:59. Первая строка файла — N и K, дальше строки вида 05:05:05 101 90000.

    Решение. Журнал уже идёт по времени — сортировать не нужно, идём по строкам по порядку:

    # №26, демоверсия ЕГЭ-2027: журнал сервера — клиент с наибольшим объёмом и сумма двух наибольших резервных копий,
# созданных не позднее 11:59:59
# Ответ: 7040 52204
f = open('26.txt')
n, k = map(int, f.readline().split())
vsego = {}                                 # клиент → сколько всего передал
pamyat = 0                                 # сколько занято в разделе
kopii = []                                 # (время, объём) резервных копий
for s in f:
    t, c, v = s.split()
    c, v = int(c), int(v)
    vsego[c] = vsego.get(c, 0) + v
    if pamyat + v > k:                     # новый запрос не помещается —
        kopii.append((t, pamyat))          # копия всего накопленного,
        pamyat = 0                         # раздел свободен
    pamyat += v                            # запрос записан
mx = max(vsego.values())
klient = [c for c in vsego if vsego[c] == mx]
utro = sorted([v for t, v in kopii if t <= '11:59:59'], reverse=True)
print(klient[0], utro[0] + utro[1])
    Условие Код
    первая строка — N и K n, k = map(int, f.readline().split())
    строка «время клиент объём» t, c, v = s.split(); время оставляем строкой
    общий объём каждого клиента словарь: vsego[c] = vsego.get(c, 0) + v
    «памяти недостаточно» pamyat + v > k — запрос не помещается (ровно K помещается)
    копия всего накопленного, раздел свободен kopii.append((t, pamyat)), pamyat = 0
    …и продолжает работу запрос записывается всегда: pamyat += v после if
    «не позднее 11:59:59» t <= '11:59:59': время ЧЧ:ММ:СС с ведущими нулями сравнивается как строка
    две наибольшие копии отсортировать по убыванию, utro[0] + utro[1]

    Время копии — время запроса, который не поместился: копию сервер делает в этот момент. То, что осталось в разделе в конце журнала, копией не считается.

    Ответ: 7040 52204.

    Проверка вручную — на примере из условия

    K = 140 000. 20 000 + 110 000 = 130 000 помещается; запрос 90 000 в 05:05:05 уже не помещается — копия 130 000, в разделе 90 000. В 07:07:07 запрос 62 000 не помещается — копия 90 000. Дальше 62 000 + 48 000 + 12 000 = 122 000, в 21:21:21 копия 122 000, в 23:23:23 — 120 000. До полудня копии 130 000 и 90 000: сумма 220 000. Клиент 303 передал 62 000 + 120 000 = 182 000 — больше всех. Ответ примера: 303 220000.

    На файле демоверсии две наибольшие утренние копии одинаковые — по 26 102, поэтому их нельзя «схлопывать» через set.

    Разновидности¶

    В условии Как записать
    журнал сервера (демо-2027, ЕГЭ 18.06, 22.06, 08.07.2026) — другие вопросы: объём клиента только до полудня; два наибольших объёма клиентов; объём ≤ 150 000; два клиента с наименьшим объёмом; последняя копия до полудня / две последние вкладка «Журнал: другие вопросы»
    строки журнала идут не по времени (авторские задачи) сначала zapisi = sorted(s.split() for s in f) — время-строка сортируется правильно
    архив, контейнеры на судне, посылки (демо 2021–2022, ЕГЭ-2021, апробации, ЕГКР 2023–2024) шаблон
    сколько контейнеров останется и их наибольшая масса (апробация 2026) n - k и sum(a) - sum(a[:k]): увезли самые лёгкие
    грузы одной группы (200–210 кг) — в первую очередь, потом как можно больше остальных вычесть первую группу из S, дальше шаблон
    закупка A и B: сначала все A (самые дешёвые партии), на остаток — B два прохода по sorted(a), из партии min(kol, m // cena) штук
    «как можно больше изделий, из них как можно больше A, потом дешевле» k — по шаблону; потом ka от наибольшего вниз: sum(a[:ka]) + sum(b[:k - ka]) <= m
    команды и самолёты, грузы и контейнеры, экипажи и санки (ЕГЭ 2023, 2025, Крылов-2026 в1–в4): одна в один, наибольшее количество и самая большая из отправленных оба списка по убыванию; в самый большой контейнер — самый тяжёлый груз, который влезет — вкладка «Один в один»
    то же, но «вместимость не меньше чем вдвое больше команды» вместимость заменить на c // 2
    коробки-матрёшки, коржи, кольца, цилиндры, передатчики (ЕГЭ 2022–2025, демо 2023, Крылов-2026 в13, в14) вкладка «Матрёшка»
    коробки двух цветов, цвета чередуются (Крылов в16) вкладка «Два цвета»
    в матрёшке только коробки, к которым есть замочек (Крылов в15) сначала отобрать: [x for x in korob if x in zamki]
    коробки вкладываются, если меньше на K + номер вкладываемой цепочка снизу вверх, от самой маленькой: x - last >= k + 2000, k — сколько уже взяли
    блоки контейнеров: наименьшее число ячеек склада контейнеры по возрастанию надевать на любой блок, где сверху меньше на 5; не на что — новый блок
    ряд с наибольшим номером, где ровно 2 (13, 11) свободных места между занятыми (ЕГЭ 2021, 2022, апробация 2022) вкладка «Ряды и места»: разность соседних занятых = свободных + 1
    наибольшее число свободных мест подряд m2 - m1 - 1, максимум по кортежу (свободных, ряд)
    самая длинная группа светлых точек подряд (частицы на экране) set, счётчик серии: следующая точка того же ряда на 1 дальше → dl += 1, иначе dl = 1
    «линия» с ≤ 7 тёмными точками подряд; линии из ≥ 3 точек; изолированные точки (дальше 500 от соседей) соседи в отсортированном списке: m - a[i - 1][1], a[i + 1][1] - m
    пиксели: ровно 2 (3) белых между чёрными, ряд наибольший / наименьший (Крылов в17–в20) как «2 свободных»: разность 3 (4)
    студент с наибольшим числом задач подряд / через одну (ЕГКР 2024, 2025); спортсмены подряд у одной точки (ЕГЭ 2025) пары (студент, задача) или (точка, спортсмен), set, счётчик серии с шагом 1 (2)
    два соседних места, перед которыми всё свободно, ряд как можно дальше (ЕГЭ 2024, апробация 2025) вкладка «Перед местом свободно»
    место, перед которым больше всего свободных кресел подряд (ЕГЭ 2024, ДВ) пары (место, ряд): свободных перед рядом r — r - pred - 2

    «Морской бой»: однопалубный, над ним больше всего свободных клеток до препятствия (Крылов в7, в8) по каждому столбцу — отсортированные занятые ряды pred < r; лучшая клетка промежутка — r - 1, над ней r - pred - 2 свободных (pred = 0 — край, в конец списка — m + 1)
    камера хранения (ЕГЭ-2023), МФЦ (ЕГЭ 2025, 2026): свободная ячейка с наименьшим номером вкладка «Очередь к ячейкам»

    окна банка с очередью ≤ 12 человек; уходит, если ждал больше 40 минут у окна — список «когда закончат», начало max(t, svobodno)
    приёмщики винограда: A — нечётные номера, B — чётные, перерыв 5 минут (ЕГЭ 19.06.2026) range(1, k + 1, 2) / range(2, k + 1, 2), свободен с t2 + 5
    конференц-зал: наибольшее число мероприятий (ЕГЭ-2023, демо-2024) вкладка «Расписание»
    …и самое позднее окончание последнего; перерыв ≥ 15 минут; уборка снега — неубранный конец дороги (ЕГКР 2026) последнее — из начинающихся после конца предпоследнего; s >= konec + 15; 10000 - max(конец)

    Подробнее: когда жадного выбора мало — динамика

    Жадный выбор («самое раннее окончание», «самая большая подходящая коробка») верен, когда нужно наибольшее количество. Если же спрашивают наибольшее время занятости зала, наибольшую сумму или цвета коробок чередуются из трёх, нужна динамика: для каждого элемента — лучший результат набора, который им заканчивается.

    # №26, «Подробнее: динамика» (свои данные): мероприятия без пересечений (конец одного может совпадать с началом другого)
# выбрать так, чтобы зал был занят как можно дольше; сколько минут он будет занят и сколько при этом мероприятий
# Ответ: 1415 11
f = open('zayavki.txt')
n = int(f.readline())
z = sorted((tuple(map(int, s.split())) for s in f), key=lambda p: p[1])   # по времени окончания
best = []                                  # best[i] — (минут, мероприятий) лучшего набора, где i-е — последнее
for i in range(len(z)):
    s, e = z[i]
    pred = max([best[j] for j in range(i) if z[j][1] <= s], default=(0, 0))   # лучший набор, который кончился до s
    best.append((pred[0] + e - s, pred[1] + 1))
print(*max(best))
    На этих данных жадный выбор по окончанию даёт 25 мероприятий, но всего 971 минуту, а лучший набор — 11 мероприятий и 1415 минут. Двойной цикл при N ≈ 1000 работает секунды — в №26 это допустимо.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Не отсортировали заявки по времени. Камера хранения (Решу ЕГЭ 57433): без сортировки — 338 и 200 вместо 344 и 53. В файлах заявки идут вперемешку.
    • <= вместо < в «свободна со следующей минуты» — 354 и 168 вместо 344 и 53; без break — 420 и 210.
    • Матрёшка снизу вверх. Количество то же, а самая маленькая коробка меньше: демоверсия 2023 — 2767 и 50 вместо 2767 и 51.
    • Второе число «архива» — не наибольший из взятых. Нужно заменить последний взятый на самый большой, который влезет: в задаче Решу ЕГЭ 27881 наибольший из взятых — 9, а ответ 17.
    • Последнее мероприятие — не из жадной цепочки. ЕГЭ 19.06.2023: перерыв по жадной цепочке 33, а верно 35 — последнее берут самое позднее из начинающихся после предпоследнего. Сортировка по началу вместо конца — 3 мероприятия вместо 17.
    • Повторы в файле. Частицы на экране (Решу ЕГЭ 46984): 77 точек записаны дважды, без set самая длинная группа — 7 вместо 10.
    • Начальное значение «первого занятого ряда» — m, а не m + 1: ЕГЭ-2024 — ряд 99 998 вместо 99 999.
    • Две наибольшие копии через set. На демоверсии обе копии по 26 102 — set оставит одну: 52 202 вместо 52 204.
    • Журнал не по времени. В авторской задаче Решу ЕГЭ 92230 строки перемешаны: по времени — 99 961, по порядку строк — 99 967 (а ответ сайта 99 996 получается, только если после копии не записывать новый запрос — ошибка сайта).
    • Минута выхода. «В момент выхода сотрудник в офисе» — -1 в минуту t2 + 1 (Решу ЕГЭ 78051: 1432 и 15); с -1 в минуту t2 — 1431 и 13.
    • Пустая строка в файле (файл ЕГЭ-2021 на КомпЕГЭ) — ValueError при распаковке; читайте for s in f if s.strip().
    • Первая строка — не данные. Прочитать её до списка: иначе N попадёт в числа. А в файлах сборника Крылова (в9, в10) и в некоторых задачах Решу ЕГЭ первой строки с N нет — посмотрите файл перед решением.
    • Пример к условию часто с другим параметром: «разница 3» в примере, 4 — в задаче; 3 свободных места в примере, 13 — в задаче. Подставляйте число из условия.
    • Номера с единицы: ячейка, окно, место в рейтинге — i + 1; 1500-е место — a[1499].
    • Порядок чисел в ответе — как в вопросе: «сначала количество пиков, потом число посетителей».
    • Сортировка списка пар — сразу по первому числу, при равенстве по второму, оба по возрастанию. Другой порядок — только через key.
    • / вместо // — дробь в ответе; «целая часть 25 %» — n // 4.
