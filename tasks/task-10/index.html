    №10. IP-адрес и маска сети¶

    Python (ipaddress) можно вручную ~3 мин 1 балл без файла

    Коротко

    net = ip_network('узел/маска', 0) — сеть узла (0 разрешает писать адрес узла). Дальше — нужный адрес: net.network_address (адрес сети), net.broadcast_address, net[1] и net[-2] (наименьший и наибольший адрес компьютера); в ответе — сумма октетов sum(octs(…)). Маска неизвестна — перебор её длины p от 0 до 32 (range(33)). Адреса с условием — цикл for a in net и f'{a:b}' (32 двоичные цифры).

    Как узнать задачу¶

    • «В терминологии сетей TCP/IP маской сети называют двоичное число…», «адрес сети получается в результате применения поразрядной конъюнкции к заданному адресу узла и его маске».
    • Даны адрес узла и маска (192.168.159.86 и 255.255.252.0) — найти адрес сети; в ответе — сумма октетов (формат 2027). Или дан адрес сети и спрашивают про маску; или сколько адресов сети с условием на двоичную запись.
    • До 2027 года это был №13 (ответ записывали числами без точек или буквами из таблицы), а №10 был «поиск слова в тексте» (Word / LibreOffice) — разборы «№10 2027: поиск в тексте», записанные до выхода проекта демоверсии, к новому формату не относятся.

    Шаблон¶

    Модуль ipaddress встроен в Python — ставить ничего не нужно.

    # №10, демоверсия ЕГЭ-2027: узел 192.168.159.86, маска 255.255.252.0. Найдите адрес сети;
# в ответе — сумма числовых значений его октетов.
# Ответ: 516
from ipaddress import *


def octs(a):                                   # адрес → список октетов: [192, 168, 156, 0]
    return [int(x) for x in str(a).split('.')]


net = ip_network('192.168.159.86/255.255.252.0', 0)   # «узел/маска»; 0 — разрешаем писать узел, а не адрес сети
print(sum(octs(net.network_address)))                 # адрес сети → сумма октетов
    В условии В шаблоне
    узел X и маска Y (или «/22» — 22 единицы) net = ip_network('X/Y', 0)
    адрес сети net.network_address (это и net[0])
    широковещательный адрес; «наибольший адрес сети» net.broadcast_address (net[-1])
    наибольший / наименьший адрес, который можно назначить компьютеру net[-2] / net[1]
    в ответе — сумма октетов; адрес без точек sum(octs(…)); str(…).replace('.', '')
    маска; число единиц и нулей в маске net.netmask; net.prefixlen и 32 - net.prefixlen
    сколько адресов в сети; сколько компьютеров net.num_addresses; net.num_addresses - 2
    третий слева байт (октет) маски / адреса octs(net.netmask)[2] — счёт с нуля
    номер компьютера в сети int(ip_address(узел)) - int(net.network_address)
    маска неизвестна (дан адрес сети, два узла в одной сети) перебор p — вкладки «Маска неизвестна», «Два узла»
    сколько адресов сети с условием на двоичную запись цикл по сети — вкладка «Адреса с условием»

    Пример с разбором¶

    Задача (демоверсия ЕГЭ-2027, пересказ). Даны адрес узла 192.168.159.86 и маска 255.255.252.0. Найдите адрес сети; в ответе укажите сумму числовых значений его октетов (например, для 100.20.3.4 — 127).

    Решение.

    Условие Код
    узел и маска ip_network('192.168.159.86/255.255.252.0', 0)
    адрес сети net.network_address → 192.168.156.0
    сумма октетов sum(octs(…)) = 192 + 168 + 156 + 0

    Программа — шаблон выше. Ответ: 516.

    Проверка вручную: двоичная запись одного октета

    В маске 255 — октет адреса сети равен октету узла (192, 168), 0 — нулю. Считать нужно только третий октет: 159 = 1001 1111, 252 = 1111 1100, поразрядное И — 1001 1100 = 156. Адрес сети 192.168.156.0, сумма 516. В Python без модуля — & по октетам:

    # №10, демоверсия ЕГЭ-2027 — без модуля ipaddress: адрес сети = поразрядное И (&) узла и маски, октет за октетом.
# Ответ: 516
ip = '192.168.159.86'.split('.')
mask = '255.255.252.0'.split('.')

set_ = [int(ip[j]) & int(mask[j]) for j in range(4)]  # [192, 168, 156, 0]: 159 & 252 = 156
print(sum(set_))

    Разновидности¶

    Условие Как записать
    адрес сети по узлу и маске — сумма октетов (демо-2027, ЕГЭ-2026); старые формы — адрес без точек, буквы по таблице шаблон
    широковещательный адрес; наибольший / наименьший адрес компьютера (ЕГЭ-2025, 2026) broadcast_address, net[-2], net[1] (вкладка «Адреса узлов»)
    сколько адресов (компьютеров) допускает маска num_addresses (- 2, только если в условии сказано, что адрес сети и широковещательный не используются)
    номер компьютера в сети int(узел) - int(адрес сети) — нумерация с нуля
    по узлу и адресу сети: третий / последний байт маски; наименьшее, наибольшее значение; сколько масок возможно вкладка «Маска неизвестна»
    наименьшее / наибольшее число единиц (нулей) в маске; единиц в последнем байте маски там же: p, 32 - p, f'{octs(m)[3]:b}'.count('1')
    наибольшее число адресов в сети при известном узле и адресе сети там же: max(net.num_addresses …)
    два узла в одной сети: наибольший байт маски / число единиц; в разных сетях — наименьший вкладка «Два узла»; «в разных» — b not in net
    «третий байт маски равен 224 — чему равен третий байт адреса сети?» 95 & 224 — поразрядное И октета узла и маски
    сколько адресов сети, в двоичной записи которых единиц чётно / не кратно 4 / нулей больше вкладка «Адреса с условием»
    в третьем байте адреса поровну нулей и единиц f'{octs(a)[2]:08b}'.count('1') == 4 — 08b: 8 цифр с ведущими нулями
    наименьший адрес компьютера с условием на единицы for a in net.hosts(): … break — первый подходящий
    сеть неизвестна: «в сети 10 адресов с 12 единицами», «есть узел вида x.y.y.x», «два узла — наименьшее число адресов с 15 единицами» перебор p, внутри — цикл по адресам сети
    «единиц в адресе сети столько же, сколько нулей в маске» перебор p: f'{net.network_address:b}'.count('1') == 32 - p
    наибольшее число единиц в адресе компьютера при известном адресе сети перебор p, f'{net[-2]:b}'.count('1')
    маска 255.255.A.0 неизвестна, условие «для всех адресов сети» перебор A по 9 возможным байтам маски: 0, 128, 192, 224, 240, 248, 252, 254, 255 
    # №10 (своя): сеть задана узлом 172.31.203.77 и маской 255.255.248.0. Найдите широковещательный адрес, наибольший
# и наименьший адреса, которые можно назначить компьютеру; в ответе для каждого — сумма октетов.
# Ответ: 665
# Ответ: 664
# Ответ: 404
from ipaddress import *


def octs(a):
    return [int(x) for x in str(a).split('.')]


net = ip_network('172.31.203.77/255.255.248.0', 0)
print(sum(octs(net.broadcast_address)))        # широковещательный: все биты узла — единицы (это net[-1])
print(sum(octs(net[-2])))                      # наибольший адрес компьютера — предпоследний
print(sum(octs(net[1])))                       # наименьший адрес компьютера — net[1] (net[0] — адрес сети)

    «Наибольший адрес в сети» — широковещательный; «наибольший, который можно назначить компьютеру» — на 1 меньше. Разница в одном слове — самый частый подвох ЕГЭ-2026.

    # №10 (своя): для узла 121.47.180.205 адрес сети равен 121.47.176.0. Чему равно наименьшее возможное значение
# третьего слева байта маски? Сколько различных масок возможно? Наибольшее количество единиц в маске?
# Ответ: 240
# Ответ: 2
# Ответ: 21
from ipaddress import *


def octs(a):
    return [int(x) for x in str(a).split('.')]


ip = '121.47.180.205'
masks = []                                     # маски, при которых всё сходится
for p in range(33):                            # p — сколько единиц в маске: от 0 до 32 включительно
    net = ip_network(f'{ip}/{p}', 0)
    if str(net.network_address) == '121.47.176.0':
        masks.append(net.netmask)
print(min(octs(m)[2] for m in masks))          # третий слева байт — [2], счёт с нуля
print(len(masks))
print(max(f'{m:b}'.count('1') for m in masks)) # f'{m:b}' — 32 двоичные цифры маски

    Длина маски p — от 0 до 32, всего 33 варианта: range(33). Для каждой строим сеть узла и оставляем те маски, при которых адрес сети совпадает с данным. Дальше — что спрашивают: байт маски, сколько масок, число единиц.

    # №10 (своя): узлы 98.130.77.200 и 98.130.79.14 находятся в одной сети. Каково наибольшее возможное количество
# единиц в маске этой сети?
# Ответ: 22
from ipaddress import *

a, b = ip_address('98.130.77.200'), ip_address('98.130.79.14')
v = []
for p in range(33):
    net = ip_network(f'{a}/{p}', 0)
    ends = (net.network_address, net.broadcast_address)   # эти два адреса узлам не назначают
    if b in net and a not in ends and b not in ends:      # оба в одной сети и оба — настоящие узлы
        v.append(p)
print(max(v))

    Оба узла — в одной сети: второй входит в сеть первого (b in net). И оба должны быть узлами: адрес сети и широковещательный узлам не назначают — без этой проверки в одной задаче ЕГЭ (Решу ЕГЭ 18081) получается неверная маска.

    # №10 (своя): сеть задана адресом 172.16.168.0 и маской 255.255.248.0. Сколько в ней IP-адресов, в двоичной записи
# которых нулей больше, чем единиц?
# Ответ: 1816
from ipaddress import *

net = ip_network('172.16.168.0/255.255.248.0', 0)
k = 0
for a in net:                                  # все адреса сети — с адресом сети и широковещательным
    b = f'{a:b}'                               # 32 двоичные цифры, с ведущими нулями
    if b.count('0') > b.count('1'):
        k += 1
print(k)

    f'{a:b}' — двоичная запись адреса, ровно 32 цифры с ведущими нулями (Python 3.9 и новее). Цикл идёт по всем адресам сети; если спрашивают про адреса компьютеров — net.hosts().

    Подробнее: решение вручную

    Так решают большинство разборщиков — и для проверки программы полезно.

    1. В маске сначала единицы, потом нули: 255 = 1111 1111, 0 — нули. Возможные байты маски: 0, 128, 192, 224, 240, 248, 252, 254, 255.
    2. Где в маске 255 — октет адреса сети равен октету узла, где 0 — нулю. Переводить в двоичную нужно только один октет — тот, где маска не 255 и не 0 («водораздел»).
    3. Широковещательный — все биты справа от водораздела единицы; наибольший адрес компьютера — на 1 меньше; наименьший — адрес сети + 1.
    4. Маска по узлу и адресу сети: бит узла 1 и бит сети 1 — в маске 1 (и все левее); бит узла 1, а сети 0 — в маске 0 (и все правее); где у узла 0 — маска может быть любой, но единицы идут подряд.
    5. Адреса с условием: зафиксированные биты (адрес сети) + свободные биты; число вариантов — сочетания из свободных. Для примера во вкладке: 8 единиц фиксировано, 11 свободных бит, нужно меньше 8 единиц в свободной части — C(11, 0) + … + C(11, 7) = 1816.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • bin(int(a)) для подсчёта нулей. Двоичная запись теряет ведущие нули и сама содержит «0» из 0b: у адреса 10.0.0.1 нулей 26 вместо 29 (Python 3.11 и 3.12). Единицы bin считает верно, но лучше всегда f'{a:b}'.
    • Срез сети net[1:-1] — ошибка TypeError. Адреса компьютеров (без адреса сети и широковещательного) — net.hosts().
    • Узел не может совпадать с адресом сети или широковещательным. Решу ЕГЭ 18081 (ЕГЭ-2019): узлы ….224 и ….192 «в одной сети, единиц в маске наибольшее» — без проверки получается маска с последним байтом 192, но тогда ….192 — адрес сети; верно 128. Из восьми задач «два узла» на сайте это меняет ответ только здесь — но проверку пишите всегда (вкладка «Два узла»).
    • Маска через точки «наоборот»: ip_network('10.1.2.3/0.0.255.255', 0) модуль молча понимает как маску /16 (обратная маска) — ошибки нет, ответ неверный. Переписывайте маску внимательно.
    • Большие сети считаются долго: цикл по сети /8 (16,7 млн адресов) с подсчётом единиц — 16 с. В переборе масок можно пропустить заведомо неподходящие большие сети (if p >= 16:).
    • Без 0 (strict=False) — ValueError: … has host bits set: модуль ждёт адрес сети, а дан адрес узла.
    • range(32) вместо range(33) — теряется маска /32 (33 варианта: от 0 до 32 единиц).
    • «Наибольший адрес сети» ≠ «наибольший адрес компьютера» (net[-1] и net[-2]), «наименьший» — net[0] и net[1]. «Минус 2» в числе адресов — только если так сказано в условии.
    • str(net) — это 192.168.156.0/22 с маской; для суммы октетов берите net.network_address.
    • Адреса строками не сравнивают: '9.1.1.1' < '10.1.1.1' — False. Сравнивайте ip_address(…).
    • Третий байт — [2]: счёт октетов в списке с нуля.
    • Номер компьютера — с нуля (int(узел) - int(адрес сети)), а не порядковый номер среди узлов.
