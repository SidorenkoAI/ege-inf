    Шпаргалка¶

    Как пользоваться

    Шаблоны здесь — так, как решает преподаватель в задачах бота: те же приёмы и имена (nums, cnt, ok, result, nomer…). Задачи — из демоверсии ЕГЭ-2027, ответ — в строке # Ответ:. Подробности, разновидности и разборы — в карточке номера (ссылка в конце каждого раздела). Пока готовы №1, 2, 4–17. Распечатать — Ctrl+P в браузере: меню и кнопки на бумагу не попадут.

    Общее для всех номеров¶

    Что Как в Python
    ¬A, A ∧ B, A ∨ B (not A), A and B, A or B — каждый not в свои скобки
    A → B, A ≡ B, A ≢ B (A) <= (B), (A) == (B), (A) != (B) — обе части в скобках
    «делится на m» / «не делится» x % m == 0 / x % m != 0
    деление в ответе // — целое; / даёт 4100625.0, на больших числах теряет цифры
    округлить вверх from math import ceil → ceil(a / b)
    «от a до b включительно» range(a, b + 1)
    наименьшее первое подходящее — print(…) и break
    наибольшее последнее подходящее — otvet = … в цикле, print(otvet) после цикла
    файл данных f = open('D://17.txt') — свой путь к файлу; в Linux важен регистр букв имени
    двоичная запись bin(n)[2:] — без 0b; обратно — int(s, 2), из системы b ≤ 36 — int(s, b)

    Программа думает больше 2–3 минут

    Не ждать: Ctrl+C (в IDLE под Linux копирование — Ctrl+Shift+C, а Ctrl+C только прерывает программу), проверить границы range и перейти к быстрому способу из карточки.

    №1. Схема и таблица дорог¶

    Как — вручную, по шагам:

    1. Прочитать вопрос: какие буквы нужны.
    2. Подписать у каждой буквы схемы число линий, у каждой строки таблицы — число чисел. Наборы должны совпасть.
    3. Буква с особым числом дорог — её номер сразу.
    4. Остальные — по соседям: сколько дорог у соседей; связаны ли соседи между собой; общий сосед двух найденных.
    5. Буквы неразличимы (схема симметрична) — взять любой вариант: ответ от выбора не зависит.
    6. Дорога XY — число на пересечении строки X и столбца Y. Проверить соседей всех найденных букв.

    Ловушки: пункт посреди прямой линии делит её на две дороги; одних чисел дорог часто мало — различать по соседям; латинские буквы на схеме и русские в условии — это одни и те же пункты. → Карточка №1

    №2. Таблица истинности¶

    Как: печатаем строки таблицы, где F как во фрагменте, затем сопоставляем столбцы словами («во всех наборах z = 1, значит…»).

    # №2, демоверсия ЕГЭ-2027: F = ((x ≡ ¬y) → ¬(w → x)) ∨ ¬z, во фрагменте F = 0.
# Ответ: x y z w
# Ответ: 0 1 1 0
# Ответ: 1 0 1 0
# Ответ: 1 0 1 1
print("x y z w")                # шапка — в том же порядке, что и циклы
for x in range(0, 2):
    for y in range(0, 2):
        for z in range(0, 2):
            for w in range(0, 2):
                # → пишем как <=, ≡ — как ==, каждое ¬ — (not …) в скобках
                if (((x == (not y)) <= (not (w <= x))) or (not z)) == 0:
                    print(x, y, z, w)   # строки, где F = 0, как во фрагменте

    Менять: формулу в if; == 0 → == 1, если во фрагменте F = 1. Ловушки: x == not y — SyntaxError, нужно x == (not y); not w <= x — это not (w <= x): каждый not в свои скобки; <= и == в Python сильнее and/or и сцепляются: z == x <= y — это z == x and x <= y. → Карточка №2

    №4. Код Фано¶

    Как — вручную, деревом:

    1. Выписать все буквы алфавита; если спрашивают слово — сколько раз в нём каждая буква.
    2. Дерево: 0 — влево, 1 — вправо. Известные коды — листья: ниже них ничего нет, узлы над ними заняты.
    3. Свободные узлы — ветки без букв; длина кода = глубина узла.
    4. Чаще буква — короче код. Мест не хватает — раскрыть свободный узел на два (оба на 1 длиннее).
    5. Посчитать ответ, попробовать другую расстановку и взять лучшую.

    Ловушки: код нужен каждой букве алфавита, даже той, которой нет в слове; «буквы русского алфавита» — оставить свободную ветку; «с наименьшим числовым значением» — при равной длине левый узел. → Карточка №4

    №5. Алгоритм с двоичной записью¶

    # №5, демоверсия ЕГЭ-2027: чётное N — к двоичной записи слева и справа по 11, нечётное — слева 1, справа 00.
# Наименьшее R, превышающее 95.
# Ответ: 100
a = []
for N in range(1, 1000):        # N натуральное — с 1
    dv = bin(N)[2:]             # двоичная запись без '0b'
    if N % 2 == 0:              # одно правило «если … иначе» — if/else, не два if
        dv = '11' + dv + '11'
    else:
        dv = '1' + dv + '00'
    des = int(dv, 2)            # перевод из двоичной в десятичную
    if des > 95:
        a.append(des)           # спрашивают R — в список des, спрашивают N — N
print(min(a))                   # наименьшее — min, наибольшее — max

    Менять: правило — строками (dv[-2:] — две последние цифры, '10' + dv[2:] — заменить два левых разряда, dv.count('1') % 2 — остаток суммы цифр); троичная запись — своя функция перевода; спрашивают N — в список N. Ловушки: два if вместо if/else — второй проверяет уже изменённую строку; «два левых разряда» — срезом, не replace (заменит все вхождения); 0 ↔ 1 двумя replace подряд даёт одни нули; своя функция перевода без if x == 0: return '0' теряет ноль. → Карточка №5

    №6. Черепаха¶

    Как: переписать алгоритм в turtle, поставить точки в узлах сетки и посчитать точки по рисунку.

    # №6, демоверсия ЕГЭ-2027: Повтори 6 [Вперёд 24 Направо 90 Вперёд 30 Направо 90]  Поднять хвост
# Вперёд 2 Направо 90 Вперёд 10 Налево 90  Опустить хвост  Повтори 6 [Вперёд 75 Направо 90 Вперёд 71 Направо 90]
# Сколько точек с целыми координатами в пересечении фигур? Программа рисует; точки считаем по рисунку (483).
# Печатает, где начинается вторая фигура:
# Ответ: 10 2
import turtle
k = 10                          # масштаб — только у длин, не у углов
turtle.tracer(0)                # рисовать сразу, без анимации
turtle.left(90)                 # голова вверх, как в условии

for i in range(6):
    turtle.forward(24 * k)
    turtle.right(90)
    turtle.forward(30 * k)
    turtle.right(90)
turtle.penup()                  # Поднять хвост
turtle.forward(2 * k)
turtle.right(90)
turtle.forward(10 * k)
turtle.left(90)
print(round(turtle.xcor() / k), round(turtle.ycor() / k))   # round, не int: координаты дробные
turtle.pendown()                # Опустить хвост
for i in range(6):
    turtle.forward(75 * k)
    turtle.right(90)
    turtle.forward(71 * k)
    turtle.right(90)

turtle.penup()                  # иначе Черепаха нарисует путь к каждой точке
for x in range(-10, 91):        # сетка — чуть шире фигур
    for y in range(-10, 81):
        turtle.setpos(x * k, y * k)
        turtle.dot(3, "red")

turtle.done()                   # окно не закроется само

    Менять: команды — один в один (Направо → right, Налево → left, Назад → backward); сетку — шире фигур. Площадь ромба — S = a² · sin α (сторона a, острый угол α). Ловушки: k — только у длин, не у углов; без penup() перед сеткой Черепаха рисует путь к каждой точке; int(turtle.ycor() / k) даёт 8 вместо 9 — только round; площадь — по длинам, а не по точкам (квадрат 2 × 2: площадь 4, точек 9); большая сетка рисуется минутами — уменьшить диапазон. → Карточка №6

    №7. Объём звука и изображения¶

    # №7, демоверсия ЕГЭ-2027: голосовое сообщение — стерео, 32 000 Гц, глубина 16 бит, длительность 2 мин 27 с.
# Наименьшее количество Кбайт, необходимое для его хранения (без заголовка)?
# Ответ: 18375
from math import ceil, log2
K, M, G = 2**13, 2**23, 2**33          # бит в 1 Кбайте, 1 Мбайте, 1 Гбайте

V = 2 * 32000 * 16 * (2 * 60 + 27)     # звук: каналы × частота (Гц) × глубина (бит) × время (с) — в битах
print(ceil(V / K))                     # биты → Кбайты; «наименьшее целое количество» — вверх

    Менять: изображение — пиксели × бит на цвет; бит на N цветов — ceil(log2(N)); «наименьшее целое Кбайт» — ceil, «наибольшее (цветов, снимков)» — //; «только целую часть» — int. Ловушки: кГц = 1000 Гц, а Кбайт = 2¹³ бит; int(log2(1568)) = 10, нужно 11 — ceil; проценты через 1 - 0.7 дают 3.0000000000000004 и ceil → 4: доли — целыми числами, V * 30 / 100. → Карточка №7

    №8. Слова и перебор¶

    # №8, демоверсия ЕГЭ-2027: слова из 5 букв А, К, Ц, Е, Н, Т в алфавитном порядке.
# Первое слово с чётным номером, которое не начинается с А, Е, К и содержит хотя бы одну Т.
# Ответ: 3914 НААТЕ
import itertools
nomer = 1                           # номер слова в списке — с 1
for i in itertools.product(sorted('АКЦЕНТ'), repeat=5):   # sorted — по алфавиту
    if nomer % 2 == 0:              # чётный номер
        if i[0] not in 'АЕК' and 'Т' in i:
            print(nomer, ''.join(i))
            break                   # «первое» — дальше не ищем
    nomer += 1                      # номер растёт у каждого слова

    Менять: длина слова — repeat=; без повторов букв — itertools.permutations(…); «сколько слов» — cnt += 1 вместо print; последнее — ans = nomer без break; числа в k-ичной системе — алфавит '0123…' и i[0] != '0'; все буквы разные — len(set(i)) == len(i). Ловушки: без sorted — порядок букв условия, а не алфавит; латинские О/А, скопированные из условия, — 'О' == 'O' даёт False: буквы набирать самому; «не начинается с X и не заканчивается Y» — два отдельных условия. → Карточка №8

    №9. Таблица чисел по строкам¶

    Как: таблицу — Ctrl+A, Ctrl+C → Блокнот → 9.txt; условия — вложенными if: снаружи повторы, внутри суммы.

    # №9, демоверсия ЕГЭ-2027: в строке пять натуральных чисел. Сколько строк, в которых все числа различны,
# а удвоенная сумма максимального и минимального больше суммы оставшихся трёх?
# Ответ: 4874
f = open("9.txt")               # данные: Ctrl+A, Ctrl+C из таблицы → Блокнот → 9.txt
cnt = 0
for s in f:
    nums = list(map(int, s.split()))
    if len(set(nums)) == 5:     # все пять различны
        if 2 * (max(nums) + min(nums)) > sum(nums) - max(nums) - min(nums):
            cnt += 1

print(cnt)

    Менять: «все различны» из шести — == 6; «одно число дважды, остальные различны» — len(set(nums)) == 5 (из шести); повторяющиеся и одиночные — циклом for n in nums: с nums.count(n) в списки; чётные/нечётные — списки chet, nechet; номер строки — nomer += 1 первой строкой цикла. Ловушки: по len(set(…)) не всегда понятно, какие повторы: из шести «одно трижды» и «два по два» — оба == 4, считать count; «три минимальных» при повторах — три различных: sorted(set(nums))[:3]; корень через int — int(64 ** (1/3)) = 3, нужно round. → Карточка №9

    №10. IP-адреса и маски¶

    # №10, демоверсия ЕГЭ-2027: узел 192.168.159.86, маска 255.255.252.0. Найдите адрес сети;
# в ответе — сумма числовых значений его октетов.
# Ответ: 192.168.156.0
# Ответ: 516
import ipaddress
net = ipaddress.ip_network('192.168.159.86/255.255.252.0', 0)   # узел/маска; 0 — можно узел
print(net.network_address)      # адрес сети
summa = 0
for n in str(net.network_address).split('.'):
    summa += int(n)
print(summa)

    Маска неизвестна — перебрать число единиц в маске (таблицу print(net, net.num_addresses) можно и посмотреть глазами):

    # №10 (своя): для узла 121.47.180.205 адрес сети равен 121.47.176.0.
# Чему равно наименьшее возможное значение третьего слева байта маски?
# Ответ: 240
import ipaddress
for mask in range(32+1):        # сколько единиц в маске: от 0 до 32
    net = ipaddress.ip_network(f'121.47.180.205/{mask}', 0)
    #print(net, net.num_addresses)
    if str(net.network_address) == '121.47.176.0':
        ans = mask              # меньше единиц — меньше байт: первая подходящая
        break                   # наибольший байт — без break, последняя

m = '1'*ans + (32-ans) * '0'    # маска строкой из 32 цифр
print(int(m[16:24], 2))         # третий байт; четвёртый — m[24:]

    Менять: адреса с условием — for addr in net:, a = bin(int(addr))[2:], kolEd = a.count('1'), cnt += 1; сколько адресов — net.num_addresses; узлов — на 2 меньше. Ловушки: без 0 в ip_network — ValueError: has host bits set; перебор маски — range(32+1), range(32) теряет /32; bin(int(addr)) теряет ведущие нули: нули считать по 32 - a.count('1'), а не a.count('0'); наибольший адрес сети (широковещательный) — не адрес компьютера (на 1 меньше). → Карточка №10

    №11. Количество информации¶

    Как: вручную — бит на символ (2ⁱ ≥ мощность), байт на одну запись (вверх), потом × количество записей. Или перебором:

    # №11 (демоверсия ЕГЭ-2027): серийный номер — 157 символов; номер занимает минимально возможное целое число байт,
# символы кодируются одинаковым минимальным числом бит; 12 450 номеров занимают не более 955 Кбайт.
# Какая наибольшая возможная мощность алфавита?
# Ответ: 8
from math import ceil, log2
KB, MB, GB = 2**10, 2**20, 2**30         # байт в Кбайте, Мбайте, Гбайте


def bit(n):                             # бит на один символ, если символов в алфавите n
    return ceil(log2(n))                # вверх: 5 символов — 3 бита


def bajt(bity):                         # целое число байт, в которое помещаются bity бит
    return ceil(bity / 8)               # вверх: 42 бита — 6 байт


for N in range(1, 10**6):               # перебираем то, что спросили, — мощность алфавита N
    zapis = bajt(157 * bit(N))          # байт на один номер
    if 12450 * zapis <= 955 * KB:       # «не более 955 Кбайт» — как в условии, всё в байтах
        otvet = N                       # наибольшее — последнее подходящее
print(otvet)

    Менять: что спросили — то и перебираем (L — длина, N — мощность); знак — как в тексте: «не более» <=, «более» >. Ловушки: два округления вверх — бит на символ и байт на одну запись, только потом × количество; «в двух регистрах» — символов вдвое больше; граница range с запасом — иначе «наибольшее» молча неверное; ceil(a / 8), а не a // 8. → Карточка №11

    №12. Машина Тьюринга¶

    Как — разобрать, что делает каждое состояние: куда идёт головка, что меняет, где останавливается. Потом понять, что программа делает с числом (например, «прибавляет 1 и дописывает справа 1»), и посчитать ответ вручную. Сомневаешься — прогнать программу-исполнитель из карточки. Ловушки: символ, на котором программа остановилась, тоже изменён: «осталось 343 нуля» может быть 342 нетронутых нуля и бывшая единица; исходное число — без ведущих нулей, а результат может быть с ними («получилось 240» — наименьшее исходное 271, а не 15). → Карточка №12

    №13. Количество программ¶

    # №13, демоверсия ЕГЭ-2027: A: прибавь 1; B: поменяй местами две последние цифры —
# только если цифра десятков меньше цифры единиц. Сколько программ переводят 100 в 141?
# Ответ: 16
def f(s,e):                      # f(s, e) — сколько программ ведут из s в e
    if s > e:                    # перелетели финиш — 0 программ
        return 0
    if s == e:                   # дошли до финиша — 1 программа
        return 1
    c = str(s)
    if c[-2] < c[-1]:            # команда B применима: десятков меньше единиц
        res = int(c[:-2] + c[-1] + c[-2])    # B: две последние цифры местами
        return f(s + 1, e) + f(res, e)       # команды A и B
    return f(s + 1, e)           # B неприменима — только A


print(f(100,141))

    Менять: команды — в return суммой; «через число X» — f(a, X) * f(X, b); «не проходит через X» — ещё if s == X: return 0; команды уменьшают число — первое условие if s < e: return 0. Ловушки: «отбросить последнюю цифру» — s // 10; деление с округлением вверх — (s + 1) // 2; глубокая рекурсия — RecursionError или молчаливое закрытие: см. карточку. → Карточка №13

    №14. Системы счисления¶

    Неизвестная цифра x:

    # №14, демоверсия ЕГЭ-2027 (пример 1): 27x98876₂₂ + 26x51₂₂ + 711x5₂₂, x — неизвестная цифра 22-ричной системы.
# Наименьшее x, при котором значение кратно 21; в ответе — частное от деления на 21. Печатает x и частное:
# Ответ: 3 276296118
import string
alfavit = string.printable[:22] #0123456789abcdefghijkl
for x in alfavit:                # x — цифра-символ: '3', 'a' — f-строка вставит её как есть
    s = int(f'27{x}98876', 22) + int(f'26{x}51', 22) + int(f'711{x}5', 22)
    if s % 21 == 0:
        print(int(x, 22), s // 21)    # // — частное целым числом
        break                    # наименьшее x — первое

    Сколько нулей (единиц, цифр) в записи — цифры по одной, остатками:

    # №14, демоверсия ЕГЭ-2027 (пример 2): 3·3125⁸ + 2·625⁷ − 4·625⁶ + 3·125⁵ − 2·25⁴ − 2025
# записали в системе с основанием 25. Сколько значащих нулей в этой записи?
# Ответ: 10
s = 3 * 3125**8 + 2 * 625**7 - 4 * 625**6 + 3 * 125**5 - 2 * 25**4 - 2025
cnt = 0
while s != 0:
    if s % 25 == 0:              # младшая цифра в системе 25 — остаток
        cnt += 1
    s //= 25                     # отбросить младшую цифру
print(cnt)

    Менять: основание — в string.printable[:b] и int(…, b); две неизвестные — второй цикл for y in alfavit:; наибольшее x — без break, последнее. Ловушки: x числом в f-строке (for x in range(22)) при x = 10 вставит «1» и «0» — число молча другое, поэтому перебираем символы alfavit; int(s, b) — только до 36; частное — //: с / на огромных числах OverflowError; bin(n).count('0') на 1 больше — ноль из 0b. → Карточка №14

    №15. Найти параметр A¶

    # №15, демоверсия ЕГЭ-2027: ДЕЛ(x, A) ∨ ((x ∈ B) → ¬ДЕЛ(x, 22)), B = [70; 90].
# Наибольшее натуральное A, при котором выражение истинно при любом целом x > 0.
# Ответ: 88
def Del(n,m):
    return n % m == 0

for A in range(1, 1000):
    ok = True
    for x in range(1, 10000):
        B = 70 <= x <= 90       # x ∈ [70; 90]
        f = Del(x, A) or (B <= (not Del(x, 22)))   # → — это <=, not — в скобках
        if f == 0:
            ok = False          # нашли x, где ложно, — A не подходит
            break
    if ok:
        otvet = A               # наибольшее — последнее; наименьшее — print(A) и break
print(otvet)

    Отрезки — списком точек: ищем x, где выражение без A ложно, — эти x и есть A:

    # №15 (своя): P = [30; 35], Q = [10; 25], R = [20; 41]. Наименьшая длина отрезка A,
# при котором (x ∈ A) ∨ (x ∈ P) ∨ ((x ∈ Q) → (x ∈ R)) истинно при любом x.
# Ответ: 10 19
# Ответ: 10
P = list(range(30, 36))         # отрезок [30; 35] — правая граница + 1
Q = list(range(10, 26))
R = list(range(20, 42))
A = []                          # A пустой: ищем x, где без A выражение ложно
for x in range(1000):
    f = (x in A) or (x in P) or ((x in Q) <= (x in R))
    if f == 0:
        A.append(x)             # эти x обязаны быть в A

print(A[0], A[-1])              # 10 19
print(20 - 10)                  # 19 нет в условии — берём 20: длина 20 - 10
#если левой границы нет в условии, то делаем ее на 1 меньше
#если правой границы нет в условии, то делаем ее на 1 больше

    Менять: поразрядная конъюнкция — (x & m != 0) вместо Del; две переменные — второй цикл for y, и после внутреннего break — if ok == False: break. Ловушки: not слабее сравнений — каждое (not …) в скобках; наименьшее A — break после первого подходящего; ответ бывает больше 1000 — «наименьшее» не напечатает ничего: расширить range; длинные отрезки списком считаются долго (по 50 000 точек, x до 100 000 — больше 2 минут) — писать P = range(30, 36) без list: in по range мгновенный, а остальное не меняется; если точки A распались на два куска (15-043: [7, 8, 12, 13, 14]) — длина не A[-1] - A[0], разобрать по смыслу. → Карточка №15

    №16. Рекурсивная функция¶

    Как: часто быстрее вручную — выразить всё через одно значение и сократить. На Python — кэш и прогрев:

    # №16: F(n) = n при n <= 3;  F(n) = n * F(n - 1) при n > 3.
# Чему равно значение выражения (F(2026) - F(2025)) / F(2024)?
# Ответ: 4100625
from functools import lru_cache


@lru_cache(None)                 # запоминать уже посчитанные значения
def F(n):
    if n <= 3:                   # условие переписываем как есть
        return n
    return n * F(n - 1)


for i in range(1, 2027):         # прогрев: считаем по порядку снизу вверх,
    F(i)                         # тогда рекурсия не уходит вглубь

print((F(2026) - F(2025)) // F(2024))     # «/» в условии -> «//» в Python

    Ловушки: / из условия — // в Python; без прогрева — RecursionError или Python молча закрывается; int(a / b) неточен на больших числах. → Карточка №16

    №17. Пары и тройки из файла¶

    # №17, демоверсия ЕГЭ-2027 (файл 17.txt): пары соседних чисел, в которых остаток от деления
# на 33 хотя бы одного из элементов равен минимальному элементу последовательности.
# В ответе — количество таких пар и максимальная из их сумм.
# Ответ: 622 174933
f = open('17.txt')              # на экзамене — свой путь: 'D://17.txt'
nums = []
for s in f:
    nums.append(int(s))

mn = min(nums)                  # вспомогательное число — до цикла, один раз

result = []
for i in range(len(nums) - 1):  # пары: - 1, тройки: - 2
    para = nums[i:i+2]          # тройка — nums[i:i+3]
    el = []
    for n in para:
        if n % 33 == mn:
            el.append(n)

    if len(el) >= 1:            # «хотя бы один»; «ровно два» — == 2
        result.append(para)

Summa = []
for para in result:
    Summa.append(sum(para))
print(len(result), max(Summa))

    Менять: тройки — range(len(nums) - 2) и nums[i:i+3]; «ровно два» — len(el) == 2; «оканчивается на 3» — abs(n) % 10 == 3; «четырёхзначное» — 999 < abs(n) < 10000; вспомогательный список (yslMax) — отдельным циклом до основного. Ловушки: % на отрицательных: -17 % 10 = 3 — последние цифры брать от abs(n); len(str(-512)) = 4; пустая строка в конце файла — int('\n') даёт ValueError. → Карточка №17
