    9. Модули-помощники¶

    Коротко

    Модули стандартной библиотеки есть в любом Python, ставить ничего не нужно: from itertools import product — все слова из букв (№8), permutations — перестановки, combinations — наборы по возрастанию; math.isqrt — целый корень (№25); fnmatch(str(x), '3?12*5') — маска (№25); ipaddress.ip_network('узел/маска', 0) — сеть (№10); turtle — Черепаха (№6), координаты — только через round; functools.lru_cache — кэш (§6), re — регулярные выражения (§4).

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter. Строки с ... — тело цикла: набирайте с отступом, а в конце нажмите Enter ещё раз на пустой строке. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Как подключить модуль¶

    >>> import math
>>> math.isqrt(50)
7
>>> from math import isqrt
>>> isqrt(50)
7
    • import math — потом пишут math.isqrt(…), math.ceil(…);
    • from math import isqrt, ceil — только нужные имена, без math.;
    • from ipaddress import * — все имена модуля (так в шаблоне №10 — меньше писать).

    Не называйте свой файл как модуль: программа turtle.py или math.py в папке с решением подменит настоящий модуль, и from turtle import * загрузит её саму — посыпятся ошибки «нет такого имени».

    itertools: перебор слов и наборов (№8)¶

    Нужно Код Пример
    все слова длины n из букв (буквы повторяются) product(буквы, repeat=n) АА, АБ, БА, ББ
    все перестановки (каждая буква один раз) permutations(буквы) или permutations(буквы, k) АБВ, АВБ, БАВ…
    наборы по возрастанию, без повторов combinations(буквы, k) 12, 13, 23 
    >>> from itertools import product, permutations, combinations
>>> [''.join(w) for w in product('АБ', repeat=2)]
['АА', 'АБ', 'БА', 'ББ']
>>> [''.join(w) for w in permutations('АБВ')]
['АБВ', 'АВБ', 'БАВ', 'БВА', 'ВАБ', 'ВБА']
>>> [''.join(w) for w in combinations('1234', 2)]
['12', '13', '14', '23', '24', '34']
>>> len(list(product('АКЦЕНТ', repeat=5)))
7776
    • product и permutations выдают кортежи букв — строку собирает ''.join(w) (§4).
    • Слова идут в порядке букв, которые им дали. Для «слов в алфавитном порядке» — sorted(буквы) (шаблон №8); без sorted — порядок букв из условия:
    >>> from itertools import permutations
>>> [''.join(w) for w in permutations('ТОР')][:3]
['ТОР', 'ТРО', 'ОТР']
>>> [''.join(w) for w in permutations(sorted('ТОР'))][:3]
['ОРТ', 'ОТР', 'РОТ']

    (Решу ЕГЭ 58475: КИВТРО вместо КИВОТР.) - Перестановки букв с повторами — одинаковые слова получаются несколько раз (в КАПКАН две К и две А): set(…) убирает дубли (№8: 288 вместо 156). - «Цифры строго по возрастанию» — сразу combinations: наборы уже упорядочены. - Скорость: product + join + условие — около 3 млн слов в секунду. 60 млн — 15–20 секунд, нормально; 2,5 млрд — 8,5 минут, тогда считать «виды цифр» на местах и умножать (карточка №8, «Подробнее»).

    math: корни, округления, комбинаторика¶

    >>> import math
>>> math.isqrt(10 ** 9), math.sqrt(16)
(31622, 4.0)
>>> math.ceil(7 / 2), math.floor(7 / 2)
(4, 3)
>>> math.log2(1024), math.gcd(12, 18), math.lcm(4, 6)
(10.0, 6, 12)
>>> math.prod([2, 3, 4]), math.comb(5, 2), math.factorial(5)
(24, 10, 120)
>>> math.dist((0, 0), (3, 4))
5.0
    Функция Что делает Где
    isqrt(n) целый корень (вниз), точно и для огромных чисел №25 — делители до корня
    sqrt(x) корень дробью — для «точного квадрата» неточен на больших числах —
    ceil(x), floor(x) округление вверх и вниз до целого №7, №11
    log2(x) двоичный логарифм (сколько бит) №11
    gcd, lcm НОД, НОК (lcm — с Python 3.9) §1
    prod(a) произведение списка №25
    comb(n, k) число сочетаний — проверка подсчёта в №8 №8
    dist(p, q) расстояние между точками №27
    • «Точный квадрат» — math.isqrt(n) ** 2 == n, а не math.sqrt(n) % 1 == 0: у больших чисел дробный корень неточен (§1).
    • math.dist считает по всем координатам: у точки с третьим числом (энергия, высота) получится трёхмерное расстояние — брать dist(p[:2], q[:2]) (№27).
    • ceil для «наименьшего целого числа байт», но если в условии «укажите только целую часть» — int (№7).

    fnmatch: маска (№25)¶

    fnmatch(строка, маска) — подходит ли строка под маску: ? — ровно один любой символ, * — любые символы (в том числе ни одного), [02468] — один символ из перечисленных:

    >>> from fnmatch import fnmatch
>>> fnmatch('3512614035', '3?12?14*5'), fnmatch('31214035', '3?12?14*5')
(True, False)
>>> fnmatch('12345', '12*'), fnmatch('12', '12*')
(True, True)
>>> fnmatch('1234', '1[02468]34'), fnmatch('1334', '1[02468]34')
(True, False)
    • Первый аргумент — строка: fnmatch(str(x), маска).
    • «?» в условии — «одна цифра», а не «чётная»: если в задаче «вместо ? — чётная цифра», это [02468], а не ? (12 вместо 5).
    • Перебирать только кратные делителю из условия — range(K, N + 1, K) (шаблон №25): так 10¹⁰ чисел превращаются в 5 млн. Кратных больше ~10⁷ — уже долго; тогда числа строят по маске сами (карточка №25).

    ipaddress: сети и маски (№10)¶

    >>> from ipaddress import *
>>> net = ip_network('192.168.159.86/255.255.252.0', 0)
>>> net
IPv4Network('192.168.156.0/22')
>>> net.network_address, net.broadcast_address
(IPv4Address('192.168.156.0'), IPv4Address('192.168.159.255'))
>>> net.netmask, net.prefixlen, net.num_addresses
(IPv4Address('255.255.252.0'), 22, 1024)
>>> f'{net.netmask:b}'
'11111111111111111111110000000000'
>>> [int(x) for x in str(net.network_address).split('.')]
[192, 168, 156, 0]
    • 0 вторым аргументом (strict=False) — обязательно, когда указан узел, а не адрес сети: без него — ValueError: … has host bits set.
    • Маска пишется и числом единиц: ip_network('192.168.159.86/22', 0) — то же самое. Перебор маски — range(33): от 0 до 32 единиц (range(32) теряет /32).
    • f'{адрес:b}' — 32 двоичные цифры с ведущими нулями (§7); октеты — str(адрес).split('.').
    • Адреса — по номеру: net[0] — адрес сети, net[-1] — широковещательный, net[1] … net[-2] — компьютеры; все компьютеры — net.hosts(). Срез net[1:-1] — TypeError.
    • Адреса строками не сравнивать: '9.1.1.1' < '10.1.1.1' — False; сравнивают сами адреса ip_address(…).
    >>> from ipaddress import *
>>> ip_network('192.168.159.86/22')
Traceback (most recent call last):
  ...
ValueError: 192.168.159.86/22 has host bits set
>>> net = ip_network('10.0.0.0/30')
>>> net[1], net[-2], list(net.hosts())
(IPv4Address('10.0.0.1'), IPv4Address('10.0.0.2'), [IPv4Address('10.0.0.1'), IPv4Address('10.0.0.2')])
>>> ip_address('9.1.1.1') < ip_address('10.1.1.1')
True

    Неизвестный байт маски (255.255.A.0) — перебирать только 9 возможных значений (0, 128, 192, 224, 240, 248, 252, 254, 255): for A in range(256) падает уже на A = 1 — ValueError: … does not appear to be an IPv4 or IPv6 network (сборник Крылова 2026, в15–в20). Байт адреса (32.0.A.5) — range(256) можно.

    turtle: Черепаха (№6)¶

    Модуль turtle рисует путь исполнителя Черепаха в окне. Команды условия переводятся почти дословно:

    Условие turtle
    Вперёд n / Назад n forward(n * k) / backward(n * k)
    Направо a / Налево a right(a) / left(a) — угол без масштаба
    Повтори k [ … ] for i in range(k):
    Поднять хвост / Опустить хвост penup() / pendown()
    где Черепаха xcor(), ycor() (в пикселях — делить на k)

    Готовый шаблон с масштабом k, tracer(0), left(90) в начале (в условии голова смотрит вверх, в turtle — вправо) и сеткой точек — карточка №6.

    Координаты Черепахи — дробные и неточные. Повороты считаются через синусы, и после поворотов «5» оказывается 4.999999999999999. int отбрасывает дробную часть — получается 4; правильно — round. Проверить можно и без окна: TNavigator — та же «арифметика» Черепахи без рисования:

    >>> from turtle import TNavigator
>>> t = TNavigator()
>>> t.left(90)
>>> for i in range(3):
...     t.forward(3)
...     t.right(90)
...     t.forward(5)
...     t.right(90)
...
>>> t.pos()
(5.00,3.00)
>>> t.xcor()
4.999999999999999
>>> int(t.xcor()), round(t.xcor())
(4, 5)

    На экране (5.00, 3.00), а на деле x чуть меньше 5. На 3000 случайных путях с поворотами на 90° так «портится» каждая третья координата.

    • Масштаб k — только у длин (forward(n * k)), не у углов.
    • Перед сеткой точек — penup(), иначе Черепаха прочертит путь к каждой точке; tracer(0) — рисовать сразу; в конце done() — чтобы окно не закрылось.
    • Сетка у большой фигуры — даже с tracer(0) 108 000 точек рисуются минуту, окно «висит»: точку ставить через 5 шагов (range(…, …, 5)) — 0,2 секунды (Решу ЕГЭ 83136).
    • Признак «точка по одну сторону от всех сторон» годится только для выпуклой фигуры; у «звезды» он молча неверен (Решу ЕГЭ 58242: 27 вместо 99) — подробно в карточке №6.
    Подробнее: collections, heapq

    collections.Counter — готовый подсчёт «значение → сколько раз» (§5); collections.deque — очередь, из которой быстро брать с начала (popleft()); list.pop(0) на сотнях тысяч элементов медленный.

    heapq — «куча»: быстро достаёт наименьшее. В №26 и №22 с очередями — «кто освободится раньше всех»:

    >>> import heapq
>>> h = [17, 5, 30]
>>> heapq.heapify(h)
>>> heapq.heappop(h)
5
>>> heapq.heappush(h, 3)
>>> heapq.heappop(h), heapq.heappop(h)
(3, 17)

    heappop всегда отдаёт наименьшее из оставшихся. Для пар (время, номер) — наименьшее время, при равенстве — наименьший номер (кортежи, §5). На ЕГЭ хватает и min по списку — куча нужна, когда элементов сотни тысяч.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • permutations без sorted — слова не по алфавиту (Решу ЕГЭ 58475: КИВТРО вместо КИВОТР) (№8).
    • Перестановки букв с повторами без set — дубли (№8: 288 вместо 156).
    • product на миллиардах слов — не дождаться; 3 млн слов в секунду (№8).
    • ip_network без 0 — ValueError: has host bits set (№10).
    • Маска range(32) теряет /32 — range(33) (№10).
    • Байт маски range(256) — ValueError на A = 1; только 9 значений (№10, Крылов 2026).
    • net[1:-1] — TypeError; компьютеры — net.hosts() (№10).
    • Адреса строками — '9.1.1.1' < '10.1.1.1' = False (№10).
    • int(ycor() / k) — 8 вместо 9; координаты Черепахи — только round (№6).
    • Масштаб у угла, нет penup() перед сеткой, нет left(90) в начале — рисунок не тот (№6).
    • «По одну сторону от всех сторон» — только для выпуклой фигуры (№6: 27 вместо 99).
    • fnmatch(x, …) с числом — первый аргумент строка str(x); «чётная цифра» — [02468], не ? (№25).
    • math.dist по трём координатам — p[:2] (№27); math.sqrt для «точного квадрата» — isqrt (№25).
    • Свой файл turtle.py, math.py — подменяет модуль.
