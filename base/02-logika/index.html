    2. Условия и логика¶

    Коротко

    Сравнение — == (а = — присваивание), «не равно» — !=; «x от a до b» — a <= x <= b. Одно правило «если … иначе …» — if … else, а не два if. В логических формулах ЕГЭ: → — (x <= y), ≡ — (x == y), ¬ — (not x), и каждую такую часть — в свои скобки: сравнения в Python сильнее and/or и сцепляются в цепочки.

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter. Строки с ... — продолжение (тело if или цикла): набирайте с отступом, а в конце нажмите Enter ещё раз на пустой строке. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Сравнения: True и False¶

    Сравнение отвечает «да» или «нет»: True (истина) или False (ложь).

    Знак Значит Знак Значит
    == равно != не равно
    < меньше <= меньше или равно
    > больше >= больше или равно 
    >>> x = 7
>>> x > 5, x == 7, x != 7
(True, True, False)
>>> 3 <= x <= 10
True
>>> x % 2 == 0
False
    • Один знак = — это «положить в переменную», сравнение — два: if x == 7, а if x = 7 — ошибка.
    • 3 <= x <= 10 — «x от 3 до 10 включительно», как в математике (x ∈ [3; 10]).
    • Арифметика считается раньше сравнения: x % 2 == 0 — без скобок.

    Слова условия → знак. Здесь чаще всего ошибаются на единицу:

    В условии Код
    «больше 500», «превышает», «более» x > 500
    «не меньше 500», «не менее», «хотя бы 500» x >= 500
    «меньше 500», «менее» x < 500
    «не больше 500», «не более», «не превышает» x <= 500
    «делится на 7», «кратно 7», ДЕЛ(x, 7) x % 7 == 0
    «не делится на 7» x % 7 != 0
    «от 10 до 20» (включительно), x ∈ [10; 20] 10 <= x <= 20

    «Более 500 Кбайт»: файл ровно 500 Кбайт не подходит (№11). ДЕЛ(90, A) — «90 делится на A»: 90 % A == 0, делимое первым (№15).

    if, elif, else¶

    if выполняет строки с отступом, только когда условие верно; else — когда неверно. Двоеточие в конце строки и отступ (4 пробела, в IDLE ставится сам) — обязательны:

    >>> x = 14
>>> if x % 2 == 0:
...     print('чётное')
... else:
...     print('нечётное')
...
чётное

    Несколько вариантов — elif («иначе если»): проверки идут сверху вниз, срабатывает первая верная, остальные пропускаются:

    >>> n = 77
>>> if n >= 85:
...     print('отлично')
... elif n >= 70:
...     print('хорошо')
... else:
...     print('надо подтянуть')
...
хорошо

    Одно правило — один if … else. В №5 правило звучит «если …, то дописать одно, иначе — другое». Если записать его двумя отдельными if, второе условие проверится по уже изменённой строке — и сработают оба:

    >>> s = '101'
>>> if s.count('1') % 2 == 0:
...     s += '1'
... else:
...     s += '0'
...
>>> s
'1011'
>>> s = '101'
>>> if s.count('1') % 2 == 0:
...     s += '1'
...
>>> if s.count('1') % 2 != 0:
...     s += '0'
...
>>> s
'10110'

    В строке '101' две единицы — дописываем 1, и всё. Во втором варианте после первого if единиц уже три, и второй if дописал ещё 0. На задаче типа демоверсии 2023 такая запись даёт 12 вместо 16 (№5).

    and, or, not¶

    Связка Верно, когда Пример (x = 15)
    a and b верны оба x % 3 == 0 and x % 5 == 0 → True
    a or b верно хотя бы одно x % 2 == 0 or x > 10 → True
    not a a неверно not x > 10 → False 
    >>> x = 15
>>> x % 3 == 0 and x % 5 == 0
True
>>> x % 2 == 0 or x > 10
True
>>> not x > 10
False
>>> x % 4 != 0
True

    «Не делится» проще и надёжнее писать x % 4 != 0, чем not x % 4 == 0.

    Порядок: сначала арифметика, потом сравнения, потом not, потом and, последним or. Значит, and выполнится раньше or, даже если записан правее. «Делится на 2 или на 3, и при этом больше 10» — без скобок получится другое условие:

    >>> x = 4
>>> x % 2 == 0 or x % 3 == 0 and x > 10
True
>>> (x % 2 == 0 or x % 3 == 0) and x > 10
False

    and проверяет слева направо и останавливается на первом False (or — на первом True). Поэтому то, без чего вторая часть упадёт, — первым:

    >>> a = []
>>> len(a) > 0 and a[0] == 5
False
>>> a[0] == 5 and len(a) > 0
Traceback (most recent call last):
  ...
IndexError: list index out of range

    Это же правило ускоряет программы: быстрые проверки (x % 10 == 7) — первыми, долгие (разложение на множители, проверка простоты) — последними, тогда они считаются только для немногих чисел (№25). И то, что существует не в каждой строке файла (например, «число, которое встречается трижды»), — вычислять внутри условия после and, а не до if (№9).

    Логические формулы (№2, №15)¶

    Формулу из условия переписываем по таблице. Главное правило — каждая операция со значком → ≡ ¬ — в своих скобках:

    В условии Python Пример
    ¬x (не) (not x)
    x ∧ y (и) x and y
    x ∨ y (или) x or y
    x → y (импликация, «следует») (x <= y) или (not x or y)
    x ≡ y (равносильно) (x == y)
    x ≢ y, x ⊕ y (не равносильно, «исключающее или») (x != y)

    Импликация ложна только в одном случае — «из правды следует ложь» (1 → 0). На числах 0 и 1 это ровно x <= y:

    >>> for x in 0, 1:
...     for y in 0, 1:
...         print(x, y, int(x <= y))
...
0 0 1
0 1 1
1 0 0
1 1 1

    Почему скобки обязательны. В логике → и ≡ — самые слабые операции, а в Python <= и == — сильнее and/or. Кроме того, сравнения в Python сцепляются: z == x <= y значит «z == x и x <= y», а не z ≡ (x → y):

    >>> x, y, z = 0, 0, 1
>>> z == x <= y
False
>>> z == (x <= y)
True

    not после сравнения без скобок — вообще ошибка, а not в начале захватывает всё сравнение целиком:

    >>> x, y = 1, 0
>>> x == not y
Traceback (most recent call last):
  ...
SyntaxError: invalid syntax
>>> x == (not y)
True
>>> w, x = 0, 1
>>> not w <= x
False
>>> (not w) <= x
True

    not w <= x — это ¬(w → x), а не (¬w) → x. На 72 задачах №2 из Решу ЕГЭ наивный перевод без своих скобок дал 16 ошибок SyntaxError и 4 тихо неверных ответа. Правило простое: каждый not — в свои скобки, каждая → и ≡ — в свои скобки.

    True — это 1, False — это 0. Условия можно складывать: «ровно два из трёх чисел чётные» —

    >>> True + True + False
2
>>> a, b, c = 12, 7, 30
>>> (a % 2 == 0) + (b % 2 == 0) + (c % 2 == 0) == 2
True

    any и all: «хотя бы один» и «при любом»¶

    all(…) — верно ли условие для всех, any(…) — хотя бы для одного. Внутри — условие и for, как в списковом выражении (§5):

    >>> a = [3, 8, 12]
>>> all(x > 2 for x in a)
True
>>> any(x % 5 == 0 for x in a)
False
>>> all([]), any([])
(True, False)

    В №15 «выражение истинно при любом натуральном x» — это all по x. Например, «наибольшее A, при котором (x < A) → (x² < 50) истинно при любом натуральном x»:

    >>> for A in range(1, 100):
...     if all((x < A) <= (x * x < 50) for x in range(1, 1000)):
...         otvet = A
...
>>> otvet
8

    (Наибольшее — последнее подходящее, поэтому без break; подробно про перебор — §3.)

    В условии Код
    «при любом x», «для всех x», «тождественно истинно» all(… for x in …)
    «найдётся x», «хотя бы при одном x» any(… for x in …)
    «найдутся x, y, при которых выражение ложно» any(not (…) for x … for y …)
    «при любом ходе» соперника (№19–21) all(…) по ходам
    «есть ход», «может выиграть» (№19–21) any(…) по ходам

    all от пустого — True. В №19–21 позиция, из которой нет ни одного хода, по all «засчитывается» как выигрышная для соперника. Если по условию ходов может не быть (например, «добавить n // k камней» при n = 1), этот случай надо проверить отдельно (Решу ЕГЭ 68252: 7 вместо 6).

    Подробнее: побитовое «и», запреты в №8, похожие буквы

    & (№15). x & A — побитовое «и» (§7). Оно сильнее сравнений: x & 5 != 0 = (x & 5) != 0. Но запись x & 17 == 0 <= x & A != 0 — снова цепочка сравнений, а не импликация:

    >>> x, A = 1, 8
>>> x & 17 == 0 <= x & A != 0
False
>>> ((x & 17) == 0) <= ((x & A) != 0)
True

    Поэтому ((x & 17) == 0) — со скобками вокруг каждой части (Решу ЕГЭ 9804: без них — ни одного A). В других языках & слабее ==, так что скобки вокруг x & A полезны всегда.

    «∨» и «∧» с параметром. (A > x) ∨ (A > y) — A больше меньшего из x и y, (A > x) ∧ (A > y) — большего. На бумаге их легко спутать (Крылов-2026: 106 вместо 36), программа по шаблону №15 различает сама.

    Два запрета в №8. «Слово не может начинаться с X и заканчиваться на Y» на ЕГЭ понимают как два отдельных запрета: w[0] != 'X' and w[-1] != 'Y', а не not (w[0] == 'X' and w[-1] == 'Y') (так во всех таких задачах Решу ЕГЭ).

    «Хотя бы одно из». «Запись содержит 14 или 18» — одно условие ('14' in s) or ('18' in s). Если считать отдельно «с 14» и «с 18» и сложить — записи, где есть оба, посчитаются дважды (Решу ЕГЭ 83153: 93 вместо 69, №13).

    Похожие значки и буквы. В скопированной формуле «и»/«или» бывают символами ˄ ˅, а не ∧ ∨ — замена по тексту их пропустит (сборник Крылова, №2). Переменные кириллицей (Д, М) Python разрешает, но русская Р и латинская P на вид одинаковы — NameError или «пустой» ответ. Формулу лучше перенабрать руками латинскими буквами.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Два if вместо if … else — второе условие проверяется по уже изменённым данным (№5: 12 вместо 16).
    • → и ≡ без скобок. z == x <= y — цепочка «z == x и x <= y»; пишите (z == (x <= y)) (№2).
    • not без скобок. x == not y — SyntaxError; not w <= x — это ¬(w → x). Каждый not — в свои скобки (№2, №15).
    • and раньше or. a or b and c = a or (b and c) — скобки по смыслу условия.
    • Цепочка с &. x & 17 == 0 <= x & A != 0 — не импликация; каждую часть в скобки (№15).
    • Знак на единицу. «Более 500» — > 500, «не менее» — >=: файл ровно 500 Кбайт при «более 500» не подходит (№11).
    • ДЕЛ(90, A) — 90 % A == 0, не A % 90 (№15).
    • all([]) — True. Позиция без ходов в №19–21 — проверять отдельно.
    • any и all в №19–21. «Неудачный ход Пети», «Ваня выиграл» — у соперника any; «при любом ходе» — all. Перепутать — неверны все задачи такого вида (№19–21).
    • «Найдутся x, при которых ложно» — any(not (…)); через all ответ уходит на край range (Решу ЕГЭ 61361, №15).
    • Порядок в and. То, без чего вторая часть упадёт (len(a) > 0), — первым; долгие проверки — последними (№9, №25).
    • Символы ˄ ˅ и похожие русские/латинские буквы в скопированной формуле — перенабирать руками (№2).

    Где встречается¶

    №2 (логические формулы, таблица истинности), №5 (if … else в правиле), №8 (запреты на буквы), №9 и №17 (несколько условий через and), №11 («более», «не менее»), №13 («хотя бы одно из»), №15 (импликация, all, &, ДЕЛ), №19–21 (any и all по ходам), №25 (порядок проверок в and).
