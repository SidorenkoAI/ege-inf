    7. Системы счисления и биты¶

    Коротко

    В двоичную — bin(n)[2:] (без 0b), в восьмеричную — oct(n)[2:], в шестнадцатеричную — hex(n)[2:]; обратно — int(s, b) для любого основания от 2 до 36. В другие системы — своя функция: остаток n % b — младшая цифра, n //= b. При основании больше 10 цифры — списком чисел, не строкой. Биты: & — «и», | — «или», >> — сдвиг вправо, f'{x:08b}' — 8 цифр с ведущими нулями.

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter. Строки с ... — тело цикла или функции: набирайте с отступом, а в конце нажмите Enter ещё раз на пустой строке. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Готовые переводы: bin, oct, hex, int¶

    >>> bin(13), oct(13), hex(255)
('0b1101', '0o15', '0xff')
>>> bin(13)[2:]
'1101'
>>> int('1101', 2), int('15', 8), int('ff', 16), int('FF', 16)
(13, 13, 255, 255)
>>> int('2027', 9), int('Z', 36)
(1483, 35)
    • bin, oct, hex дают строку с приставкой 0b, 0o, 0x — её отрезают срезом [2:].
    • int(s, b) — из строки-записи в системе b в обычное число; буквы — любые, большие или маленькие.
    • Основание int — только от 2 до 36 (10 цифр и 26 латинских букв). Больше — своя функция (ниже).

    Цифры двоичной записи. Единицы — s.count('1'), сумма цифр в любой системе — sum(map(int, s)) (до 10), длина — len(s):

    >>> s = bin(2027)[2:]
>>> s
'11111101011'
>>> s.count('1'), s.count('0'), len(s)
(9, 2, 11)
>>> bin(2027).count('0')
3

    bin(n).count('0') — на один ноль больше: ноль из приставки 0b тоже считается (Решу ЕГЭ 92256: 72 вместо 71). Так же с oct, hex — сначала [2:]. Единицы считаются верно (в приставке их нет), поэтому ошибка видна не сразу.

    Обратно в число — int(s, 2): в №5 запись меняют (дописывают цифры, переворачивают) и переводят назад:

    >>> n = 13
>>> s = bin(n)[2:]
>>> s = s + str(s.count('1') % 2)
>>> s, int(s, 2)
('11011', 27)

    Своя функция перевода¶

    В троичную, пятеричную и любую другую систему — делением: остаток от деления на b — младшая (правая) цифра, частное делят дальше, пока не станет 0:

    >>> def to_base(x, b):
...     if x == 0:
...         return '0'
...     s = ''
...     while x > 0:
...         s = str(x % b) + s
...         x //= b
...     return s
...
>>> to_base(13, 3), to_base(2027, 5), to_base(0, 3)
('111', '31102', '0')
>>> int(to_base(123, 7), 7)
123
    • if x == 0: return '0' — без этой строки to_base(0, b) вернёт пустую строку: цифра молча пропадает (№5, Дядя Саша: R(12) = 12 вместо 36, ответ 18 вместо 6). Ноль появляется, когда в запись переводят остаток или разность.
    • Проверка функции — перевести число туда и обратно: int(to_base(123, 7), 7) должно дать 123.
    • str(x % b) годится только до основания 10: при b > 10 цифра «10» превращается в два символа «1» и «0».

    Основание больше 10 — цифры списком. Цифра 10, 11… в строке из str — уже не одна цифра. На случайных 20-значных 25-ричных числах подсчёт нулей по такой строке ошибается в 822 случаях из 1000. Надёжно — список цифр-чисел (так в шаблоне №14):

    >>> def cifry(n, b):
...     c = []
...     while n > 0:
...         c.append(n % b)
...         n //= b
...     return c[::-1]
...
>>> cifry(250, 25)
[10, 0]
>>> cifry(250, 25).count(0)
1
>>> def to_base_str(x, b):
...     s = ''
...     while x > 0:
...         s = str(x % b) + s
...         x //= b
...     return s
...
>>> to_base_str(250, 25), to_base_str(250, 25).count('0')
('100', 2)

    250 = 10 · 25 + 0 — в 25-ричной записи две цифры: «10» и «0». Строка '100' выглядит как три цифры и даёт два нуля.

    Из списка цифр — обратно в число (схема Горнера): «приписать цифру справа» = умножить на основание и прибавить цифру. Работает при любом основании — и при 37, 40, 47, где int(s, b) уже не умеет:

    >>> def chislo(c, b):
...     n = 0
...     for d in c:
...         n = n * b + d
...     return n
...
>>> chislo([10, 0], 25), chislo([1, 1, 0, 1], 2)
(250, 13)
>>> chislo([36, 5], 40)
1445
>>> int('15', 40)
Traceback (most recent call last):
  ...
ValueError: int() base must be >= 2 and <= 36, or 0

    Буквы-цифры¶

    В системах с основанием больше 10 цифры от 10 обозначают латинскими буквами: A = 10, B = 11, … F = 15, G = 16, H = 17 … Z = 35. Строка всех цифр по порядку — номер символа в ней и есть значение цифры:

    >>> D = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ'
>>> D[14], D[17], D.index('G')
('E', 'H', 16)
>>> x = 10
>>> int(f'98{x}79', 19)
23334460
>>> int(f'98{D[x]}79', 19)
1231513
>>> int('98A79', 19)
1231513

    x в f-строке — числом нельзя. Запись «98x79₁₉» при x = 10 — пятизначное число с цифрой A. А f'98{x}79' подставляет два символа «1» и «0» — получается шестизначное число, другое, и ошибки нет. В 6 из 14 задач №14 Решу ЕГЭ с цифрой x (все — «наибольшее x») так получается неверный ответ. Цифру подставлять символом D[x] или считать по списку chislo([9, 8, x, 7, 9], 19).

    Первая цифра записи — не ноль. «Число 3x5₇» с неизвестной старшей цифрой — перебор с 1, иначе находятся лишние «решения» (Решу ЕГЭ 76682: 39 решений вместо 1). А основание больше самой большой цифры записи: в «x5₇» не бывает цифры 7.

    Подробнее: что ещё умеет int

    int пропускает пробелы по краям и знак подчёркивания между цифрами (так в Python можно писать 1_000_000):

    >>> int(' 101 ', 2), int('1_0', 2)
(5, 2)
>>> sum(map(int, ' 101 '))
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: ' '

    В №12 пустая клетка ленты — _: если перевести ленту '1_0' в число, int молча склеит 10. А sum(map(int, s)) на строке с пробелами падает — сначала s.strip().

    Биты: & | ^ >> <<¶

    Над целыми числами есть действия «по битам» — по цифрам двоичной записи:

    Действие Запись Пример Результат
    «и»: 1, где у обоих 1 a & b 12 & 10 (1100 и 1010) 8 (1000)
    «или»: 1, где хоть у одного 1 a | b 12 | 10 14 (1110)
    «исключающее или»: 1, где разные a ^ b 12 ^ 10 6 (0110)
    сдвиг вправо на k — отбросить k младших цифр a >> k 13 >> 1 6 (= 13 // 2)
    сдвиг влево на k — приписать k нулей a << k 13 << 2 52 (= 13 · 4) 
    >>> 12 & 10, 12 | 10, 12 ^ 10
(8, 14, 6)
>>> 13 >> 1, 13 << 2
(6, 52)
>>> 13 & 1, 12 & 1
(1, 0)
>>> 2 ** 10, 1 << 10
(1024, 1024)
    • x & 1 — последняя двоичная цифра (1 — нечётное), x >> k = x // 2**k, x << k = x * 2**k.
    • ^ — не степень! 2 ^ 10 = 8 («исключающее или»), степень — 2 ** 10.
    • В №15 x & A — «поразрядная конъюнкция» из условия; & сильнее сравнений: x & 5 != 0 = (x & 5) != 0 (§2).

    Ведущие нули. bin записывает число без ведущих нулей. В №10 октет IP-адреса — ровно 8 цифр, адрес — 32: нужен формат с шириной f'{x:08b}':

    >>> bin(5)[2:], f'{5:b}', f'{5:08b}'
('101', '101', '00000101')
>>> ip = (10 << 24) + 1
>>> bin(ip).count('0'), f'{ip:032b}'.count('0')
(26, 29)
>>> f'{ip:032b}'.count('1')
3

    Адрес 10.0.0.1 в двоичной — 32 цифры: 3 единицы и 29 нулей. bin(ip).count('0') теряет ведущие нули и добавляет ноль из 0b — неверно; единицы считает верно. Адрес из модуля ipaddress форматируется так же: f'{адрес:b}' — 32 цифры (§9).

    ~ в Python — отрицательное число: ~5 = −6, а не «инверсия 32 бит». Перевернуть 32 бита маски — ~mask & 0xFFFFFFFF (0xFFFFFFFF — 32 единицы); широковещательный адрес — ip | (~mask & 0xFFFFFFFF). Проще — модуль ipaddress (§9, карточка №10).

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • bin(n).count('0') — на 1 больше: ноль из 0b; сначала [2:] (Решу ЕГЭ 92256: 72 вместо 71).
    • to_base(0, b) без if x == 0 — пустая строка, цифра пропадает (№5: 18 вместо 6).
    • str(n % b) при b > 10 — «10» становится двумя цифрами; цифры — списком (№14: 822 ошибки из 1000 случайных).
    • x в f-строке числом — f'98{x}79' при x = 10 вставляет «1» и «0» (№14: 6 из 14 задач Решу ЕГЭ — неверно); символом D[x] или списком.
    • int(s, b) — только до 36 — ValueError; при больших основаниях — chislo(список, b) (№14).
    • Первая цифра — не ноль при переборе неизвестной старшей цифры (Решу ЕГЭ 76682: 39 решений вместо 1).
    • bin теряет ведущие нули — 32 цифры адреса: f'{ip:032b}', октет: f'{x:08b}' (№10).
    • ^ — не степень, ~x — отрицательное число; 32 бита — ~mask & 0xFFFFFFFF (№10).
    • int('1_0', 2) = 2 — подчёркивание между цифрами int пропускает (лента №12).
    • Буквы: A = 10 … F = 15, G = 16, H = 17 — по строке D, не в уме (№14).
    • Исходное число — без ведущих нулей, а запись после изменений — может с ними: «получилось 240 — наименьшее исходное» 271, а не 15 (№12, Крылов в19).

    Где встречается¶

    №5 (bin, int(s, 2), своя to_base), №10 (октеты, 32 бита, &, |), №12 (лента в число), №14 (cifry, chislo, цифра x, основание больше 36), №15 (поразрядная конъюнкция &).
