    8. Файлы¶

    Коротко

    Число в строке — a = [int(s) for s in open('17.txt')]; несколько чисел в строке — map(int, s.split()); одна длинная строка (№24) — open('24.txt').readline().strip(). Первая строка с количеством — f.readline() до цикла. Пустая строка в конце файла — ValueError: читать if s.strip(). Текст с русскими буквами — encoding='utf-8'. Сначала посмотрите файл в Блокноте: есть ли первая строка с количеством, чем разделены числа, нет ли запятых в дробях.

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter. Примеры сами создают маленькие файлы (open('chisla.txt', 'w').write(…); Python в ответ напишет, сколько символов записал) — файл появится в текущей папке (§0), его можно открыть Блокнотом. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Открыть и прочитать¶

    open('имя') открывает файл на чтение. Файл — это строки, и for s in open(…) проходит по ним по одной. Каждая строка приходит с переводом строки \n в конце (кроме, может быть, последней):

    >>> open('chisla.txt', 'w').write('15\n-7\n42\n')
9
>>> for s in open('chisla.txt'):
...     print(repr(s))
...
'15\n'
'-7\n'
'42\n'
>>> open('chisla.txt').readlines()
['15\n', '-7\n', '42\n']
>>> open('chisla.txt').read()
'15\n-7\n42\n'

    repr(s) показывает строку «как есть», со спецсимволами. Три способа:

    Нужно Код Что получится
    по строкам, по одной for s in open(f): строки с \n
    все строки списком open(f).readlines() список строк с \n
    весь файл одной строкой open(f).read() одна строка, внутри \n
    одну (следующую) строку f.readline() строка с \n; в конце файла — ''

    Числа по одному в строке (№17)¶

    int сам отбрасывает пробелы и \n по краям, поэтому число получается прямо из строки файла:

    >>> open('chisla.txt', 'w').write('15\n-7\n42\n')
9
>>> a = [int(s) for s in open('chisla.txt')]
>>> a
[15, -7, 42]
>>> int(' 7\n')
7

    Пустая строка в конце файла (лишний Enter) — int('\n') падает. Пропускать пустые — if s.strip():

    >>> open('chisla.txt', 'w').write('15\n-7\n42\n\n')
10
>>> a = [int(s) for s in open('chisla.txt')]
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: '\n'
>>> a = [int(s) for s in open('chisla.txt') if s.strip()]
>>> a
[15, -7, 42]

    s.strip() — строка без пробелов и \n по краям; у пустой строки получается '', а пустая строка в if — «ложь» (§2).

    Несколько чисел в строке¶

    s.split() режет строку по пробелам и табуляции (сколько бы их ни было) и сам выбрасывает \n. Числа — map(int, …); если в каждой строке ровно два-три числа, их сразу раскладывают по переменным:

    >>> open('pary.txt', 'w').write('3\n10 25\n7 3\n40 1\n')
17
>>> f = open('pary.txt')
>>> n = int(f.readline())
>>> p = []
>>> for s in f:
...     a, b = map(int, s.split())
...     p.append((a, b))
...
>>> n, p
(3, [(10, 25), (7, 3), (40, 1)])
>>> list(map(int, '5\t17  3\n'.split()))
[5, 17, 3]

    Первая строка — до цикла. В №26, №27 и многих №17 в первой строке — количество (N) или параметры (N и K). Её читают f.readline(), а цикл for s in f продолжает со следующей строки. Но бывает и без неё: в файлах сборника Крылова (№26, в9 и в10) и Решу ЕГЭ 51995 строки с N нет — сначала посмотреть файл. Обратный случай — первая строка с количеством есть, а в условии о ней ни слова (№17, Решу ЕГЭ 59784): Решу ЕГЭ и КомпЕГЭ считают её элементом последовательности (2453 с ней, 2452 без).

    Пустая строка в середине или в конце — a, b = map(int, s.split()) падает с not enough values to unpack:

    >>> open('pary.txt', 'w').write('10 25\n\n7 3\n')
11
>>> for s in open('pary.txt'):
...     a, b = map(int, s.split())
...
Traceback (most recent call last):
  ...
ValueError: not enough values to unpack (expected 2, got 0)
>>> p = [tuple(map(int, s.split())) for s in open('pary.txt') if s.strip()]
>>> p
[(10, 25), (7, 3)]

    Такая строка встретилась в файле ЕГЭ-2021 на КомпЕГЭ (1868, №26).

    Таблица чисел (№9, №18 — данные из электронной таблицы) — список строк, каждая — список чисел: t = [list(map(int, s.split())) for s in open('9.txt')], клетка — t[i][j].

    Одна длинная строка (№24)¶

    В №24 файл — одна строка из сотен тысяч символов. readline() даёт её с \n, который попадёт в подсчёты, — strip() убирает его:

    >>> open('24.txt', 'w').write('XYZZYX\n')
7
>>> s = open('24.txt').readline()
>>> s, len(s)
('XYZZYX\n', 7)
>>> s = open('24.txt').readline().strip()
>>> s, len(s)
('XYZZYX', 6)

    Дробные числа и текст¶

    Дробные — float. int('4582.0') — ошибка (№23: вес ребра в файле записан как 4582.0):

    >>> int('4582.0')
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: '4582.0'
>>> float('4582.0'), int(float('4582.0'))
(4582.0, 4582)
>>> float('0,5')
Traceback (most recent call last):
  ...
ValueError: could not convert string to float: '0,5'
>>> float('0,5'.replace(',', '.'))
0.5

    Запятая в дробях — так числа приходят из таблицы с русскими настройками (№3, старый №9 с измерениями): float(x.replace(',', '.')).

    Данные из таблицы — через Блокнот. Если данные в .ods или .xlsx, а решать хочется программой: в таблице Ctrl+A, Ctrl+C → Блокнот, Ctrl+V → сохранить как 9.txt рядом с программой. Клетки окажутся разделены табуляцией:

    >>> s = '42\tМука пшеничная\t50\n'
>>> s.split()
['42', 'Мука', 'пшеничная', '50']
>>> s.rstrip('\n').split('\t')
['42', 'Мука пшеничная', '50']
    • Только числа — s.split() без аргумента (split(' ') и split(';') на табуляции не режут — ValueError в int).
    • Текст с пробелами (названия товаров в №3) — s.rstrip('\n').split('\t'): split() разрежет название на слова.
    • 28 000 строк вставлять в Блокнот, а не в окно редактора: большие вставки редакторы кода «подвешивают».

    Русские буквы — encoding='utf-8'. Без него Windows читает файл в своей кодировке (cp1251), и русский текст из файла UTF-8 превращается в РџСЂРёРІРµС‚; в Linux наоборот — файл cp1251 даёт UnicodeDecodeError (§0). Файлы с латиницей и цифрами (почти все файлы ЕГЭ) читаются везде одинаково:

    >>> open('slova.txt', 'w', encoding='utf-8').write('Привет\n')
7
>>> open('slova.txt', encoding='utf-8').read()
'Привет\n'
>>> open('slova.txt', encoding='cp1251').read()
'РџСЂРёРІРµС‚\n'

    Где лежит файл и что делать с FileNotFoundError — §0 «Файл данных».

    Подробнее: время строкой, зависимости №22, необычные переводы строк, with

    Время ЧЧ:ММ:СС с ведущими нулями сравнивается и сортируется как строка — в секунды переводить не нужно (№26, демо-2027). Без ведущих нулей (9:05) — уже нельзя: '9:05' > '10:00'.

    >>> '08:15:00' < '11:59:59' < '12:00:00'
True
>>> sorted(['12:00:01', '08:30:00', '11:59:59'])
['08:30:00', '11:59:59', '12:00:01']
>>> '9:05' < '10:00'
False

    Зависимости в №22 — в клетке текст 3;25, бывает 109; 112 и даже 101, 102 (Решу ЕГЭ 75259, 75286); у независимого процесса — пустая клетка или 0:

    >>> def zavisimosti(z):
...     return [int(x) for x in z.replace(',', ';').split(';') if x.strip() not in ('', '0')]
...
>>> zavisimosti('3;25'), zavisimosti('109; 112'), zavisimosti('101, 102'), zavisimosti('0'), zavisimosti('')
([3, 25], [109, 112], [101, 102], [], [])

    Переводы строк. Файл из Windows (\r\n) Python в Linux читает так же, как \n. Бывают файлы, где строки разделены одним \r (старый формат Mac; 6 файлов №17 на Решу ЕГЭ): Блокнот покажет одну длинную строку, а Python читает построчно правильно.

    with open(…) as f: — тот же open, но файл закрывается сам в конце блока. Для чтения на ЕГЭ разницы нет; при записи без закрытия файл может остаться недописанным — пишите через with.

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • Пустая строка в конце файла — int('\n'): ValueError; с двумя числами — not enough values to unpack (№17, №23, №26). Читать if s.strip().
    • Первая строка с количеством — читать до цикла f.readline(); но в некоторых файлах её нет, а где-то её нужно считать элементом (№17: Решу ЕГЭ 59784, 2453 вместо 2452) — смотреть файл и условие.
    • \n в строке №24 — readline() без strip(): на символ длиннее, \n попадает в подсчёты.
    • int('4582.0') — ValueError; дробные — float (№23). float('0,5') — запятая из таблицы: replace(',', '.') (№3, №9).
    • split(' ') на табуляции — не режет; числа — split() без аргумента; текст с пробелами — split('\t') (№3, №9).
    • Без encoding='utf-8' русский текст в Windows — РџСЂРёРІРµС‚, в Linux — UnicodeDecodeError (§0).
    • FileNotFoundError — файл не в папке программы, скрытое расширение 17.txt.txt, в Linux — регистр букв (§0).
    • Время с ведущими нулями сравнивать строкой можно, без нулей — нельзя (№26).
    • Зависимости №22 — бывают ;, ;, , и пустая клетка — replace(',', ';').split(';') + strip().

    Где встречается¶

    №3 (лист таблицы через Блокнот, запятая в дробях), №9 (таблица чисел через табуляцию), №17 (число в строке, первая строка), №18 (таблица клеток), №22 (зависимости), №23 (рёбра с дробным весом), №24 (одна длинная строка), №26 (первая строка N и K, время строкой), №27 (точки с дробными координатами).
