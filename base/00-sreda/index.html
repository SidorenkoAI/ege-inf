    0. Справка и рабочее место на экзамене¶

    Коротко

    На экзамене — компьютер без интернета: Python 3.12+ со средой IDLE, таблицы — МосТех.Таблицы (аналог LibreOffice Calc), не Excel, Блокнот. Программу сохраняйте в одну папку с файлом данных и запускайте F5; остановить — Ctrl+C. Под Linux: копировать в IDLE — Ctrl+Shift+C, имена файлов различают 17.txt и 17.TXT, кодировка — UTF-8.

    Как устроена справка¶

    • База (этот раздел) — язык Python и таблицы: в начале каждой темы рамка «Коротко», ниже подробности, в конце типичные ошибки и ссылки на номера ЕГЭ.
    • Номера 1–27 — карточка на каждый номер: как узнать задачу, шаблон, что в нём менять под условие, пример с разбором, разновидности, скрытые ловушки, «потренируйся» — задачи номера в боте.
    • Шпаргалка — все шаблоны на одной странице для печати (готовится).

    Как готовиться по карточке: прочитать «Коротко» и шаблон → набрать шаблон самому в IDLE → решить пример из карточки и сверить ответ → решать задачи номера в боте. Примеры со строками >>> набирайте в окне IDLE Shell — так, как описано в оглавлении базы.

    Что будет на компьютере¶

    Ориентировочный перечень программ для ЕГЭ по информатике 2027 года (окончательный список утверждает регион — его публикуют заранее, не позже 1 марта):

    Что Программа Зачем на ЕГЭ
    Python Python 3.12 и выше со средой IDLE основной способ: большинство номеров
    Электронные таблицы МосТех.Таблицы (аналог LibreOffice Calc) №3, №9, №18, №22 — табличные способы; проверка
    Текстовый редактор Блокнот (KWrite, Kate) посмотреть файл данных, вставить данные из таблицы (№9)
    Просмотр файлов Okular (PDF), Gwenview (картинки) открыть условие или рисунок
    Архиватор Ark если файлы выдадут архивом
    Другие языки КуМир, PascalABC.NET, Code::Blocks, IntelliJ IDEA в справочнике не используются

    Интернета нет, и справки по Python под рукой может не оказаться — шаблоны нужно помнить. Дополнительные модули (numpy, pandas) в перечне не указаны: в справочнике только то, что входит в сам Python.

    IDLE: как работать¶

    В IDLE два вида окон:

    • IDLE Shell — открывается при запуске, строки с >>>: набрали команду — сразу ответ. Удобно, чтобы проверить кусочек (-17 % 10, int('0012')) и посмотреть результат программы.
    • Окно программы — File → New File (Ctrl+N): здесь пишут программу целиком.

    Порядок работы:

    1. File → New File, написать программу.
    2. Сохранить (Ctrl+S) — в ту же папку, где лежит файл данных (17.txt, 24.txt…). Имя — латиницей, например n17.py; не называйте файл как модуль Python (turtle.py, fnmatch.py, ipaddress.py) — тогда import возьмёт ваш файл вместо модуля.
    3. F5 (Run → Run Module) — запуск; результат появится в окне IDLE Shell. Перед запуском IDLE попросит сохранить изменения и сделает папку программы текущей — поэтому open('17.txt') найдёт файл, лежащий рядом.
    4. Программа считает долго? Ctrl+C в окне Shell — остановить (или Shell → Restart Shell, Ctrl+F6). Нет ответа за 2–3 минуты — скорее всего, нужен способ побыстрее (смотрите «Типичные ошибки» в карточке номера).

    Отступы IDLE ставит сам после строки с : (4 пробела). Сдвинуть выделенный блок — Ctrl+] и Ctrl+[. Меню IDLE — на английском: File, Edit, Format, Run, Shell, Options.

    Клавиши в Windows и Linux различаются (так IDLE настроен по умолчанию — наборы «IDLE Classic Windows» и «IDLE Modern Unix»):

    Действие Windows Linux
    запустить программу F5 F5
    остановить программу (в Shell) Ctrl+C Ctrl+C
    копировать Ctrl+C Ctrl+Shift+C (или Ctrl+Insert)
    вставить Ctrl+V Ctrl+V
    отменить / вернуть Ctrl+Z / Ctrl+Shift+Z Ctrl+Z / Ctrl+Shift+Z
    найти Ctrl+F Ctrl+F
    заменить Ctrl+H Ctrl+R
    закомментировать / раскомментировать Alt+3 / Alt+4 Ctrl+D / Ctrl+Shift+D
    предыдущая команда в Shell Alt+P Alt+P
    перезапустить Shell Ctrl+F6 Ctrl+F6

    Если сочетание не срабатывает — то же самое есть в меню Edit (Copy, Paste, Replace) и Format (Comment Out Region). Набор клавиш виден в Options → Configure IDLE → Keys.

    Файл данных¶

    Где лежат файлы задания и куда сохранять свои, скажет организатор в аудитории. Проще всего — программа в той же папке, что и файл данных, и в ней короткое имя: open('17.txt').

    Если Python пишет FileNotFoundError:

    • проверьте имя: в Windows расширения бывают скрыты (файл называется 17.txt.txt или 17.TXT), в Linux 17.TXT и 17.txt — разные имена;
    • проверьте папку: программа сохранена рядом с файлом? Текущую папку покажет import os; print(os.getcwd());
    • или укажите полный путь. В Windows — с r перед кавычками (или с прямыми чёрточками /), в Linux — от /home:
    open(r'C:\ЕГЭ\17.txt')            # Windows: r — чтобы \ не превратилась в спецсимвол
open('C:/ЕГЭ/17.txt')             # Windows: так тоже можно
open('/home/user/ЕГЭ/17.txt')     # Linux: путь видно в свойствах файла

    Без r обратная черта портит путь: \n внутри строки — это перевод строки, а \t — табуляция:

    >>> print('C:\new')
C:
ew
>>> print(r'C:\new')
C:\new

    Как читать числа и строки из файла — раздел «Файлы» (готовится) и карточки №17, №24, №26.

    Windows или Linux: что меняется¶

    В перечне 2027 года — программы для Linux (Kate, Okular, Gwenview, Ark — из Linux-окружения KDE), так что экзамен может проходить под Linux; в других регионах и в прошлые годы — под Windows. Шаблоны справочника работают одинаково, а различаются мелочи:

    Windows Linux
    путь к файлу C:\Users\…, черта \ /home/…, черта /
    17.TXT и 17.txt один и тот же файл разные файлы
    кодировка open() без encoding cp1251 UTF-8
    копировать в IDLE Ctrl+C Ctrl+Shift+C
    таблицы LibreOffice Calc (бывает МойОфис, Р7-Офис) МосТех.Таблицы — аналог LibreOffice Calc
    файловый менеджер Проводник Dolphin (или другой)
    конец строки в файле \r\n \n — Python читает оба одинаково

    Кодировка — только для файлов с русскими буквами. Файлы демоверсии 2027 — цифры и латиница, им кодировка не важна. А свой файл с русским текстом (например, лист таблицы, вставленный в Блокнот, — альтернатива №3 на Python) в Windows может прочитаться «кракозябрами»: Блокнот Windows 11 сохраняет в UTF-8, а Python в Windows по умолчанию читает в cp1251. В Linux наоборот: файл в cp1251 даёт UnicodeDecodeError. Лечение одно — указать кодировку явно: open('3.txt', encoding='utf-8'). Вот как выглядит UTF-8, прочитанный как cp1251:

    >>> 'Привет'.encode('utf-8').decode('cp1251')
'РџСЂРёРІРµС‚'

    Увидели РџСЂ… — допишите encoding='utf-8'; UnicodeDecodeError — попробуйте encoding='cp1251'.

    Глубина рекурсии с lru_cache ограничена в обеих системах, и sys.setrecursionlimit не помогает: по нашему замеру Windows (Python 3.12.0) падает уже при глубине ≈ 500, Linux (Python 3.12.3) — при ≈ 3300 (RecursionError). Поэтому в №16 и №13 шаблон «кэш + прогрев» (№16) — он работает везде. Рекурсия без кэша на глубину 100 000 прошла и там, и там.

    Раскладку клавиатуры (русская/латинская) в Linux могут переключать не тем сочетанием, что дома, — уточните у организатора в начале экзамена. Буквы для программы набирайте сами, а не копируйте из условия: в PDF латинская «O» и русская «О» выглядят одинаково (раздел «Строки»).

    Электронные таблицы: LibreOffice¶

    Excel на экзамене нет — будет МосТех.Таблицы, аналог LibreOffice Calc (в Windows-регионах — обычно сам LibreOffice). Табличные способы справочника проверены в LibreOffice 26.8; в МосТех.Таблицах мы их не запускали — они должны совпасть, но попробуйте на пробном экзамене.

    Самое нужное:

    • формула начинается с =, аргументы — через точку с запятой: =ЕСЛИ(A1>0;1;0); названия функций — русские: СУММ, МАКС, СЧЁТЕСЛИ, ВПР;
    • $ закрепляет столбец или строку при протягивании: $A$1, A$1;
    • протянуть формулу — потянуть маркер в правом нижнем углу клетки;
    • автофильтр — Ctrl+Shift+L, найти и заменить — Ctrl+H;
    • сумма видимых строк после фильтра — ИТОГ(9;…) (в Excel — ПРОМЕЖУТОЧНЫЕ.ИТОГИ), ссылка на другой лист — $Лист.A1 (в Excel — Лист!A1).

    Подробно — раздел «Электронные таблицы» (готовится). Где таблица — основной или запасной способ: №3 (база данных), №9 (условия по строкам), №18 (робот), №19–21 (позиции игры), №22 (процессы), №17 (проверка в таблице).

    Перед экзаменом¶

    • Узнайте перечень программ своего региона: какая система (Windows или Linux), версия Python, есть ли IDLE.
    • Тренируйтесь в IDLE: набрать шаблон, сохранить рядом с файлом, F5, остановить Ctrl+C. Под Linux — потренируйтесь копировать (Ctrl+Shift+C) и вставлять.
    • Табличные номера решайте в LibreOffice Calc — формулы и окна в нём не такие, как в Excel.
    • Помните, что интернета и справки не будет: шаблоны из шпаргалки нужно знать наизусть.
