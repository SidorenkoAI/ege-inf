    5. Списки, множества, словари¶

    Коротко

    Список [5, 8, 3] — числа по порядку: append добавляет, len, sum, min, max отвечают; подходящие значения собирают в список и спрашивают len(s), max(s). Множество set(a) — без повторов («различные»), словарь {'A': 5} — ключ → значение. sorted(a) — новый отсортированный список, a.sort() меняет сам a и возвращает None. max([]) — ошибка: проверять if s: или max(s, default=0).

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter. Строки с ... — тело цикла: набирайте с отступом, а в конце нажмите Enter ещё раз на пустой строке. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Список¶

    Список — несколько значений в квадратных скобках через запятую. Номера (индексы) и срезы — как у строк (§4): с нуля, a[-1] — последний, a[1:3] — с 1-го по 2-й:

    >>> a = [5, 8, 3, 9]
>>> len(a), a[0], a[-1], a[1:3]
(4, 5, 9, [8, 3])
>>> a.append(4)
>>> a
[5, 8, 3, 9, 4]
>>> sum(a), min(a), max(a)
(29, 3, 9)
>>> 8 in a, 7 in a
(True, False)
>>> a.count(3), a.index(9)
(1, 3)
    Нужно Код
    пустой список a = []
    добавить в конец a.append(x)
    добавить несколько a += [x, y]
    длина, сумма, наименьшее, наибольшее len(a), sum(a), min(a), max(a)
    есть ли x x in a
    сколько раз x встречается, где первое a.count(x), a.index(x)
    список из n нулей [0] * n
    символы строки списком list('1011') → ['1', '0', '1', '1']

    Список, в отличие от строки, можно менять: a[1] = 0. Это нужно, например, для ленты машины Тьюринга в №12 — строку переводят в список list(s), правят по клеткам, а обратно собирают ''.join(lenta).

    >>> a = [5, 8, 3]
>>> a[1] = 0
>>> a
[5, 0, 3]
>>> b = a
>>> c = list(a)
>>> a[0] = 7
>>> b, c
([7, 0, 3], [5, 0, 3])

    b = a — не копия, а второе имя того же списка: изменили a — изменился и b. Копия — list(a) или a[:]. Нужна, когда исходный список ещё понадобится (№12: «сколько клеток изменилось» — сравнить ленту до и после).

    Отрицательный номер — не ошибка. a[-1] — последний элемент, поэтому номер, ушедший левее нуля, молча берёт элемент с конца. Справа за концом — ошибка:

    >>> lenta = ['0', '1', '1']
>>> lenta[-1]
'1'
>>> lenta[3]
Traceback (most recent call last):
  ...
IndexError: list index out of range

    В №12 головка, ушедшая левее начала ленты, пишет в её конец — ответ неверный, ошибки нет (4057 вместо 6124). Поэтому ленту дополняют пустыми клетками с обеих сторон: ['_'] * 10 + list(s) + ['_'] * 10.

    Собрать подходящие — и ответить¶

    Главный приём для ответов «количество и максимум», «количество и сумма» (№17, №9, №26): все подходящие значения — в список, потом len, max, min, sum:

    >>> a = [12, -35, 47, 50, -8, 23]
>>> s = []
>>> for i in range(len(a) - 1):
...     if (a[i] + a[i + 1]) % 3 == 0:
...         s.append(a[i] + a[i + 1])
...
>>> s
[12, 42, 15]
>>> len(s), max(s)
(3, 42)

    Так не нужно думать, с чего начинать максимум: счётчик maxi = 0 ошибается, когда все подходящие отрицательные. И max — от списка подходящих: max(a) по всем числам даёт другой ответ (демоверсия №17: 177 727 вместо 174 933).

    Пустой список. Если ни одно значение не подошло (или открыт не тот файл), max и min падают, а sum и len дают 0:

    >>> s = []
>>> max(s)
Traceback (most recent call last):
  ...
ValueError: max() ...
>>> max(s, default=0), sum(s), len(s)
(0, 0, 0)

    «Если подходящих нет, запишите 0» — max(s, default=0) или if s:. Деление на длину пустого списка — ZeroDivisionError. У простого числа нет делителей кроме 1 и самого себя — список нетривиальных делителей пуст (№25).

    Списковые выражения¶

    Короткая запись «собрать список в одну строку»: что положить, по чему пройти и (необязательно) какое условие:

    >>> a = [12, -35, 47, 50, -8, 23]
>>> [x for x in a if x > 0]
[12, 47, 50, 23]
>>> [abs(x) for x in a]
[12, 35, 47, 50, 8, 23]
>>> len([x for x in a if x % 2 == 0])
3
>>> [int(c) for c in '2027']
[2, 0, 2, 7]
>>> list(map(int, '5 17 3'.split()))
[5, 17, 3]

    [int(c) for c in s] — цифры числа списком, list(map(int, строка.split())) — числа из строки файла (§8).

    Сортировка¶

    >>> a = [5, 8, 3, 9, 3]
>>> sorted(a)
[3, 3, 5, 8, 9]
>>> sorted(a, reverse=True)
[9, 8, 5, 3, 3]
>>> a
[5, 8, 3, 9, 3]
>>> a.sort()
>>> a
[3, 3, 5, 8, 9]
>>> b = [5, 8, 3].sort()
>>> print(b)
None
    • sorted(a) возвращает новый список, a не меняется. a.sort() сортирует сам a и ничего не возвращает: b = a.sort() положит в b пустое значение None.
    • reverse=True — по убыванию.
    • key=… — по какому признаку сортировать: sorted(slova, key=len) — по длине; при равенстве порядок сохраняется.

    Кортежи (значения в круглых скобках: (3, 'б')) сравниваются по первому элементу, при равенстве — по второму. Так сортируют рейтинги в №26 и выбирают «меньше рёбер, при равенстве — меньшая сумма» в №23. Другой порядок — через key: минус перед числом — «это поле по убыванию»:

    >>> pary = [(3, 'б'), (1, 'в'), (3, 'а')]
>>> sorted(pary)
[(1, 'в'), (3, 'а'), (3, 'б')]
>>> sorted(pary, key=lambda p: (-p[0], p[1]))
[(3, 'а'), (3, 'б'), (1, 'в')]
>>> (2, 100) < (3, 0)
True

    lambda p: (-p[0], p[1]) — короткая функция «по элементу p вернуть ключ сортировки» (функции — §6).

    min и max тоже понимают кортежи и key. «При каком N значение R наименьшее» (№5) — список пар (R, N): min найдёт наименьшее R, а [1] возьмёт его N. «Ближайшее к X» — key с расстоянием:

    >>> pary = [(120, 4), (101, 5), (133, 6), (101, 7)]
>>> min(pary)
(101, 5)
>>> min(pary)[1]
5
>>> X = 125
>>> min([120, 101, 133], key=lambda r: abs(r - X))
120

    Две наибольших — сортировкой, не через set. set выбросит повтор, и вторая из двух равных пропадёт:

    >>> a = [26102, 15000, 26102, 9000]
>>> s = sorted(set(a), reverse=True)
>>> s[0] + s[1]
41102
>>> b = sorted(a, reverse=True)
>>> b[0] + b[1]
52204

    (Демоверсия-2027 №26: две копии по 26 102.) А вот «три наименьших различных» (№9) — как раз через set: sorted(set(v))[:3].

    Множество¶

    Множество set — значения без повторов и без порядка. Нужно, чтобы считать «различные», быстро проверять «есть ли x» и убирать дубли:

    >>> a = [3, 1, 3, 2, 1]
>>> set(a)
{1, 2, 3}
>>> len(set(a))
3
>>> m = {2, 4, 6}
>>> m.add(8)
>>> 4 in m, 5 in m
(True, False)
>>> {1, 2, 3} & {2, 3, 4}, {1, 2} | {2, 5}, {1, 2, 3} - {2}
({2, 3}, {1, 2, 5}, {1, 3})
>>> type({}), type(set())
(<class 'dict'>, <class 'set'>)
    • len(set(a)) == len(a) — все элементы разные; len(set(s)) == 3 — в строке ровно 3 разные буквы (№8, №9).
    • & — общие, | — все вместе, - — кроме.
    • Пустое множество — set(), а {} — пустой словарь.
    • x in m у множества мгновенно даже на миллионе элементов, у списка — перебор по одному.

    Делители — в множество (№25). Делители ищут парами i и n // i до корня. У квадрата на последнем шаге i и n // i совпадают — в списке корень окажется дважды:

    >>> import math
>>> n = 36
>>> d = []
>>> for i in range(1, math.isqrt(n) + 1):
...     if n % i == 0:
...         d += [i, n // i]
...
>>> len(d), len(set(d))
(10, 9)
>>> sorted(set(d))
[1, 2, 3, 4, 6, 9, 12, 18, 36]

    Но «множители не обязательно различные» — список, без set: 49 = 7 · 7 — это два множителя.

    В множество кладутся только неизменяемые значения: числа, строки, кортежи. Список — нельзя; точки или строки файла переводят в кортежи (№26, №27):

    >>> tochki = [[1, 2], [3, 4], [1, 2]]
>>> set(tochki)
Traceback (most recent call last):
  ...
TypeError: unhashable type: 'list'
>>> len(set(tuple(p) for p in tochki))
2

    Словарь¶

    Словарь — пары «ключ → значение»: по ключу сразу находится значение, как слово в словаре:

    >>> d = {'A': 5, 'B': 3}
>>> d['A']
5
>>> d['C'] = 7
>>> d
{'A': 5, 'B': 3, 'C': 7}
>>> 'B' in d, len(d)
(True, 3)
>>> d['Z']
Traceback (most recent call last):
  ...
KeyError: 'Z'
>>> d.get('Z', 0)
0
    Нужно Код
    пустой словарь d = {}
    положить или заменить d[k] = v
    значение, а если ключа нет — 0 d.get(k, 0)
    есть ли ключ k in d
    пройти по ключам for k in d:
    пройти по парам for k, v in d.items():
    ключ с наибольшим значением max(d, key=d.get)

    Подсчёт — ключ — что считаем, значение — сколько раз:

    >>> k = {}
>>> for c in 'ПАПАЙЯ':
...     k[c] = k.get(c, 0) + 1
...
>>> k
{'П': 2, 'А': 2, 'Й': 1, 'Я': 1}
>>> max(k, key=k.get)
'П'
>>> sorted(k, key=lambda c: k[c])
['Й', 'Я', 'П', 'А']

    sorted и max по словарю отдают ключи (упорядоченные по значениям), а не значения.

    Справочник по таблице (№3). Строки таблицы — в словарь по первому столбцу: {s[0]: s for s in stroki} — это ВПР из электронных таблиц. Ключи, прочитанные из файла, — строки, и искать надо строкой:

    >>> stroki = [['42', 'Мука', '50'], ['17', 'Сахар', '80']]
>>> tovar = {s[0]: s for s in stroki}
>>> tovar['42'][1]
'Мука'
>>> tovar[42]
Traceback (most recent call last):
  ...
KeyError: 42

    Словарь словарей — таблица «строка × столбец»: в №12 программа машины Тьюринга prog[состояние][символ].

    Подробнее: повторы в строке (№9), таблица списков, Counter

    Повторы в строке (№9). Число, которое встречается k раз, попадёт в список [x for x in a if a.count(x) > 1] k раз. «Одно число повторяется трижды» — это len(povt) == 3, а не 1. Надёжнее «отпечаток» строки — сколько раз встречается каждое из различных чисел, по возрастанию; его пишут прямо по условию:

    >>> a = [5, 7, 5, 2, 5, 9, 1]
>>> [x for x in a if a.count(x) > 1]
[5, 5, 5]
>>> sorted(a.count(x) for x in set(a))
[1, 1, 1, 1, 3]

    «Одно число трижды, остальные четыре различны» = [1, 1, 1, 1, 3], «две пары и три различных» = [1, 1, 1, 2, 2] (так решаются все 52 задачи №9 Решу ЕГЭ). «Ни максимальное, ни минимальное» при равных — не a[1] после сортировки, а [x for x in a if min(a) < x < max(a)].

    Таблица (список списков) — [[0] * m for _ in range(n)]: n строк по m нулей, клетка — t[i][j] (№18). Короткая запись [[0] * m] * n — ловушка: это n раз одна и та же строка, изменение одной клетки меняет весь столбец:

    >>> t = [[0] * 3] * 2
>>> t[0][0] = 1
>>> t
[[1, 0, 0], [1, 0, 0]]
>>> t = [[0] * 3 for _ in range(2)]
>>> t[0][0] = 1
>>> t
[[1, 0, 0], [0, 0, 0]]

    Список «по номеру» (вершины графа в №23) — длиной на наибольший номер + 1: [10 ** 10] * 1001 при номерах до 1000; короче — IndexError.

    Список, который растёт во время обхода. for x in a: обходит и элементы, добавленные в a по ходу цикла — так собирают кластер в №27 (соседи соседей). А удалять из списка, по которому идёт цикл, нельзя — элементы будут пропущены; удалять — после, по готовому списку.

    >>> a = [1]
>>> for x in a:
...     if x < 5:
...         a.append(x + 1)
...
>>> a
[1, 2, 3, 4, 5]

    Counter из модуля collections — готовый подсчёт: Counter(a) — словарь «значение → сколько раз», most_common(k) — k самых частых:

    >>> from collections import Counter
>>> Counter('ПАПАЙЯ').most_common(2)
[('П', 2), ('А', 2)]

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • max([]), min([]) — ValueError: ничего не подошло или открыт не тот файл; max(s, default=0) или if s: (№17, №22, №25).
    • max вне if — максимум по всем числам, а не по подходящим (демо №17: 177 727 вместо 174 933).
    • Счётчик maxi = 0 ошибается на отрицательных — собирать подходящие в список (№17).
    • b = a — не копия: менять a — меняется и b; копия — list(a) (№12).
    • a[-1] — не ошибка: номер левее нуля молча берёт элемент с конца (№12: 4057 вместо 6124).
    • b = a.sort() — в b будет None; новый список — sorted(a).
    • Две наибольших через set теряют равные (демо-2027 №26: 52 202 вместо 52 204); «три наименьших различных» — наоборот, sorted(set(v))[:3] (№9).
    • Делители — в set: у квадрата корень иначе посчитан дважды (№25); множители «не обязательно различные» — без set.
    • Повторы в строке (№9): число, встречающееся трижды, в списке повторов лежит трижды — проверять «отпечаток» sorted(a.count(x) for x in set(a)).
    • Список в set не кладётся — set(tuple(p) for p in …) (№26).
    • Ключ-строка и ключ-число — разные: tovar['42'], а не tovar[42] (№3).
    • sorted(d) по словарю даёт ключи, а не значения (№26).
    • [[0] * m] * n — n копий одной строки; таблица — [[0] * m for _ in range(n)] (№18).
    • Перестановки букв с повторами — через set, иначе дубли (№8: 288 вместо 156); ответ, который находится несколько раз, — в set и печатать один раз (№2).

    Где встречается¶

    №2 (ответы в set), №3 (словарь-справочник), №5 (min по парам), №8 (перестановки без повторов), №9 (повторы в строке, count, set), №12 (лента — список, программа — словарь словарей), №17 (список подходящих, len и max), №18 (таблица), №22 (max(…, default=0)), №23 (список по номеру вершины, кортежи), №25 (делители в set), №26 (сортировка кортежей, повторы), №27 (точки-кортежи, кластер).
