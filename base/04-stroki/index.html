    4. Строки¶

    Коротко

    Символы строки нумеруются с 0, s[-1] — последний; срез s[a:b] — с a до b, b не включается; s[::-1] — задом наперёд. Строку не изменить — только собрать новую: s = s.replace(…), '10' + s[2:]. Число ↔ строка — str(x) и int(s). count и replace не видят наложений: 'АААА'.count('АА') = 2.

    Как пробовать примеры

    Строки с >>> набирайте в окне IDLE Shell и нажимайте Enter — следующей строкой Python напишет ответ. Каждый пример на странице проверен запуском (Python 3.11 и 3.12).

    Строка и её символы¶

    Строка — текст в кавычках: 'ЕГЭ' или "ЕГЭ" (одинаково). len(s) — длина. Каждый символ имеет номер (индекс) с нуля; отрицательные номера считают с конца:

    s = 'ПИТОН' П И Т О Н
    индекс 0 1 2 3 4
    с конца −5 −4 −3 −2 −1 
    >>> s = 'ПИТОН'
>>> len(s), s[0], s[-1], s[2]
(5, 'П', 'Н', 'Т')
>>> s[5]
Traceback (most recent call last):
  ...
IndexError: string index out of range

    Последний символ — s[len(s) - 1] или проще s[-1]; s[len(s)] — уже ошибка.

    Срезы¶

    s[a:b] — кусок с индекса a до b, не включая b (как в range). Пропущенное начало — с самого начала, пропущенный конец — до конца:

    Нужно Срез s = '1100101'
    первые k символов s[:k] s[:3] → '110'
    последние k символов s[-k:] s[-2:] → '01'
    всё, кроме первых двух s[2:] '00101'
    всё, кроме последних двух s[:-2] '11001'
    задом наперёд s[::-1] '1010011'
    первая половина s[:len(s) // 2] '110'
    два символа с позиции i s[i:i + 2] при i = 1 → '10' 
    >>> s = '1100101'
>>> s[:3], s[-2:], s[2:], s[:-2], s[::-1]
('110', '01', '00101', '11001', '1010011')
>>> s[:len(s) // 2]
'110'

    Срез никогда не выдаёт ошибку: если строка короче, он просто берёт, что есть ('12'[:5] → '12', '12'[5:] → ''). А обращение к одному символу за концом строки — ошибка. Поэтому «всё, кроме двух последних цифр» надёжнее срезом s[:-2], чем перечислением s[0] + s[1]…, рассчитанным на трёхзначные числа (№13).

    Палиндром (читается одинаково в обе стороны): s == s[::-1] (№25).

    Склеить, повторить, сравнить¶

    >>> 'ЕГЭ' + '-' + '2027'
'ЕГЭ-2027'
>>> '0' * 5
'00000'
>>> '1' + 5
Traceback (most recent call last):
  ...
TypeError: can only concatenate str (not "int") to str
>>> '1' + str(5)
'15'

    Строку и число не сложить — число сначала в строку: str(x). Это частая ошибка в №5: дописать остаток к двоичной записи — s = s + str(s.count('1') % 2).

    Строки сравниваются по символам слева направо, а не как числа:

    >>> '9' < '10'
False
>>> 9 < 10
True
>>> 'АРБУЗ' < 'АРКА'
True

    Сравнивать строками можно только отдельные цифры ('0' <= c <= '9') или слова «по алфавиту». Числа — сравнивать числами.

    Числа и строки¶

    Нужно Код Пример
    число → строка str(x) str(2027) → '2027'
    строка → число int(s) int('0012') → 12
    строка с дробным → число float(s) float('4582.0') → 4582.0
    количество цифр len(str(abs(x))) len(str(-512)) = 4, с abs — 3
    сумма цифр sum(int(c) for c in str(x)) для 2027 — 11 
    >>> int('0012'), int(' 12\n')
(12, 12)
>>> int('4582.0')
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: '4582.0'
>>> int(float('4582.0'))
4582
>>> int('')
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: ''
>>> len(str(-512)), len(str(abs(-512)))
(4, 3)

    int сам убирает пробелы и перевод строки по краям, но не понимает точку и пустую строку. int('') чаще всего означает пустую строку в конце файла (см. «Файлы»). Строка в другой системе счисления — int(s, 2), int(s, 16) (раздел «Системы счисления», №14).

    Поиск в строке¶

    Нужно Код Результат для s = 'ABBA'
    есть ли кусок 'BB' in s True
    сколько раз (без наложений) s.count('B') 2
    где первое вхождение s.find('B') 1 (нет — -1)
    начинается / кончается на s.startswith('AB'), s.endswith('A') True, True 
    >>> s = 'ABBA'
>>> 'BB' in s, s.count('B'), s.find('B'), s.find('Z')
(True, 2, 1, -1)
>>> s[s.find('Z')]
'A'

    Последняя строка — ловушка: find вернул −1 («не нашёл»), а s[-1] — это последний символ, ошибки нет. Перед тем как брать символ по find, проверьте if 'Z' in s.

    count не считает наложения. В «TTTT» пар «TT» три (позиции 0, 1, 2), а count находит две — после найденного куска ищет дальше с его конца. Пересекающиеся — перебором позиций со срезом:

    >>> 'TTTT'.count('TT'), '000'.count('00')
(2, 1)
>>> s = 'TTTT'
>>> sum(s[i:i + 2] == 'TT' for i in range(len(s) - 1))
3

    (True при сложении считается за 1, поэтому sum условий — это «сколько раз выполнилось».)

    «Ровно один раз» ≠ «есть»: str(x).count('16') == 1 — ровно одно вхождение, '16' in str(x) — хотя бы одно (№25).

    Префикс — startswith: условие Фано для двух кодов — not a.startswith(b) and not b.startswith(a) (№4).

    Замена¶

    replace заменяет все вхождения и возвращает новую строку — старая не меняется:

    >>> s = '1101'
>>> s.replace('1', '2')
'2202'
>>> s
'1101'
>>> s = s.replace('1', '2', 1)
>>> s
'2101'
    • Третье число — сколько замен сделать: replace('1', '2', 1) — только первое вхождение (№12, №13).
    • Результат надо присвоить: s = s.replace(…). Просто s.replace(…) отдельной строкой ничего не делает.
    • Замены за один проход не перекрываются: '000'.replace('00', '0 0') даёт '0 00' — пара нулей осталась. Повторять, пока есть что заменять: while '00' in s: s = s.replace('00', '0 0') (№24).
    >>> '000'.replace('00', '0 0')
'0 00'
>>> s = '000'
>>> while '00' in s:
...     s = s.replace('00', '0 0')
...
>>> s
'0 0 0'

    Изменить символ¶

    Строку нельзя менять по месту — s[0] = '1' даёт ошибку. Два выхода:

    >>> s = '0011'
>>> s[0] = '1'
Traceback (most recent call last):
  ...
TypeError: 'str' object does not support item assignment
>>> '10' + s[2:]
'1011'
>>> lenta = list(s)
>>> lenta[0] = '1'
>>> ''.join(lenta)
'1011'
    • Собрать новую строку из срезов: «заменить два левых разряда на 10» — '10' + s[2:], а не replace (тот заменит все вхождения, а не первые два символа; №5).
    • Список символов: если строку правят много раз по одному символу (лента машины Тьюринга, №12) — list(s), правка lenta[i] = …, обратно в строку — ''.join(lenta).

    Перебор символов¶

    >>> s = 'ЕГЭ27'
>>> for c in s:
...     if c in '0123456789':
...         print(c)
...
2
7
>>> for i in range(len(s) - 1):
...     print(s[i:i + 2])
...
ЕГ
ГЭ
Э2
27
    • for c in s — по самим символам; for i in range(len(s)) — по номерам, когда нужен сосед (s[i + 1]) или пара. Для пар — range(len(s) - 1), иначе s[i + 1] выйдет за конец.
    • «Символ — цифра» — c in '0123456789' или c.isdigit(); «гласная» — c in 'АЕЁИОУЫЭЮЯ'.

    Разбить и собрать: split, join, strip¶

    >>> '655 861 4582'.split()
['655', '861', '4582']
>>> '655   861'.split(' ')
['655', '', '', '861']
>>> '3;7;12'.split(';')
['3', '7', '12']
>>> '-'.join(['1', '2', '3'])
'1-2-3'
>>> '__101__'.strip('_'), '  12 \n'.strip()
('101', '12')
    • split() без аргумента режет по любым пробелам и табуляциям и не даёт пустых кусков — так и читать строки файла (№23, №26). split(' ') на нескольких пробелах подряд даёт пустые строки, и a, b, c = … падает.
    • join склеивает только строки: числа сначала str — ''.join(str(d) for d in цифры).
    • strip убирает символы только по краям: strip() — пробелы и \n, strip('_') — подчёркивания (№12).

    Буквы: латиница и Ё¶

    >>> 'О' == 'O'
False
>>> ord('О'), ord('O')
(1054, 79)
>>> sorted(['ЕЛЬ', 'ЁЖ', 'АРБУЗ'])
['ЁЖ', 'АРБУЗ', 'ЕЛЬ']
>>> a = 'АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ'
>>> sorted('ЛЁКА', key=a.index)
['А', 'Ё', 'К', 'Л']
    • Русская «О» и латинская «O» выглядят одинаково, но это разные символы (в первой строке примера слева — русская, справа — латинская). На сайтах с задачами в условиях бывает латиница; буквы для программы набирайте сами, не копируйте (№8).
    • sorted упорядочивает по кодам символов (ord), и у заглавной Ё код меньше, чем у А, — она встаёт первой. Нужен порядок алфавита — key=a.index со своей строкой алфавита (№8).

    f-строки¶

    f'…' подставляет значения в фигурных скобках; после двоеточия — формат (подробно — «Системы счисления»):

    >>> x = 13
>>> f'x = {x}, двоичная {x:b}, восемь разрядов {x:08b}'
'x = 13, двоичная 1101, восемь разрядов 00001101'
    Подробнее: регулярные выражения (№24)

    Модуль re ищет в строке куски по образцу. Для №24 хватает нескольких приёмов (полностью — в карточке №24):

    Образец Что значит
    [0-9], [AEIOU] один символ из перечисленных
    [0-9]+, [0-9]* один и больше / сколько угодно (и ни одного)
    A|B A или B — берётся первый подошедший, не самый длинный
    0|[1-9][0-9]* число без ведущих нулей (ноль — отдельной веткой)
    (?=(…)) искать с каждой позиции, в том числе внутри уже найденного 
    >>> import re
>>> s = 'X12+007*30Y'
>>> [m.group() for m in re.finditer('[0-9]+', s)]
['12', '007', '30']
>>> [m.group() for m in re.finditer('0|[1-9][0-9]*', s)]
['12', '0', '0', '7', '30']
>>> re.findall('[0-9]+([+*])', s)
['+', '*']
>>> re.match('[1-9]|[1-9][0-9]*', '345').group(), re.match('[1-9][0-9]*|[1-9]', '345').group()
('3', '345')
>>> [m.group() for m in re.finditer('[0-9][*][0-9]', '2*3*4')]
['2*3']
>>> [m.group(1) for m in re.finditer('(?=([0-9][*][0-9]))', '2*3*4')]
['2*3', '3*4']
    • finditer + m.group() — найденные куски; findall при скобках в образце возвращает содержимое скобок, а не весь кусок.
    • Длинный вариант в | — первым, иначе поиск остановится на коротком.
    • finditer продолжает поиск после конца найденного: «34» внутри «23*4» он пропустит. Искать с каждой позиции — (?=(…)) и m.group(1).

    Типичные ошибки¶

    Скрытые ловушки — проверены запуском

    • s.replace(…) без s = — строка не изменилась (№5).
    • replace меняет все вхождения: «заменить два левых разряда» — '10' + s[2:]; только первое — replace(a, b, 1) (№5, №13).
    • count без наложений: 'TTTT'.count('TT') = 2, а пар три (№8, №24).
    • Одна замена replace('00', '0 0') не рвёт «000» — while '00' in s (№24).
    • len(str(x)) считает минус: len(str(-512)) = 4 — len(str(abs(x))) (№17).
    • '9' < '10' — False: числа сравнивать числами (№13).
    • Строка + число — TypeError: '1' + str(5); в строке ищут строку: s.count('1'), не s.count(1) (№5).
    • s[i] = … — TypeError: собрать новую строку срезами или работать со списком list(s) (№12).
    • s[s.find(x)], когда x нет, молча берёт последний символ (find вернул −1).
    • split(' ') на нескольких пробелах даёт пустые куски — split() без аргумента (№23).
    • int('4582.0') — ValueError: дробное из строки — float, потом int (№23).
    • Латиница вместо русских букв (О/O, А/A, Е/E) — 'О' == 'O' даёт False; буквы набирать самим (№8).
    • sorted ставит Ё перед А — key=алфавит.index (№8).
    • Пары символов — range(len(s) - 1), иначе s[i + 1] выйдет за конец строки.
    • Регулярки (№24): finditer без (?=(…)) пропускает перекрывающиеся куски, в | короткий вариант первым обрывает длинный, число без ведущих нулей — 0|[1-9][0-9]*.
